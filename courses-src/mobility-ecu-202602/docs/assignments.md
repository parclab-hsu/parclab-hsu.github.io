# 과제집 · 주차별 과제와 제출 예시

> 🔗 **사용법** — 각 주차 강의 페이지의 `🧪 실습·과제`가 "무엇을 하는가"라면, 이 페이지는 **"무엇을 어떤 형식으로 내고 어떻게 채점되는가"**를 정한다. 제출 예시는 계산이 끝난 견본이며, 팀 조건으로 다시 계산해야 한다.

!!! note "공통 제출 규칙"
    - 파일명은 `W주차_팀명_이름.pdf` 형식. 예: `W03_로버1팀_홍길동.pdf`
    - 모든 수치에 **단위와 계산 근거**를 적는다. 근거 없는 값은 0점 처리한다.
    - 측정값에는 조건(장비, 설정, 부하, 온도)을 같이 적는다.
    - 데이터시트 인용은 부품 번호·페이지·시험 조건을 표기한다.
    - **예시 수치를 그대로 옮겨 적으면 감점한다.**
    - 마감은 다음 주 수업 시작 전, 1일 지각당 배점의 20% 감점.
    - 각 주차 5점, 15주 합계가 주차별 실습 과제 점수(25%)로 환산된다.

## 1주차 · 로버 ECU 신호 흐름도

| 제출물 | 형식 | 필수 포함 |
|---|---|---|
| 신호 흐름도 A4 1장, 요구사항 3개, 미니 FMEA 3행 | PDF 1~2장 | 전원·MCU·센서·인버터·모터·통신·보호 |

**지시** — 전원 경로와 신호 경로를 선 종류로 구분한다. 요구사항은 주어·조건·행동·수치·단위를 모두 포함한다.

**제출 예시**

```text
전원 ═══        신호 ───

Battery 24V ═ 퓨즈 ═ 역극성 ═ DC링크 ═ 3상 인버터 ═ BLDC
                              ╚═ 벅 5V ═ LDO 3.3V ═ MCU

MCU ── PWM U/V/W ──> 게이트드라이버      MCU <── 홀 A/B/C ─── 모터
MCU <── 스로틀 ADC ── 그립              MCU <── 전류 ─── 션트+증폭
MCU ── UART 상태 ──> PC                 MCU ── Fault ──> LED
```

- REQ-DRV-001: 로버는 평지에서 0.5m/s 이상으로 5m를 이탈 없이 주행해야 한다.
- REQ-SAFE-001: 상전류가 5.0A를 초과하면 2ms 이내에 PWM 출력을 차단해야 한다.
- REQ-PWR-001: 배터리 18~30V 범위에서 MCU 3.3V를 ±5% 이내로 공급해야 한다.

| 고장 형태 | 원인 | 영향 | 탐지 | 안전 상태 |
|---|---|---|---|---|
| 스로틀 단선 | 커넥터 이탈 | 입력 부동, 오동작 가속 | ADC <0.3V 또는 >3.0V | PWM 차단 |
| 홀 신호 오류 | 접촉 불량 | 정류 오류, 역회전 | HallSum 000/111 | PWM 차단, 재시작 요구 |

**채점** — 경로 구분·블록 포함 2점 / 요구사항 검증 가능성 2점 / FMEA 구체성 1점

## 3주차 · MOSFET 선정표

| 제출물 | 형식 | 필수 포함 |
|---|---|---|
| 후보 3종 비교, 손실·접합온도 계산, 선정 근거 | PDF 2장 | 고온 Rds(on), 스위칭·게이트 손실, 열 |

**제출 예시** (24V, 20A 피크, 20kHz, 주위 40°C, 도통률 50%)

```text
Rds(on) @125°C = 5.0mΩ × 1.7 = 8.5mΩ
Pcond = 20² × 0.0085 × 0.5 = 1.70W
Psw  ≈ 0.5 × 24 × 20 × (30+40)ns × 20kHz = 0.34W
Pgate = 30nC × 12V × 20kHz = 7.2mW
Tj ≈ 40 + 2.05 × 40 = 122°C  → 여유 부족
```

판단: 구리 면적을 2배로 늘려 RθJA 25°C/W → Tj ≈ 91°C로 낮추면 채택 가능. 40V 정격 후보는 24V 링잉·회생 과전압에 여유가 없다.

**채점** — 세 손실 계산 2점 / 접합온도·방열 연결 1점 / 전압 여유 판단 1점 / 데이터시트 근거 1점

## 7주차 · PI 속도제어 튜닝 보고

| 제출물 | 형식 | 필수 포함 |
|---|---|---|
| Kp·Ki 3조합 비교, 선택 근거, anti-windup 검토 | PDF 2~3장 + 그래프 | 동일 조건, 전류 기록, 포화 실험 |

**제출 예시** (무부하, 0 → 300rpm step, 1ms 주기, duty 상한 60%)

| 실험 | Kp | Ki | 상승 | overshoot | 정착 | 정상오차 | 최대전류 |
|---|---:|---:|---:|---:|---:|---:|---:|
| A | 1.0 | 5 | 0.42s | 0% | 0.55s | 6.0% | 1.8A |
| B | 2.0 | 10 | 0.18s | 8% | 0.31s | 0.5% | 2.6A |
| C | 4.0 | 20 | 0.09s | 24% | 0.72s | 0.4% | 4.8A |

선택 **B**. C는 최대 전류가 과전류 임계 5.0A에 근접하고, A는 정상오차 6%로 ±5% 요구를 못 맞춘다.

포화 실험: duty 상한 30%에서 500rpm 지령 후 200rpm으로 낮추면 210rpm까지 overshoot가 1.4초 지속된다 → 적분항이 포화 중에도 누적된 결과.

**채점** — 정량 비교 2점 / 요구사항 연결 1점 / 포화 재현 1점 / 적분 처리 지적 1점

## 8주차 · 레지스터 직접 제어 코드

| 제출물 | 형식 | 필수 포함 |
|---|---|---|
| GPIO 제어 코드와 주석, CubeMX 생성 코드 대조 | 코드 + PDF 1~2장 | "왜 필요한가" 중심 주석, register view |

**제출 예시**

```c
/* BSRR을 쓰는 이유: ODR read-modify-write는 ISR이 같은 포트를 건드리면
 * 갱신이 유실될 수 있다. BSRR은 해당 비트만 원자적으로 set/reset한다. */
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN;   /* 클럭 없으면 레지스터 쓰기가 무시된다 */
GPIOC->MODER &= ~(3U << (6 * 2));      /* 두 비트를 먼저 지운다 */
GPIOC->MODER |=  (1U << (6 * 2));      /* 01 = output */
GPIOC->BSRR   =  (1U << 6);            /* ON  */
GPIOC->BSRR   =  (1U << (6 + 16));     /* OFF */
```

CubeMX로 같은 핀을 설정해 생성된 `MX_GPIO_Init()`이 건드리는 레지스터를 register view로 확인하고 위 코드와 대조한다.

**채점** — 비트 마스킹·BSRR 이유 2점 / clock enable 연결 1점 / CubeMX 대조 1점 / 주석 품질 1점

| 회로도·PCB 초안, 배치 의도 1장, net class, DRC 결과 | PDF 2~3장 + 프로젝트 | 폭 근거, 미해결 DRC |

**제출 예시** — 배치 순서: `전원 커넥터 → DC 링크 → MOSFET 브리지 → 게이트드라이버 → 션트 → MCU → 센서 커넥터`. 고전류 루프를 먼저 최소화하고 MCU는 스위칭 노드에서 15mm 이상 이격.

| Net class | 폭/규칙 | 근거 |
|---|---|---|
| High current (BAT+, PHASE) | 2.5mm, 2oz 외층 | 10A, ΔT 20K 기준 + 여유 |
| Switching (SW node, GATE) | 0.5mm, 루프 최소 | 면적 최소·민감 신호 이격 |
| Analog sense (SHUNT, NTC) | 0.3mm 차동쌍 | Kelvin, 리턴 분리 |

DRC: 오류 0, 경고 3(실크 겹침 2, 테스트 포인트 간격 1) → rev C 정리 예정

**채점** — 배치 논리 2점 / 폭 근거 1점 / net class 1점 / DRC 기록 1점

## 14주차 · 노이즈·그라운드 개선 보고서

| 제출물 | 형식 | 필수 포함 |
|---|---|---|
| 개선안 3건(문제·원인·영향·개선·검증), A/B 실험 | PDF 2~3장 + 파형 | 동일 조건 비교, 부작용 기록 |

**제출 예시** — 게이트 저항만 변경, 나머지 조건 동일

| 항목 | A: 10Ω | B: 22Ω | 판단 |
|---|---:|---:|---|
| Switch node overshoot | 41V | 31V | 정격 여유 개선 |
| ADC 전류 표준편차 | 12 LSB | 5 LSB | 개선 |
| MOSFET 온도(10분) | 62°C | 69°C | **악화** |
| 효율 | 89.1% | 88.6% | 소폭 악화 |

**B 채택** — 온도 7°C 상승은 Tj 여유 내이고 overshoot·계측 안정성 이득이 크다. 방열 면적을 늘리고 장시간 부하로 재확인한다.

**채점** — source·path·victim 분리 2점 / 동일 조건 1점 / 부작용 기록 1점 / 실현 가능성 1점

## 15주차 · 구동 펌웨어 구조도와 최종 보고서

15주차는 두 과제를 함께 낸다. 배점은 각 5점이며 최종 발표 평가와 별도로 산정한다.

### 15-A. 통합 펌웨어 구조도와 안전 차단 경로

**제출 예시**

```text
[TIM1 ISR 20kHz] ADC → 전류·온도 판정 → Fault 처리 → Set_Phases()
                                    ↓ (FltFlg)
                               Disable_PWM() → MOE=0
[EXTI0/1/2] Hall edge → Update_Hall_Sequence() → SpeedCal()
[1ms Task]  RpmRef → PI → VoltageRef
```
