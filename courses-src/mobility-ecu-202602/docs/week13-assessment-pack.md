## 10분 퀴즈

1. 회로도와 PCB가 각각 답해야 하는 질문을 구분하게 한다.
2. 전력 트레이스 폭을 결정할 때 고려할 요소를 쓰게 한다.
3. 테스트포인트 네 개의 위치와 측정 목적을 제안하게 한다.
4. `회로도와 PCB 배치`를 SDV 진단 데이터와 연결해 한 문장으로 설명하라.

## 계산·해석 문제

### 문제 1 · 입력 조건 정리
회로도·PCB 설계 기초에서 필요한 입력 조건을 세 개 쓰고, 각 조건의 단위를 붙인다.

### 문제 2 · 결과 예측
회로도에서 같은 net label이 PCB에서 실제 구리 경로로 바뀌는 과정을 보여준다. 이때 학생 답안에는 식, 대입값, 단위, 결론이 들어가야 한다.

### 문제 3 · 실패 원인 분류
커넥터 방향을 고려하지 않으면 조립 후 케이블이 모터와 간섭할 수 있다. 이 상황을 하드웨어, 펌웨어, 측정 조건으로 나누어 원인을 추정한다.

### 문제 4 · 보호 기능 제안
전력 트레이스가 너무 얇으면 전압강하와 발열이 생긴다. 이 문제를 줄이기 위한 감지 조건, 안전 상태, 로그 항목을 제안한다.

## 구두 발표 질문

- `회로도와 PCB 배치`에서 학생이 실제로 측정한 값은 무엇인가?
- 오토라우터가 배선을 끝내면 PCB가 완성된다는 오해를 전류 루프와 노이즈로 교정한다.
- 회로도에서 선이 이어졌으니 PCB도 안전하다는 생각을 트레이스 폭과 간격으로 바로잡는다.
- 테스트포인트는 남는 공간에 넣는다는 습관을 디버깅 절차와 연결한다.

## 채점 루브릭

### 5점
회로도·PCB 설계 기초의 시스템 위치, 수치 근거, 실험 증거, 안전 고려가 모두 명확하다.

### 4점
핵심 원리는 맞고 `회로도와 PCB 배치` 증거도 있으나 최악 조건 설명이 약하다.

### 3점
동작 결과는 있으나 회로도와 PCB가 각각 답해야 하는 질문을 구분하게 한는 충분히 설명하지 못한다.

### 2점
용어 설명은 있으나 실제 회로, 코드, 로그와 `회로도와 PCB 배치`를 연결하지 못한다.

### 1점
결과만 제출하고 회로도·PCB 설계 기초 판단 근거가 없다.

## 슬라이드 기반 평가 문항 설계

### 즉답형 확인

1. `회로도와 PCB 배치`를 설명할 때 가장 먼저 확인해야 할 입력 조건을 하나 쓰시오.
2. `기본 설계 기준: 전류 경로 폭, 절연거리, 열 방출, 테스트 포인트 접근성`에서 학생이 직접 측정하거나 정해야 하는 값을 표시하시오.
3. 첨부자료 이미지에서 이번 주 주제와 연결되는 실제 부품, 단자, 파형, 코드 위치 중 하나를 지목하시오.

### 서술형 확인

- 정상 동작과 비정상 동작을 구분하는 기준값을 정하고, 그 기준값을 어떻게 검증할지 쓰게 한다.
- 계산 결과와 측정 결과가 다를 때 가능한 원인을 하드웨어, 펌웨어, 측정 조건으로 나누어 설명하게 한다.

### 발표 평가 포인트

- 발표자는 그림을 읽는 수준에서 멈추지 않고, 그림 속 요소가 최종 AMR ECU의 어떤 요구사항을 만족시키는지 말해야 한다.
- AI 도구를 사용한 경우, AI가 제안한 내용과 학생이 실제 자료로 검증한 내용을 분리해 적게 한다.
