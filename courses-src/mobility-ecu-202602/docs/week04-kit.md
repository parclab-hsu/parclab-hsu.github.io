# 4주차 운영 키트 — 전원회로와 변환기

### 교안 정보

| 항목 | 내용 |
|---|---|
| 교과목 | 모빌리티 전자제어유닛 실습 (3학점 · 전공) |
| 대상 | 미래모빌리티학과 3~4학년 |
| 차시 | 4주차 / 15주차 · 180분 |
| 강의실 | Physical AI 실습실 |
| 관련 자료 | 상세 강의자료 04번 · 과제집 17번 · 배포용 워크시트 I·J |

### 학습목표

이 시간이 끝났을 때 학생은 다음을 수행할 수 있다.

1. 배터리 전원에서 MCU·센서·게이트드라이버 전원을 나누는 전원 트리를 설계한다.
2. 리니어 레귤레이터, 벅컨버터, 부스트컨버터의 차이를 설명한다.
3. 전원 노이즈와 리턴 경로가 ADC와 MCU 동작에 미치는 영향을 이해한다.

### 핵심 질문

- 왜 배터리 24V를 바로 MCU에 넣을 수 없는가?
- LDO와 벅컨버터는 언제 각각 유리한가?
- 전원 노이즈는 어디로 돌아가는가?

### 지도 중점

3주차가 "소자 하나를 조건으로 고른다"였다면, 4주차는 **"시스템 전체의 전류를 장부로 관리한다"** 를 처음 시키는 시간이다. 이 주차의 목표는 회로도 그리기가 아니라 **전원을 예산과 시퀀스로 보는 눈**이다.

> 이 주차의 산출물(전원 트리·전력 예산)은 **8주차 중간 설계 리뷰에 그대로 제출**된다. 학생에게 미리 알린다.

### 1. 180분 진행 대본

#### 블록 1 · 0~40분 — 전원 구조와 두 가지 변환 방식

**목표** — "배터리 하나에서 왜 전압이 네 개나 필요한가"를 납득시킨다.

1. (5분) **3주차 과제 피드백.** 온도 계수를 적용한 답안과 안 한 답안을 나란히 보여 준다.

   > 🗣️ "지난주엔 **부품 하나**의 열을 계산했습니다. 오늘은 **보드 전체**의 전류를 계산합니다."

2. (10분) **모빌리티 전원 구조.** 레퍼런스 보드의 전원 트리를 띄운다.

   ```text
   배터리 → 퓨즈 → 역극성 보호 → +DC_LINK (인버터)
                                → 12V (게이트드라이버)
                                → 5V  (센서·통신)
                                → 3.3V (MCU·로직)
   ```

   > 🗣️ "왜 배터리 24V를 MCU에 바로 못 넣습니까? MCU는 3.3V에서 동작하고, 3.6V가 넘으면 죽습니다. 그런데 왜 5V도 따로 필요할까요?"

   답: 센서·통신 소자가 5V를 요구한다. **전압 종류는 부품이 정한다.**

3. (12분) **리니어 레귤레이터(LDO)** — 단순·저노이즈 vs 발열.

   > ✍️ 판서: `P = (Vin − Vout) × Iout`

   여기서 **실물 시연**을 넣는다. LDO에 12V를 넣고 5V/300mA를 뽑아 표면 온도를 재게 한다.

   > 🗣️ "(12−5) × 0.3 = 2.1W입니다. 손대지 마세요. 이 열은 **어디로도 안 갑니다.** 그냥 버려집니다."

4. (13분) **벅컨버터** — 스위칭 강압, 인덕터·동기 MOSFET·커패시터, 주파수와 리플.

   > 🗣️ "벅은 전압을 **잘라서 평균을 만듭니다.** 그래서 버리는 열이 적습니다. 대신 스위칭 노이즈가 생기죠. 14주차에서 이 노이즈 때문에 고생합니다."

   | | LDO | 벅 |
   |---|---|---|
   | 효율 | 낮음 (Vout/Vin) | 높음 (85~95%) |
   | 노이즈 | 낮음 | 스위칭 노이즈 |
   | 부품 수 | 적음 | 인덕터·커패시터 필요 |
   | 유리한 곳 | 전압차 작고 전류 작을 때, 아날로그 기준 | 전압차 크거나 전류 클 때 |

> ✅ **이 블록이 끝났을 때** — 학생이 "LDO는 입출력 전압 차이를 열로 버린다"를 온도 측정으로 확인한 상태.

#### 블록 2 · 40~90분 — 전력 예산과 벅 계산 (활동 1·2)

**목표** — 전원 설계를 **장부(전류 예산)** 로 다루게 한다.

1. (25분) **활동 1 — 전원 트리와 전력 예산** (워크시트 I)

   레일별로 부하를 적고, **설계 여유 30%** 를 곱하게 한다.

   판서로 예시를 채운다.

   ```text
   12V  게이트드라이버   0.30A × 1.3 = 0.39A
   5V   홀센서·통신      0.45A × 1.3 = 0.59A
   3.3V MCU·로직         0.25A × 1.3 = 0.33A

   Pout = 12×0.39 + 5×0.59 + 3.3×0.33 = 8.72W
   Pin  = Pout / η = 8.72 / 0.85       = 10.26W
   Iin(24V) = 10.26 / 24               = 0.43A
   ```

   > ⚠️ **출력 전류 = 입력 전류가 아니다.** 효율을 나누는 단계를 빠뜨리는 사례가 매 학기 반복된다. 이 지점을 분명히 짚는다.

2. (10분) **활동 2 — LDO 발열 계산** (워크시트 I 하단)

   Vin 12V → Vout 5V에서 100/300/500mA 각각의 발열을 계산하고 판단하게 한다.

   > 🗣️ "500mA면 3.5W입니다. 이 부품의 열저항이 50°C/W면 접합온도가 얼마나 오릅니까? 지난주에 배운 식 그대로입니다."

   답: 175°C 상승. **LDO를 쓸 수 없다** → 벅 채택 근거가 숫자로 나온다.

3. (15분) **배터리는 이상적인 전압원이 아니다.**

   > ✍️ 판서
   > ```text
   > Vbat(부하) ≈ Vocv(SoC) − Ipeak × (Rcell + Rwire + Rconnector + Rfuse)
   > ```

   > 🗣️ "로버가 전류를 가장 많이 쓰는 순간이 언제입니까? 경사를 오를 때죠. 그런데 **바로 그때 배터리 전압이 가장 많이 떨어집니다.** 그래서 경사 진입할 때마다 로버가 꺼지는 일이 생깁니다."

   설계 기준은 만충 전압이 아니라 **"방전 말기 + 피크 전류"의 최저 전압**임을 강조한다. 그 조건에서 각 레귤레이터가 드롭아웃을 넘기는지 확인시킨다.

#### 블록 3 · 90~155분 — 벅 계산과 전원 계측 (활동 3·추가 실습)

**목표** — 데이터시트 예제를 **자기 조건으로 다시 계산**하게 한다.

1. (25분) **활동 3 — 벅컨버터 소자 검토** (워크시트 J 상단)

   TPS54360 예시(36V→12V)를 열고 항목을 확인시킨 뒤, 팀별 조건으로 다시 계산하게 한다.

   > ✍️ 판서
   > ```text
   > D     ≈ Vout / Vin
   > ΔIL   ≈ (Vin − Vout) × D / (L × fsw)
   > Ipeak ≈ Iout + ΔIL/2
   > ```

   확인 포인트: **인덕터 포화전류 > 계산한 Ipeak** 인가.

   > 🗣️ "포화전류를 넘기면 인덕턴스가 갑자기 떨어집니다. 그러면 전류가 폭주하고, 그 다음은 지난주에 배운 대로입니다."

2. (25분) **추가 실습 — 전원 계측**

   먼저 **가짜 링잉 시연**을 한다. 이 주차에서 교육 효과가 가장 큰 시연이다.

   > 같은 지점을 ① 긴 GND 리드 ② 짧은 ground spring 두 방식으로 재서 파형을 나란히 보여 준다.

   > 🗣️ "회로는 바꾸지 않았습니다. **프로브만 바꿨습니다.** 어느 쪽이 진짜입니까?"

   그다음 팀별로 측정한다.

   | 조건 | 기록할 것 |
   |---|---|
   | 무부하 | 리플 (AC coupling, bandwidth limit 조건 명기) |
   | 정상 부하 | 리플, 출력 전압 |
   | 최대 부하 | 리플, 전압 강하 |
   | 기동 순간 | 상승 시간, 오버슈트 |

3. (15분) **부하 과도 시험.** 5V 레일을 100mA → 500mA로 급변시키고 전압 강하와 회복 시간을 잰다.

   > ⚠️ 저항 부하를 쓸 때는 **전력 정격과 표면 온도를 먼저 계산**하게 한다. 계산 없이 연결하면 저항이 소손된다.

**교수는 돌아다니며 두 가지만 확인한다**
- 측정 조건(프로브 종류·커플링·대역폭 제한)을 적었는가
- 무부하와 부하 조건을 **구분해서** 기록했는가

> ✅ **이 블록이 끝났을 때** — 학생이 "측정값에는 측정 조건이 따라붙는다"를 파형으로 확인한 상태.

#### 블록 4 · 155~180분 — 입력 보호와 과제

1. (10분) **입력 보호 순서**를 판서로 정리한다.

   ```text
   커넥터 → 퓨즈 → 역극성 보호 → TVS → 입력 필터 → DC/DC
   ```

   | 항목 | 왜 그 자리인가 |
   |---|---|
   | 퓨즈 | 사고 전류를 가장 앞에서 끊는다 |
   | 역극성 보호 | 역방향으로 연결해도 후단 회로가 손상되지 않게 한다 |
   | TVS | 순간 과전압 흡수 |
   | 입력 필터 | 전도 노이즈 차단 (14주차 연결) |

   **돌입전류**도 짚는다. 큰 DC 링크 커패시터는 켜는 순간 빈 물통이라 전류가 몰린다 → 프리차지 또는 전류 제한 필요성 판단.

   > 🗣️ "그리고 전원이 천천히 올라오면 MCU가 **반복 리셋**됩니다. BOR와 power-good를 확인해야 합니다."

2. (7분) **형성평가 3문항**

   1. 24V에서 5V/1A를 90% 효율로 만들 때 입력 평균전류는?
   2. 벅컨버터 입력 커패시터가 스위치에서 멀면 어떤 루프가 커지는가?
   3. MCU가 모터 기동 때만 리셋된다면 확인할 전원 파형 세 가지는?

3. (5분) **과제 안내**

   > 4주차 과제 — 전원 트리 도식 + 레일별 전류·보호 요구사항 표 + 입력 전류 계산
   > 형식: PDF 2장 · 파일명 `W04_팀명_이름.pdf`
   > 마감: 다음 주 수업 시작 전 · 1일 지각당 20% 감점
   > 배점 5점 — 레일별 부하·여유 2 / 효율 반영 입력 전류 1 / LDO·벅 선택 근거(발열) 1 / 입력 보호 순서 1

   > 🗣️ "이 과제는 **8주차 중간 설계 리뷰에 그대로 들어갑니다.** 지금 잘 만들어 두면 그때 다시 안 만들어도 됩니다."

4. (3분) **다음 주 예고**

   > 🗣️ "다음 주부터 모터입니다. 오늘 만든 전력 예산에 **가장 큰 부하**가 들어옵니다. 로버가 경사를 오르려면 토크가 얼마나 필요한지 역산합니다."

### 2. 판서 목록

1. 전원 트리 (배터리 → 퓨즈 → 역극성 → DC링크 / 12V / 5V / 3.3V)
2. `P = (Vin − Vout) × Iout` — LDO 발열, 12→5V 0.3A = 2.1W
3. 전력 예산 3줄 + `Pin = Pout/η` + `Iin = Pin/Vin` (8.72W → 10.26W → 0.43A)
4. `Vbat(부하) ≈ Vocv − Ipeak × Rtotal`
5. `D ≈ Vout/Vin`, `ΔIL ≈ (Vin−Vout)×D/(L×fsw)`, `Ipeak ≈ Iout + ΔIL/2`
6. 입력 보호 순서: 커넥터 → 퓨즈 → 역극성 → TVS → 필터 → DC/DC

### 3. 자주 나오는 질문과 답

| 학생 질문 | 답 |
|---|---|
| "그냥 다 벅으로 하면 안 되나요?" | 대체로 맞다. 다만 **아날로그 기준 전압**처럼 노이즈에 민감한 곳은 LDO가 유리하다. 벅으로 내린 뒤 LDO로 한 번 더 거르는 조합도 흔하다 |
| "여유 30%는 어디서 나온 숫자인가요?" | 관례적 출발점이다. 근거는 **부품 공차·온도·측정 오차·미래 추가 부하**다. 팀이 다른 값을 쓰려면 이유를 적으면 된다 |
| "효율 85%는 어떻게 아나요?" | 데이터시트의 효율 곡선을 본다. **출력 전류에 따라 달라진다** — 경부하에서 특히 낮다 |
| "리플이 얼마면 되나요?" | 부하가 정한다. MCU는 관대하지만 **ADC 기준전압**은 엄격하다. 목표를 먼저 정하고 측정한다 |
| "왜 프로브만 바꿨는데 파형이 달라지나요?" | 긴 GND 리드가 만드는 **루프 인덕턴스**가 스코프에 링잉으로 보인다. 회로가 아니라 **측정계의 문제**다 |

| 10분 남음 | 부스트컨버터 구조만 짚고 "로버 보조 전원에 언제 쓰는가" 예고 |
| 15분 부족 | 부하 과도 시험을 교수 시연으로 대체 |
| 30분 이상 부족 | 벅 계산(활동 3)을 과제로 넘긴다. **활동 1(전력 예산)은 반드시 그 자리에서** — 8주차 제출물이다 |

### 5. 안전 점검

이번 주부터 **전원공급기로 실제 전력을 다룬다.** 안전 수준을 한 단계 올린다.

- 전원공급기는 **반드시 전류 제한을 먼저 설정**하고 출력을 켠다
- 배선을 바꿀 때는 **출력을 끄고** 한다. 활선 상태로 점퍼를 옮기지 않는다
- LDO 발열 시연 부품은 방열판이 없으므로 **손으로 만지지 않고 온도계로 확인**한다
- 부하 저항은 전력 정격을 계산한 뒤 사용한다. 정격을 넘기면 타거나 화상을 입는다
- 전해 커패시터 극성을 다시 확인한다. 이번 주는 전압이 24V까지 올라간다
- 오실로스코프 GND 클립은 **회로의 GND에만** 연결한다
