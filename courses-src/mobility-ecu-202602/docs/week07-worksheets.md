### 2. 이산 PI 유도

제어 주기 `Ts` = ______ ms = ______ s

```text
error[k] = ref[k] − fdb[k]

I[k]     = I[k−1] + Ki × Ts × error[k]

u_raw[k] = Kp × error[k] + I[k]

u[k]     = clamp(u_raw[k],        ,        )
```

**블록도와 코드 변수 연결**

```text
RpmRef → RpmErr → Pterm ┐
                         ├→ PIterm → VoltageRef → Duty → Motor → RpmFdb
                  Iterm ┘
```

|---|---|---|
