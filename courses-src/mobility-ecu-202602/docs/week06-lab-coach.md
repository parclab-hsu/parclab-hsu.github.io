# 6주차 실습 코칭노트 · 인버터·PWM 구동

> 이 문서는 수업 중 학생 활동을 지도하기 위한 코칭 자료다. 교수자는 설명보다 관찰, 질문, 기록을 중심으로 진행한다.

## 오늘의 실습 미션

- 미션 요약: 상하단 동시도통 위험 분석, PWM 주파수 계산, 션트 위치 비교
- 사용할 자료: `inverter-hardware-design-v0.1.pdf / motor-control-inverter-theory.pdf`
- 참고 이미지: `figures/attachment-previews/inverter-hardware-p01.png`, `figures/inverter3ph.svg`
- 제출 형식: 계산표, 회로 캡처, 코드 일부, Teleplot 로그, 사진 중 최소 1개를 포함한다.

## 실습 전 준비

| 항목 | 확인 내용 | 실패 시 조치 |
|---|---|---|
| 전원 | 전압, 전류제한, 극성, 공통 그라운드 확인 | 전원 차단 후 배선 재검토 |
| 보드 | MCU 보드, 드라이버, 센서 커넥터 방향 확인 | 사진 기록 후 조교 확인 |
| 소프트웨어 | 프로젝트 열기, 빌드, 다운로드, 시리얼 포트 확인 | 포트와 보레이트부터 재확인 |
| 기록 | 팀 폴더, 날짜, 버전, 실험 조건 작성 | 결과 없는 실습으로 처리하지 않음 |

## 단계별 코칭 질문

1. 지금 만지는 신호는 전원, 제어, 센서, 통신 중 어디에 속하는가?
2. 이 값을 바꾸면 어떤 물리량이 먼저 변해야 하는가?
3. 측정값이 예상과 다르면 회로, 코드, 장비 설정 중 무엇부터 확인할 것인가?
4. 같은 오류를 다음 팀이 피하려면 어떤 한 줄 메모를 남겨야 하는가?

## 팀 활동 절차

| 순서 | 활동 | 교수자 체크 |
|---|---|---|
| 1 | 첨부자료 대표 이미지를 열고 오늘 미션 위치에 표시 | 표시가 시스템 블록도와 일치하는가 |
| 2 | 계산값 또는 설정값을 먼저 예측 | 단위와 기준값이 맞는가 |
| 3 | 보드, 회로, 코드 중 하나를 실제로 조작 | 위험한 전원 조건이 없는가 |
| 4 | 결과를 캡처하거나 로그로 저장 | 재현 가능한 파일명인가 |
| 5 | 실패 원인을 한 문장으로 기록 | 원인과 증상이 구분되는가 |

## 평가 루브릭

| 수준 | 학생 산출물 특징 |
|---|---|
| A | 계산, 측정, 로그가 서로 맞고 최종 ECU 블록과 연결해 설명한다 |
| B | 실습 결과는 있으나 최악 조건, 오차, 안전 설명이 일부 부족하다 |
| C | 결과 캡처는 있으나 입력 조건이나 재현 절차가 빠져 있다 |
| D | 실행 여부만 적고 수치, 그림, 로그 증거가 없다 |
