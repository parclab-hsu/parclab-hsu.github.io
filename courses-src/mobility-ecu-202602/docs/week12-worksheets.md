# 12주차 배포용 워크시트

진행 대본과 준비 체크리스트는 [12주차 운영 키트](week12-kit.md)에 있다.

| 워크시트 | 인쇄 부수 | 사용 시점 |
|---|---|---|
| Y. HSI 핀 리뷰와 게이트드라이버 검토 | 수강생 수 | 50~105분 |
| Z. 회로 리뷰 체크리스트와 fault chain | 팀 수 + 2 | 105~160분 |

> ⚠️ 워크시트 Z의 **NG 항목과 조치 계획**은 15주차에 조치 여부를 확인한다. 반드시 회수한다.

### 2. 게이트드라이버 구동 능력 계산

| 항목 | 값 | 출처 |
|---|---|---|
| MOSFET `Qg` | nC | |
| 목표 스위칭 시간 `tswitch` | ns | |
| 스위칭 주파수 `fsw` | kHz | |
| 게이트 구동 전압 `Vgate` | V | |
| 스위치 개수 | 개 | |

```text
Igate,peak ≈ Qg / tswitch  =            /            =            A

Igate,avg  = Qg × fsw × 스위치 개수  =                             =            mA

Pgate      = Qg × Vgate × fsw        =                             =            mW
```

| 질문 | 우리 팀의 답 |
|---|---|
| MCU 핀이 낼 수 있는 전류는 대략 | mA |
| 필요한 피크 전류는 그보다 몇 배인가 | 배 |
| 선택한 드라이버의 피크 출력 전류 정격 | A |
| 여유가 있는가 | 예 / 아니오 |

### 3. 부트스트랩 검토

```text
Cboot ≥ Qtotal / ΔVboot
```

| 항목 | 값 | 근거 |
|---|---|---|
| `Qg` (게이트 전하만) | nC | |
| 드라이버 소비·누설 추정 | nC | |
| 여유 배수 | 배 | |
| **`Qtotal`** | nC | |
| 허용 전압 강하 `ΔVboot` | V | |
| **계산한 `Cboot` 최소값** | µF | |
| 실제 선택한 값 | µF | |

| 질문 | 답 |
|---|---|
| `Qg`만으로 정하면 왜 부족한가 | |
| 부트스트랩 다이오드에서 확인할 항목 2가지 | |
| duty 100%를 유지할 수 없는 이유 | |

### 4. 게이트드라이버 회로 리뷰 (레퍼런스 보드 시트 3)

| 리뷰 항목 | 회로도에서 찾은 것 | 판정 |
|---|---|---|
| 게이트 저항이 드라이버 출력과 게이트 **사이**에 있는가 | | OK / NG |
| 부트스트랩 다이오드 역전압 정격 | | OK / NG |
| high-side supply는 어디서 오는가 | | OK / NG |
| low-side return이 파워 GND와 만나는 지점 | | OK / NG |
| PWM 입력이 3.3V 로직을 받는가 | | OK / NG |
| **fault 출력이 어디로 가는가** | | OK / NG |

> ⚠️ fault 출력이 **아무 데도 연결되지 않았다면 NG**다. 드라이버가 이상을 알려도 받는 곳이 없다.

### 5. 전류 센싱과 보호 연결

| 항목 | 값 |
|---|---|
| 션트 저항 `Rshunt` | mΩ |
| 최대 상전류 `Irms` | A |
| `Vshunt = I × Rshunt` (최대) | mV |
| 손실 `P = Irms² × Rshunt` | W |
| 션트 정격 전력 | W |
| 여유율 | 배 |

| 질문 | 우리 팀의 답 |
|---|---|
| 션트를 크게 하면 정확도와 손실은 각각 어떻게 되는가 | |
| Kelvin 센싱을 안 하면 무엇이 측정값에 섞이는가 | |
| 과전류 임계값을 두 경로로 나누는 이유 | |
