# 모터/인버터/제어 이론 기술 노트 (5·6·7·12주차)

> 근거: UAV개발/모터제어&인버터 이론.pdf, 모터제어&인버터 기술면접 정리.pdf, 인버터하드웨어설계_ver0.1.pdf

## 모터 분류
- 전원형태: DC(권선형/영구자석) / AC(동기: PMSM(SPMSM/IPMSM)·Reluctance·WFSM / 비동기:유도전동기 농형·권선형).
- BLDC = DC 브러시 제거, 구조는 SPMSM과 유사. 킥보드/인휠 = 영구자석 회전자 + 3상 인버터.

## 기초 물리
- 토크 Tq=r·F·sinθ (θ=90°서 최대). 플레밍 왼손=모터 회전력, 오른손=역기전력.

## DC 모터 (5주차)
- 전압식: Va=Ra·ia+La·dia/dt+ea. 역기전력 ea=ke·φf·ωm.
- 토크: Te=kT·φf·ia=KT·ia → **전류제어=토크제어**.
- 운동방정식: Te=J·dωm/dt+B·ωm+TL.
- 전기(R-L)↔기계(관성/마찰) 대응.

## 제어공학 (7주차)
- 오픈루프 vs 폐루프. 라플라스 F(s)=∫f(t)e^(-st)dt, s=σ+jω.
- 주파수응답: Bode, -3dB=차단주파수. dB=20log|M|.
- RC LPF 예: G(s)=1/(0.0002s+1), fc=1/(2πRC)≈796Hz.
- 안정도: 극점이 좌반평면(LHP), 원점서 멀수록 빠른 수렴.
- **P**: u=Kp·(r−y) 빠름·정상오차有. **I**: u=u_prev+ki·Δt·(r−y) 정상오차0·느림. **PI**: 결합, 모터/온도 제어 최다 사용.
- **이득여유 GM**(위상 -180°지점 이득), **위상여유 PM**(이득 0dB지점 위상). GM3dB/PM25°면 위험.

## 인버터/PWM (6주차)
- 하프브리지=극/레그/암. 상보동작. **Arm short**(Q1·Q2 동시 On)=단락 → 데드타임으로 방지.
- 데드타임 구간: 인덕터부하 전류는 MOSFET 바디다이오드로 흐름, 전류방향(iO±)이 극전압 결정.
- PWM 사용이유: 저항조절은 손실(P=I²R)·정밀제어 불가. 듀티비로 평균전압. 캐리어(삼각파) vs 지령 비교로 생성.
- 극전압: Q1=1→Van=+Vdc/2. 평균전압=듀티 비례.
- 풀브리지(H브리지)=DC 양방향.

## BLDC (5·6주차)
- 회전자=영구자석. BLDC vs PMSM: 역기전력 형태로 구분(BLDC=준구형파/집중권, PMSM=정현파/분포권). 집중권=토크리플↑.
- **3상 인버터=하프브리지 3개, 2상 여자(한 상 Off, 두 상 통전)**.
- **홀센서**: 3개 전기적 120° 간격, N극접근 High. 홀조합→통전상태(6-step, 각 120°).
- 홀조합 통전표 예: 011→ia+,ic− / 001→ib+,ic− / 101→ib+,ia− / 100→ic+,ia− / 110→ic+,ib− / 010→ia+,ic−.
- BLDC 모델: va=Rs·ia+(Ls−M)·dia/dt+ea. 출력 Pm=Σe·i, Te=Pm/ωm. 인휠 실물 30극.
- **유니폴라 PWM**(한 스위치만 PWM)=손실 최소. **킥보드는 하단 On 유지·상단만 PWM → 이유: 션트 전류 센싱**.
- **전기각=기계각×극쌍수(PP=극수/2)**. 30극→PP15.

## 속도계산/전류측정 (5주차)
- 엔코더 A/B 90°위상차. **M방식**(펄스 개수, 고속용), **T방식**(펄스 간 시간, 저속용, MCU클럭 촘촘할수록 정밀).
  - M: N=60·m/(Ts·P). T: N=60/(m·Ts·P). (P=PPR, m=펄스수, Ts=샘플주기)
- 킥보드는 홀센서로 저속 위치 취득 → T방식.
- 전류측정: **션트**(저렴·DC측정가능, 킥보드 채택) / CT(절연·AC만) / 홀전류센서(고전력).

## 인버터 하드웨어 설계 (12주차)
- 개발흐름: 요구사항→회로설계→PCB→기능테스트→조립→통합→EMI/EMC. Tool=EasyEDA, 제작=JLCPCB. 회로 3분할(MCU/게이트드라이버/파워). EMC=EMI+EMS.
- **3상 인버터 사양**: 입력 18~42V(정격36V), 최대 350W, 연속 15A RMS, 피크 27A RMS, 스위칭 10~20kHz.
- **핵심부품**: MCU STM32F767, 게이트드라이버 UCC27211D×3, MOSFET SQJQ466(E), 홀버퍼 SN74LVC3G17, 벅IC TPS54360, LDO LM2940(5V)/LM1117(3.3V). 상보PWM=TIM1_CH1~3 + CH1N~3N.
- MCU 주변: 전원핀 근처 세라믹캡, LED(Vf2.85V·5mA이하), 홀(풀업+바이패스+슈미트버퍼), 쓰로틀(5V→분압 3.20V, R7=2.2k/R12=3.9k), NTC(온도↑저항↓, MOSFET_NTC=NTC/(R13+NTC)·3.3V), 크리스털.
- **벅(TPS54360, 36V→12V)**: fsw≈544kHz(RT178k), L=33µH(Lmin≈29µH, KIND0.3), Iripple≈0.58A, IL_peak2.58A, Cout 22µF×2+100nF, 피드백 FB≈0.8V(R57 8.45k/R53), 다이오드 B560C, 보상 위상여유≈30°.
- **게이트드라이버(UCC27211)/MOSFET(SQJQ466)**: Vds≥60V(입력42V), MOSFET온도 T=Ta+ID²·Ron·RthJA(25A→118.75°C). 부트스트랩(하단On시 부트캡 11.3V충전→상단Vgs). RG On10Ω/Off5Ω 분리. **Self turn-on 방지 G-S 1nF캡**. 풀다운저항. 션트 ±35A 차동증폭 22배 1.65V오프셋(35A→3.19V), LPF fLPF≈72.3kHz. 스너버.

## 주차 배분
- 5주차: 모터종류·DC원리·BLDC(홀/6-step/전기각)·속도계산·전류측정
- 6주차: 인버터(하프브리지/데드타임/PWM)·DC제어·BLDC제어(유니폴라)
- 7주차: 제어공학 전체(라플라스/Bode/PI/GM·PM)
- 12주차: 인버터 하드웨어 설계(사양서/MCU주변/벅/게이트드라이버) — 6·7주차 이론을 부품값으로 통합
