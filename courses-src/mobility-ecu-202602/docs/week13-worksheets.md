# 13주차 배포용 워크시트

진행 대본과 준비 체크리스트는 [13주차 운영 키트](week13-kit.md)에 있다.

| 워크시트 | 인쇄 부수 | 사용 시점 |
|---|---|---|
| AA. 배치 순서와 net class 설계 | 수강생 수 | 40~85분 |
| AB. DRC 체크리스트와 릴리스 패키지 | 팀 수 + 2 | 85~180분 |

> ⚠️ 워크시트 AA의 **배치 순서와 net class 표**는 14주차 노이즈 분석의 대상이 된다.
