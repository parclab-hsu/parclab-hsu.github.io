# 14주차 운영 키트 — PCB 노이즈, 그라운드, 파워 배선

### 교안 정보

| 항목 | 내용 |
|---|---|
| 교과목 | 모빌리티 전자제어유닛 실습 (3학점 · 전공) |
| 대상 | 미래모빌리티학과 3~4학년 |
| 차시 | 14주차 / 15주차 · 180분 |
| 강의실 | Physical AI 실습실 |
| 관련 자료 | 상세 강의자료 14번 · 과제집 19번 · 배포용 워크시트 AC·AD |

### 학습목표

이 시간이 끝났을 때 학생은 다음을 수행할 수 있다.

1. 전도성, 유도성, 용량성 노이즈를 구분한다.
2. 전류 리턴 경로와 그라운드 설계의 중요성을 설명한다.
3. 3상 인버터 PCB의 노이즈 리스크를 찾고 개선안을 제시한다.

### 핵심 질문

- 전류는 신호선으로만 흐르는가, 리턴 경로도 필요한가?
- ADC 값이 흔들리는 원인은 소프트웨어만의 문제인가?
- 파워 그라운드와 아날로그 그라운드를 무조건 분리하면 좋은가?

### 지도 중점

**전류는 반드시 돌아온다.** 신호선만 보고 그라운드를 "그냥 0V"로 여기면 문제가 보이지 않는다. 이 주차의 목표는 노이즈 용어 암기가 아니라 **리턴 경로를 그려서 원인을 좁히는 절차**다.

> 📌 **13주차에 그린 배치가 오늘의 분석 대상이다.** 워크시트 AA(배치 순서·net class)와 PCB 초안을 가져오게 한다.

> ⚠️ 10주차에 "ADC 값이 튄다"를 소프트웨어 문제로 다뤘다면, 오늘은 **같은 증상의 배선 원인**을 다룬다. 두 주차를 연결해 설명한다.

### 1. 180분 진행 대본

#### 블록 1 · 0~45분 — source–path–victim과 리턴 경로

**목표** — 노이즈를 **세 부분으로 쪼개는 습관**을 만든다.

1. (5분) **13주차 피드백.**

   > 🗣️ "지난주에 배치를 잘했다고 생각했죠? 오늘 그 배치를 **노이즈 관점에서 다시** 봅니다."

2. (13분) **source–path–victim 모델.**

   > ✍️ 판서
   > ```text
   > source(빠른 dv/dt·di/dt) → path(공통 임피던스·기생 C/L) → victim(ADC·Hall·UART)
   > ```

   > 🗣️ "대책을 말할 때 **셋 중 어디에 적용하는지**를 반드시 밝히세요. '노이즈를 줄인다'는 대책이 아닙니다."

   | 적용 위치 | 대책 예 |
   |---|---|
   | source | 게이트 저항 증가, 스너버 |
   | path | 루프 면적 축소, 기준면 연속성, 이격 |
   | victim | 차동 수신, RC 필터, 슈미트 버퍼 |

3. (15분) **리턴 경로 — 이 주차의 핵심.**

   > 🗣️ "전류가 신호선으로 갔습니다. **어디로 돌아옵니까?** 고주파에서는 신호선 **바로 아래** 기준면으로 돌아옵니다. 가장 인덕턴스가 작은 길이니까요."

   > ⚠️ **GND 면을 함부로 쪼개면** 리턴이 우회해서 루프가 오히려 커진다. "분리하면 좋다"는 오해를 여기서 깬다.

   > ✍️ 판서: `Vnoise = I × Zcommon` — 큰 전류와 작은 신호가 같은 GND를 공유하면 센서 기준전압에 노이즈가 더해진다

4. (12분) **EMC로 확장.**

   | 구분 | 내용 |
   |---|---|
   | emission | 내 보드가 내보내는 것 |
   | immunity | 밖에서 들어오는 것을 견디는 능력 |
   | 각각 | 전도(conducted, 전원·신호선) / 방사(radiated, 공간) |

   설계 단계에서 판단할 4가지를 짚는다.

   - **스위칭 루프 면적이 곧 방사 안테나 면적**이다. 가장 먼저 줄인다
   - 배터리 전원선은 전도 노이즈의 주 경로 → **입력 필터 자리를 미리 남긴다**
   - 모터 3상 케이블은 길고 dv/dt가 크다 → 꼬거나 차폐, **홀·통신 케이블과 나란히 묶지 않는다**
   - 대책을 나중에 붙이려면 자리가 필요하다 → **필터·스너버·페라이트 자리를 두고 안 쓰면 0Ω으로 채운다**

> ✅ **이 블록이 끝났을 때** — 학생이 "전류가 어디로 돌아오는지"를 먼저 묻는 상태.

#### 블록 2 · 45~90분 — PCB 경로 분석 (활동 1·2)

**목표** — 자기 팀 PCB에 **경로를 색으로 그리게** 한다.

1. (25분) **활동 1 — 노이즈 경로 표시** (워크시트 AC 상단)

   자기 팀 PCB 초안(또는 레퍼런스 보드 레이어 이미지)에 다섯 경로를 색으로 그린다.

   | 경로 | 확인할 것 |
   |---|---|
   | 고전류 스위칭 루프 | 면적이 얼마나 되는가 |
   | 게이트 구동 루프 | driver–gate–source가 짧은가 |
   | ADC 전류 센싱 경로 | 전력 패드와 분리됐는가 |
   | MCU 디지털 GND | 기준면이 연속인가 |
   | 아날로그 센서 GND | 파워 전류와 어디서 합류하는가 |

   > 🗣️ "스위칭 루프를 그렸으면 **그 면적을 대충이라도 재세요.** cm² 단위 숫자가 나와야 개선 전후를 비교할 수 있습니다."

2. (20분) **활동 2 — 잘못된 배치 찾기** (워크시트 AC 중단)

   전형적인 네 가지를 제시하고 **자기 PCB에 해당하는지** 확인시킨다.

   | 문제 | 왜 문제인가 |
   |---|---|
   | DC link capacitor가 MOSFET에서 멀다 | 스위칭 루프 면적이 커진다 |
   | 션트 감지선이 파워선 옆을 길게 지난다 | 용량성·유도성 결합 |
   | 게이트 신호가 모터 phase와 평행하게 길다 | 크로스토크, 오동작 턴온 |
   | MCU 아래 ground plane이 끊겼다 | 리턴 경로 우회, 루프 확대 |

   > 🗣️ "이 네 가지 중 하나도 없다고요? **다시 보세요.** 처음 그린 보드에 하나도 없는 경우는 드뭅니다."

#### 블록 3 · 90~155분 — A/B 실험 (추가 실습)

> ⚠️ **6주차 계측 안전 규칙을 그대로 적용한다.** 접지형 스코프 GND를 스위치 노드에 물리지 않는다. 고측은 차동 프로브만.

**목표** — 대책의 **효과와 부작용을 함께** 재게 한다.

1. (10분) **기준값 측정.** PWM off 상태에서 ADC 분산과 UART 오류를 먼저 잰다.

   > 🗣️ "개선 전 값이 없으면 **개선했다는 말을 못 합니다.** 기준값부터 잡습니다."

2. (30분) **A/B 실험 — 한 요소만 바꾼다** (워크시트 AD)

   게이트 저항 10Ω → 22Ω처럼 **한 가지만** 변경하고 네 항목을 잰다.

   | 측정 항목 | A: Rg 10Ω | B: Rg 22Ω | 판단 |
   |---|---|---|---|
   | Switch node overshoot | 41V | 31V | Vds 정격 대비 여유 개선 |
   | ADC 전류값 표준편차 | 12 LSB | 5 LSB | 개선 |
   | MOSFET 온도(10분) | 62°C | 69°C | **악화**, 스위칭 손실 증가 |
   | 효율(동일 부하) | 89.1% | 88.6% | 소폭 악화 |

   > 🗣️ "B가 좋아 보이죠. 그런데 **온도가 7도 올랐습니다.** 이게 부작용입니다. 부작용을 안 적으면 보고서가 아닙니다."

   채택 판단까지 시키고 **조건**을 달게 한다.

   > 예: **B 채택.** 온도 7°C 상승은 Tj 여유 안에 있고 overshoot 10V 감소가 더 중요하다. 단 **방열 면적을 늘리고 장시간 부하 시험에서 온도를 재확인**한다.

3. (15분) **duty 단계별 측정.** 저 duty → 중간 → 최대 허용 duty에서 같은 항목을 기록해 **duty에 따라 노이즈가 어떻게 변하는지** 보게 한다.

4. (10분) **대책의 trade-off 정리.**

   | 대책 | 얻는 것 | 잃는 것 |
   |---|---|---|
   | 게이트 저항 증가 | ringing·EMI 감소 | 스위칭 손실 증가 |
   | RC 스너버 | overshoot 감소 | 손실 추가, 부품 발열 |
   | 공통모드 초크 | 전도 노이즈 감소 | 포화·공진·누설전류 검토 필요 |
   | 필터 커패시터 | 노이즈 흡수 | 누설전류, 공진 |

**교수는 돌아다니며 두 가지만 확인한다**
- **한 번에 한 요소만** 바꿨는가 (두 개를 동시에 바꾸면 원인을 모른다)
- **부작용 항목(온도·효율)을 함께** 쟀는가

> ✅ **이 블록이 끝났을 때** — 각 팀이 효과와 부작용이 함께 적힌 A/B 표를 가진 상태.

#### 블록 4 · 155~180분 — 개선안 작성과 과제

1. (12분) **활동 3 — 개선안 5요소 형식** (워크시트 AC 하단)

   > ✍️ 판서
   > ```text
   > 문제:
   > 원인:   ← source / path / victim 중 어디인지 밝힌다
   > 영향:   ← 숫자로
   > 개선:
   > 검증:   ← 어떻게 확인할 것인가
   > ```

   예시를 함께 채운다.

   ```text
   문제: duty 50% 이상에서 ADC 전류값 분산 증가, UART 문자 깨짐
   원인: 션트 감지선이 phase 트레이스와 12mm 평행 주행, 공통 GND 경유 (path)
   영향: 과전류 임계 오판정 가능 (허위 트립 2회/10분)
   개선: Kelvin 차동쌍으로 재배선, 기준면 연속 구간으로 이동
   검증: 동일 duty·부하에서 ADC 표준편차와 트립 횟수 비교
   ```

   > 🗣️ "**영향을 숫자로** 쓰세요. '노이즈가 있다'가 아니라 '허위 트립이 10분에 2번'이라고요."

2. (5분) **형성평가 3문항**

   1. 분리된 GND plane이 오히려 EMI를 키울 수 있는 경우를 설명한다.
   2. 게이트 저항을 키운 뒤 반드시 함께 측정할 두 가지는?
   3. ADC 잡음 문제를 source–path–victim으로 각각 하나씩 분류한다.

3. (5분) **과제 안내**

   > 14주차 과제 — 노이즈·그라운드 개선 보고서
   > 제출물: 문제·원인·영향·개선·검증 형식의 **개선안 3건** / A/B 실험 결과
   > 형식: PDF 2~3장 + 파형 캡처 · 파일명 `W14_팀명_이름.pdf`
   > 마감: 다음 주 수업 시작 전 · 1일 지각당 20% 감점
   > 배점 5점 — 원인을 source·path·victim으로 분리 2 / A/B가 동일 조건 1 / 부작용 함께 기록 1 / 개선안이 제조·검증 가능 1

4. (3분) **다음 주 예고**

### 2. 판서 목록

1. `source → path → victim` 3분할과 대책 위치
2. 리턴 경로는 **신호선 바로 아래** 기준면
3. `Vnoise = I × Zcommon`
4. EMC 4분면 (emission/immunity × 전도/방사)
5. 스위칭 루프 면적 = 방사 안테나 면적
6. A/B 실험 4항목 (overshoot·ADC 분산·온도·효율)
7. 개선안 5요소 (문제·원인·영향·개선·검증)

### 3. 자주 나오는 질문과 답

| 학생 질문 | 답 |
|---|---|
| "GND를 나누면 노이즈가 줄지 않나요?" | 함부로 쪼개면 **리턴이 우회해 루프가 커진다.** 기능별 전류가 어디서 합류하는지 먼저 그린다 |
| "ADC가 튀는 건 소프트웨어로 평균 내면 되지 않나요?" | 평균은 증상을 가릴 뿐이다. **원인이 배선이면 배선을 고쳐야** 한다 |
| "게이트 저항을 키우면 다 해결되나요?" | ringing은 줄지만 **스위칭 손실과 온도가 오른다.** 둘을 함께 재야 판단할 수 있다 |
| "루프 면적을 어떻게 재나요?" | 정확할 필요 없다. **대략의 cm²**면 개선 전후 비교가 된다 |
| "차폐를 하면 되지 않나요?" | 차폐는 마지막 수단이다. **루프 면적을 줄이는 것이 먼저**이고 비용도 싸다 |
| "우리 보드에는 문제가 없는 것 같은데요?" | 처음 그린 보드에 문제가 하나도 없는 경우는 드물다. **네 가지 전형 사례**를 하나씩 대조해 보라 |

### 4. 시간이 남거나 모자랄 때

| 상황 | 대응 |
|---|---|
| 15분 이상 남음 | 레퍼런스 보드 6층을 하나씩 겹쳐 보며 스위칭 루프가 어느 층에서 닫히는지 추적 |
| 10분 남음 | 스너버를 추가해 overshoot 변화를 보여 준다 |
| 15분 부족 | A/B 실험을 **교수 시연 1건**으로 대체하고 학생은 표만 기록 |
| 30분 이상 부족 | A/B를 과제로 넘긴다. **활동 1(노이즈 경로 표시)은 반드시 그 자리에서** — 개선안 작성의 근거다 |

### 5. 안전 점검

**6주차 계측 안전 규칙이 그대로 적용된다.** 이번에는 부품 교체가 추가된다.

- 🔴 **접지형 스코프 GND를 스위치 노드·고측 소스에 연결하지 않는다.** DC 링크가 단락된다
- 🔴 **고측 게이트는 차동 프로브로만** 측정한다
- 부품을 교체할 때는 **전원을 끄고 DC 링크가 방전된 뒤** 작업한다. 커패시터에 전하가 남아 있다
- 납땜 시 인두 온도와 환기를 확인한다
- 프로브 loop를 짧게 하고, 캡처에 **프로브 종류·배율·대역폭 제한·부하 조건**을 기록한다
- 측정기의 전압·CAT·대역폭 정격을 확인한다
- 연속 운전 후 MOSFET은 뜨겁다. **온도는 비접촉으로** 측정한다
