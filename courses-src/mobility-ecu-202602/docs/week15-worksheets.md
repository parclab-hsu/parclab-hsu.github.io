# 15주차 배포용 워크시트

진행 대본과 평가표는 [15주차 운영 키트](week15-kit.md)에 있다.

| 워크시트 | 인쇄 부수 | 사용 시점 |
|---|---|---|
| AE. 요구사항 추적표와 시험 명세 | 팀 수 + 2 | 발표 준비·정리 |
| AF. pre-flight gate와 시연 기록 | 팀 수 + 2 | 시연 |

> 🔴 워크시트 AF는 **시연 전 교수 서명**이 필요하다. 서명이 없으면 시연할 수 없다. 종료 시 전량 회수한다.

**판정 기준**

| 판정 | 의미 |
|---|---|
| PASS | 시험했고 기준을 만족 |
| PARTIAL | 시험했고 일부만 만족 (수치를 적는다) |
| **FAIL** | 시험했으나 기준 미달 |
| **BLOCKED** | 시험 자체를 못 함 (사유를 적는다) |

> FAIL과 BLOCKED가 있는 표가 좋은 표다. **전부 PASS인 표는 기준이 느슨했는지 의심받는다.**

### 1. 단계적 시험 기록

> 아래 단계의 증거 없이 위 단계로 올라가지 않는다.

| 단계 | 조건 | 통과 기준 | 결과 | 실측값·비고 |
|---|---|---|---|---|
| 1 벤치 | 모터 분리, PWM만 | 파형·dead time 정상, fault 차단 | PASS / FAIL | |
| 2 무부하 회전 | 바퀴 공중 부양 | 좌우 방향 일치, RPM 추종 | PASS / FAIL | |
| 3 차동 동작 | 바퀴 공중 부양 | v/ω가 좌우 RPM으로 분배 | PASS / FAIL | |
| 4 저속 직진 | 지면, duty 제한 | 5m 경로 이탈 허용치 이내 | PASS / FAIL | 편차 ______ m |
| 5 선회·제자리 회전 | 지면 | 최소 회전반경 달성 | PASS / FAIL | 반경 ______ m |
| 6 경사·험지 | 목표 등판각부터 상승 | 실패 지점 기록 | PASS / FAIL | 실패각 ______ ° |

> 🔴 **4단계부터 지면 주행이다.** 비상차단 담당은 로버 진행 방향 **반대편**에 선다.
