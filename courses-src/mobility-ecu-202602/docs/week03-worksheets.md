### 3. 도통 손실 계산

교수가 지정한 조건을 적는다.

| 항목 | 값 |
|---|---|
| 상전류 `I` | A |
| `Rds(on)` @25°C | mΩ |
| 적용할 온도 계수 | 배 |
| 도통률 (한 소자가 켜져 있는 비율) | % |

```text
Rhot  = Rds(on) × 온도계수 =            ×          =            mΩ

Pcond = I² × Rhot × 도통률 =            ×          ×          =            W
```

### 4. 스위칭·게이트 손실 계산

| 항목 | 값 |
|---|---|
| DC 링크 전압 `Vds` | V |
| 스위칭 주파수 `fsw` | kHz |
| 게이트 구동 전압 `Vgate` | V |

```text
Psw   = 0.5 × Vds × Id × (tr + tf) × fsw

      = 0.5 ×      ×      × (     +     ) ×          =            W

```
