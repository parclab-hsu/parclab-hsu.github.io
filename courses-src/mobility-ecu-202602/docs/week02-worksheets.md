## 워크시트 E · LED 저항과 배터리 분압기 계산

**모빌리티 전자제어유닛 실습 · 2주차** &nbsp;&nbsp; 팀명 ____________ 이름 ____________

### 1. LED 전류 제한 저항

교수가 지정한 조건을 적는다.

| 항목 | 값 |
|---|---|
| 공급 전압 `Vs` | V |
| LED 순방향 전압 `Vf` | V |
| 목표 전류 `If` | mA |

**계산**

```text
R = (Vs − Vf) / If  =  (        −        ) /         =            Ω

P = If² × R         =                             =            mW
```

**표준값 선택** — 계산값에 가장 가까운 E24 표준값을 고른다.

| 항목 | 값 |
|---|---|
| 선택한 표준 저항 | Ω |
| 그때 실제 전류 `If' = (Vs − Vf) / R` | mA |
| 목표 대비 차이 | % |
| 선택한 저항의 정격 전력 | W |
| 정격 대비 여유율 | 배 |

> ⚠️ 계산값 그대로는 살 수 없다. **표준값으로 바꾼 뒤 실제 전류를 다시 계산**해야 설계가 끝난다.

### 2. 배터리 전압 분배기

**조건** — 배터리 최대 42V, MCU ADC 입력 최대 3.3V, 목표 최대 입력 **2.8V 이하**

```text
Vadc = Vbat × Rbottom / (Rtop + Rbottom)
```

| 항목 | 값 |
|---|---|
| `Rtop` | Ω |
| `Rbottom` | Ω |
| `Vadc,max` (42V일 때) | V |
| 상시 소비 전류 `Idivider` | µA |
| `Rtop` 소비 전력 | mW |

### 3. 세 가지 되묻기 — 반드시 채운다

| 질문 | 우리 팀의 답 |
|---|---|
| 저항값을 **너무 작게** 하면 무엇이 문제인가 | |
| 저항값을 **너무 크게** 하면 무엇이 문제인가 | |
| ADC 샘플링과 RC 필터는 왜 연결되는가 | |

### 4. 필터 계산

`R = 10kΩ`, `C = 100nF`일 때

```text

τ  = R × C      =                ms
5τ 후 도달률    =                %
```
