## 오늘의 실습 미션

- 미션 1: 팀 회로도에서 net label 이름이 모호한 부분을 찾아 수정한다.
- 미션 2: 전력부와 신호부 부품을 다른 영역으로 재배치해 전류 루프를 줄인다.
- 미션 3: 전원, PWM, UART, ADC 테스트포인트를 최소 하나씩 추가한다.
- 사용할 자료: `pcb-design-lecture-v0.1.pdf`
- 제출 증거: 계산식, 캡처, 사진, 로그 중 `회로도와 PCB 배치`를 입증하는 자료 하나 이상.

## 실습 전 확인

### 장비와 배선
회로도·PCB 설계 기초 실습 전에는 전원, 커넥터 방향, 공통 그라운드, 시리얼 포트를 오늘 주제에 맞춰 확인한다.

### 예측값 작성
보드에 손대기 전에 `회로도와 PCB 배치`와 관련된 예상 전압, 전류, 주파수, RPM, 또는 로그 형식을 먼저 쓴다.

### 안전 조건
실패했을 때 어떤 출력을 즉시 끄고 어떤 로그를 남길지 팀별로 한 줄씩 합의한다.

## 코칭 질문

1. 회로도와 PCB 배치에서 지금 조작하는 값은 입력인가, 처리 결과인가, 보호 조건인가?
2. 팀 회로도에서 net label 이름이 모호한 부분을 찾아 수정한다. 결과가 예상과 다르면 어떤 측정점부터 확인할 것인가?
3. 전력부와 신호부 부품을 다른 영역으로 재배치해 전류 루프를 줄인다. 과정에서 하드웨어 원인과 펌웨어 원인을 어떻게 분리할 것인가?
4. 전원, PWM, UART, ADC 테스트포인트를 최소 하나씩 추가한다. 결과를 다음 주차 설계에 어떻게 반영할 것인가?

## 강의자료-실습 통합 절차

### 수업 전 5분 준비

- 메인 페이지의 핵심 도해와 `figures/attachment-previews/pcb-design-p01.png` 이미지를 같은 화면에 열어 둔다.
- 팀별로 오늘 확인할 입력 조건, 예상값, 위험 조건을 한 줄씩 적게 한다.
- 측정 장비가 없거나 시간이 부족한 팀은 첨부자료 이미지 위에 신호 흐름을 표시하는 대체 활동을 수행한다.

### 실습 중 코칭 기준

| 관찰 상황 | 교수자 질문 | 기대되는 학생 반응 |
|---|---|---|
| 값은 나왔지만 근거가 없음 | 어떤 조건에서 측정했는가? | 전압, 주파수, 부하, 코드 버전을 함께 기록한다. |
| 회로 문제와 코드 문제가 섞임 | 하드웨어만 바꿔도 증상이 남는가? | 전원·배선·공통 GND를 먼저 분리한다. |
| 결과가 예상과 다름 | 예상식과 실제 로그 중 어느 쪽을 먼저 의심할까? | 단위, 기준값, 측정 위치를 재확인한다. |

### 실습 후 정리

회로도 한 블록을 골라 전원 루프, 신호 루프, 디버그 포인트를 PCB 위에 색으로 표시한다. 제출물에는 원본 사진이나 로그뿐 아니라, 왜 그 증거가 `회로도와 PCB 배치`를 설명하는지 한 문장 해석을 붙인다.

## 팀 활동 절차

1. 첨부자료 이미지에 `회로도와 PCB 배치` 위치를 표시한다.
2. 예측값을 적고 교수자에게 단위와 기준값을 확인받는다.
3. 실습을 수행하되 위험한 전원 조건이나 무부하 고속 회전을 피한다.
4. 결과 파일명을 `week13_team_result` 형식으로 저장한다.
5. 실패 원인을 하드웨어, 펌웨어, 측정 조건 중 하나로 먼저 분류한다.

## 평가 루브릭

### A 수준
회로도와 PCB가 각각 답해야 하는 질문을 구분하게 한다. 또한 실험 증거와 `회로도와 PCB 배치`의 시스템 위치를 함께 설명한다.

### B 수준
전력 트레이스 폭을 결정할 때 고려할 요소를 쓰게 한다. 다만 최악 조건이나 안전 여유 설명이 일부 부족하다.

### C 수준
테스트포인트 네 개의 위치와 측정 목적을 제안하게 한다. 하지만 재현 절차나 측정 조건이 빠져 있다.

### D 수준
회로도·PCB 설계 기초의 실행 여부만 적고 수치, 그림, 로그 증거가 없다.

## 보강 과제

- 커넥터 방향을 고려하지 않으면 조립 후 케이블이 모터와 간섭할 수 있다.
- 전력 트레이스가 너무 얇으면 전압강하와 발열이 생긴다.
- 실크가 없으면 현장 수리에서 U/V/W와 센서 커넥터를 혼동한다.
- AI 도구를 사용했다면 질문, 답변 요약, 사람이 검증한 항목을 함께 제출한다.
