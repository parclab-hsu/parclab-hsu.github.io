# 5주차 배포용 워크시트

진행 대본과 준비 체크리스트는 [5주차 운영 키트](week05-kit.md)에 있다.

| 워크시트 | 인쇄 부수 | 사용 시점 |
|---|---|---|
| K. 주행 요구 역산과 차동 구동 | 수강생 수 | 45~100분 |
| L. 모터 후보 대조표와 홀센서 | 팀 수 + 2 | 100~155분 |

> ⚠️ 워크시트 L의 **홀 상태 순서표**는 11주차 정류 테이블의 원본이 된다. 반드시 회수하거나 사진을 남긴다.

### 5. 차동 구동 계산

```text
v  = (vR + vL)/2          vR = v + ω × W/2
ω  = (vR − vL)/W          vL = v − ω × W/2
R  = v / ω   (ω ≠ 0)      rpm = 60 × v_wheel / (2π × r)
```

### 3. 역기전력 상수 `Ke` 실측

모터 축을 손으로 일정하게 돌리며 상간 전압을 측정한다. **전원은 끈 상태로 한다.**

| 항목 | 값 |
|---|---|
| 측정한 상 (예: U-V) | |
| 관측 전압 `E` | V |
| 대략의 회전 속도 | rpm |
| 각속도 `ω = 2π × rpm / 60` | rad/s |
| `Ke = E / ω` | V·s/rad |
| 데이터시트 값 (있다면) | |
| 차이가 난 이유 추측 | |

> 모터는 **발전기이기도 하다.** 이 성질이 6주차의 회생 과전압, 15주차의 회생 제동으로 이어진다.
