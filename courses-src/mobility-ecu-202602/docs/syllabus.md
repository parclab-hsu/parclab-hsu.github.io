# 강의계획서 (Syllabus)

**모빌리티 전자제어유닛 — 우주 로버 대회 참가 프로젝트**
한성대학교 미래모빌리티학과 · 3학년 중심 15주 전공 실습(주 3시간) · 담당: **이경복** · PARC Lab

## 1. 교과목 개요

본 교과목은 **전자회로 → 모터 제어 → 임베디드 펌웨어 → PCB 설계 → 시스템 통합**에 이르는 모빌리티 전자제어유닛(ECU)의 전 과정을, **‘우주 로버 대회 참가’라는 하나의 프로젝트 목표** 아래 실전 중심으로 학습한다.

학생들은 팀을 이루어 **월면(月面) 험지주행·경사극복 미션**을 수행하는 소형 자작 로버의 구동 제어보드를 직접 설계·제작하며, 요구사항 정의부터 회로설계·펌웨어·PCB·통합시험까지 산업 현장의 개발 프로세스를 그대로 경험한다.

### 학습 목표

1. 모빌리티 ECU의 하드웨어/펌웨어 구조를 이해하고 전 개발 과정을 수행할 수 있다.
2. BLDC/DC 모터 구동을 위한 3상 인버터 회로를 설계·제작할 수 있다.
3. STM32 마이크로컨트롤러를 **레지스터 수준**에서 제어하는 임베디드 펌웨어를 구현할 수 있다.
4. 다층 PCB를 설계하고 제어보드를 완성해 로버 섀시와 통합할 수 있다.
5. 월면 험지주행 미션 요구사항을 정의하고, 등판각·주행성능 지표로 검증할 수 있다.

### 선수 과목 및 대상

- **선수 권장**: 모빌리티 전기전자회로, 모빌리티 프로그래밍 실습(C언어)
- **대상**: 미래모빌리티학과 3학년 중심(4학년 심화 수강 가능)

## 2. 로버 대회 미션 시나리오

월면 모사 시험장(경사·자갈·모래 지형)에서 자작 로버가 지정 경로를 완주하고 목표 경사구간을 극복하는 **험지주행 경진** 형태로 운영한다.

| 미션 | 내용 | 채점 |
|---|---|---|
| **A — 평지 완주** | 지정 코스를 이탈 없이 완주 | 기본 구동·조향 검증 |
| **B — 경사 극복** | 목표 경사각(예: 15° → 25°) 등판 | 실패 지점 각도로 채점 |
| **C — 험지 통과** | 자갈·모래 구간 통과 | 통과 시간·안정성 평가 |
| **공학 평가** | 회로도·PCB·펌웨어 완성도 및 설계 문서(HSI) 심사 | 설계 품질 |

## 3. 주차별 강의 계획 (15주)

각 주차는 **이론 강의(1.5h) + 실습/프로젝트(1.5h)**로 구성한다. 8주차 중간 설계 리뷰를 먼저 거친 뒤 9~11주차에서 STM32와 BLDC 구동 펌웨어를 통합한다.

| 주차 | 모듈 | 핵심 학습내용 | 로버 대회 연계 실습 |
|---:|---|---|---|
| 1 | OT·미션 정의 | ECU의 정의와 역할, V-모델 개발 흐름, ECU 시간·자원 예산, 기능/성능/안전 요구사항 구분 | 팀 편성·역할분담, 로버 ECU 입출력 분해, 요구사항 3개와 미니 FMEA 작성 |
| 2 | 실전 회로 (1) | R·L·C의 실제 특성과 데이터시트 정격·공차, RC 차단주파수와 시정수, ADC 소스 임피던스, 최악조건 설계 | LED 저항·배터리 전압 분배기 계산, 계측으로 공차·gain/offset 확인 |
| 3 | 실전 회로 (2) | 다이오드·BJT·MOSFET 동작, Rds(on)·Vgs(th)·Qg·SOA, 고온 도통손실·스위칭·게이트 구동 손실, 열저항 | MOSFET 후보 3종 선정표 작성, 데드타임 사고 시 전류 경로 분석 |
| 4 | 전원 회로 | 전원 트리, 리니어/벅/부스트 컨버터, 전력 예산과 효율, 입력 보호·돌입전류, 배터리 내부저항과 부하 시 전압 강하 | 로버 ECU 전원 트리·전류 예산 작성, LDO 발열 계산, 전원 리플·부하 과도 계측 |
| 5 | DC·BLDC 모터 | DC/BLDC 구조와 역기전력, 주행저항(경사·구름·가속) 역산, 감속기 효율, Kt/Ke와 전류, 홀센서 6상태, 차동 구동 운동학 | 구동륜 모터 사양 산정(토크·RPM), 요구사항–부품 추적표, 최소 회전반경·제자리 회전 요구 산정 |
| 6 | 인버터·PWM 이론 | 하프/풀브리지와 3상 인버터, 6-step 전류 경로, center-aligned PWM, 데드타임·부트스트랩 제약, 회생과 DC 링크 | 6-step 상 패턴 표 작성, 파형 판독표와 안전 측정 절차 설계 |
| 7 | 제어공학·PI 속도제어 | open/closed loop, P·I·PI 특성, 이산 PI 구현과 샘플 주기, anti-windup, RPM 필터 지연, 좌우 2채널 제어 | Teleplot 속도 응답 관찰, Kp·Ki 후보별 상승시간·overshoot·정상상태 오차 정량 비교 |
| 8 | **중간 설계 리뷰** | 요구사항 계층과 양방향 추적성, HSI를 인터페이스 계약으로 작성, 시스템 상태기계, 리뷰 결함 등급, CubeMX Pinout 검증 | 팀별 1차 설계 발표(요구사항·블록도·HSI·리스크 3개), 결함 분류 후 수정본 제출 |
| 9 | STM32 펌웨어 (1) | 메모리맵과 주변장치 레지스터, GPIO MODER/ODR/BSRR과 원자적 접근, volatile의 한계, 클럭 트리, startup·벡터 테이블 | MCU 보드 브링업, LED·스위치 레지스터 직접 제어, CubeMX·HAL·레지스터 3종 결과 비교 |

## 4. 평가 방법

| 평가 항목 | 비중 | 세부 내용 |
|---|---:|---|
| 출석 및 참여 | 10% | 실습 참여, 안전 수칙 준수, 팀 활동 기여 |
| 주차별 실습 과제 | 25% | 회로 계산, STM32 코드, 측정 결과, 주차별 짧은 보고서 |
| 중간 설계 리뷰 | 20% | 요구사항, HSI, 시스템 블록도, 인버터·전원 회로 이해 |
| 최종 프로젝트 문서 | 25% | 회로, PCB, 펌웨어, 검증 계획·결과의 연결성 |
| 최종 발표 및 시연 | 20% | 로버/모터 구동 시나리오 설명, 제한 조건 시연, 질의응답 |

!!! note "동작 실패도 평가 대상"
    실제 모터 구동을 완료하지 못한 팀도 모듈 테스트 증거와 다음 검증 계획을 제시하면 평가 대상으로 인정한다. 동작 성공 여부보다 요구사항·측정 증거·실패 원인 분석의 연결성을 우선 평가한다. 팀 산출물 점수에는 개인 기여도를 반영한다.

### 학습성과-평가 매핑

| 학습성과 | 확인 방법 | 주요 증거 |
|---|---|---|
| ECU 하드웨어/펌웨어 구조 이해 | 실습 과제, 구두 질문 | 블록도, 신호 흐름 설명 |
| 모터 구동 회로 설계 | 중간 설계발표, 팀 프로젝트 | 인버터 회로도, 전원 트리, 보호회로 근거 |
| STM32 레지스터 제어 구현 | 실습 과제, 팀 프로젝트 | GPIO/EXTI/ADC/Timer/UART 코드와 로그 |
| PCB·HSI 설계 역량 | 중간 설계발표, 팀 프로젝트 | HSI 표, PCB 리뷰 체크리스트, 수정 전후 비교 |
| 로버 미션 검증 | 대회 미션 수행, 최종 발표 | 주행 영상, Teleplot/UART 로그, 실패 분석 |

## 5. 실습 환경 및 제공 자료

**하드웨어 / 소프트웨어**

- **MCU**: STM32F767 기반 개발보드 또는 실습 키트 (레지스터 직접 제어 중심, HAL은 비교 학습용)
- **구동부**: 12V급 소형 로버 구동 모터 + 한성대 보드
- **개발툴**: STM32CubeIDE, EasyEDA(회로/PCB), 로버 섀시 조립 키트

**제공 자료**

- 참조 스키매틱·PCB(거버)·펌웨어 소스·BOM (설계 baseline)
- HSI 요구사항 명세 템플릿, 설계 리뷰 체크리스트, 대회 채점 루브릭

## 6. 원 강의 대비 각색 포인트

본 계획서는 회로→모터제어→펌웨어→모터 회로→PCB→실전 구동을 기반으로, 다음과 같이 학과 특화·대회 형태로 각색하였다.

- 12V DC 모터 제어 → 12V급 **로버 구동용 좌우 휠 모터 제어**
- ‘로버 원격 주행’ 최종 목표 → **‘월면 험지주행·경사극복 미션’ 팀 프로젝트**로 전환
- 개인 제작 → **팀 기반 역할분담**(회로·펌웨어·PCB·통합)과 설계 리뷰 도입
- 실습 결과물을 **‘대회 미션 수행’이라는 명확한 성과 지표**로 평가하도록 재설계
