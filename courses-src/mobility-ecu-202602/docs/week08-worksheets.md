# 8주차 배포용 워크시트

진행 대본과 평가표는 [8주차 운영 키트](week08-kit.md)에 있다.

| 워크시트 | 인쇄 부수 | 사용 시점 |
|---|---|---|
| Q. 발표 팀 자가 점검과 제출 양식 | 팀 수 + 2 | 발표 준비 |
| R. 리뷰 결함 기록표 | **팀 수 × 팀 수** | 발표 내내 |

> ⚠️ 워크시트 R은 **팀마다 다른 팀 수만큼** 필요하다. 5팀이면 팀당 4장, 총 20장.
> 워크시트 R은 수업 종료 시 **전부 회수한다.** 리뷰 참여도 평가 대상이다.

## 워크시트 Q · 발표 팀 자가 점검과 제출 양식

**모빌리티 전자제어유닛 실습 · 8주차 중간 설계 리뷰** &nbsp;&nbsp; 팀명 ____________

### 0. 발표 전 자가 점검 — 발표 시작 전에 채운다

> 이 표에서 "아니오"가 있으면 **그 항목이 그대로 지적받는다.** 발표 전에 고칠 수 있으면 고친다.

| 점검 항목 | 예 / 아니오 |
|---|---|
| 모든 요구사항에 **수치와 단위**가 있는가 | |
| 모든 요구사항에 **검증 방법**이 적혀 있는가 | |
| "잘", "안정적으로", "빠르게" 같은 말이 남아 있지 않은가 | |
| HSI에 **정상 범위**가 있는가 (0~3.3V가 아니라 0.8~2.8V처럼) | |
| HSI에 **고장 판정 조건**이 있는가 | |
| HSI에 **리셋 중 핀 상태**가 있는가 | |
| 🔴 **부팅 중 게이트드라이버가 꺼져 있음**을 설명할 수 있는가 | |
| 🔴 **과전류 차단 경로**가 설계에 있는가 | |
| 블록도에 전원 경로와 신호 경로가 **구분**돼 있는가 | |
| 앞 주차 산출물(전력 예산·모터 사양·6-step·PI 게인)을 반영했는가 | |

> 🔴 표시 두 항목은 **Critical 판정 대상**이다. 발표에서 언급하지 않으면 교수가 직접 질문한다.
