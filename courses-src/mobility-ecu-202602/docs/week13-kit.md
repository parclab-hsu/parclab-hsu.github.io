# 13주차 운영 키트 — 회로도 작성과 PCB 설계 기초

### 교안 정보

| 항목 | 내용 |
|---|---|
| 교과목 | 모빌리티 전자제어유닛 실습 (3학점 · 전공) |
| 대상 | 미래모빌리티학과 3~4학년 |
| 차시 | 13주차 / 15주차 · 180분 |
| 강의실 | Physical AI 실습실 |
| 관련 자료 | 상세 강의자료 13번 · 과제집 19번 · 배포용 워크시트 AA·AB |

### 학습목표

이 시간이 끝났을 때 학생은 다음을 수행할 수 있다.

1. EasyEDA에서 회로도와 PCB 설계 흐름을 이해한다.
2. PCB 용어, 레이어, 트레이스 폭, 비아, 3W 룰을 설명한다.
3. 회로 기능을 이해한 뒤 PCB 배치와 배선을 검토한다.

### 핵심 질문

- 회로도가 맞으면 PCB도 자동으로 좋은가?
- 전류가 큰 경로는 왜 넓고 짧아야 하는가?
- 신호선과 파워선은 왜 같은 방식으로 배선하면 안 되는가?

### 지도 중점

회로도는 "무엇이 무엇과 연결되는가"만 말한다. PCB는 거기에 **길이·폭·거리·층**이라는 물리를 붙인다. 이 주차의 목표는 CAD 조작 숙달이 아니라 **전류가 돌아오는 길을 먼저 그리는 습관**이다.

> 📌 **12주차에 정한 게이트 루프와 션트 배선이 오늘 배치 순서를 결정한다.** 워크시트 Z(fault chain)를 가져오게 한다.

> ⚠️ 이 주차는 **CAD 실습 시간이 길다.** 프로그램 설치·계정 문제로 첫 30분이 날아가지 않도록 전날 확인한다.

### 1. 180분 진행 대본

#### 블록 1 · 0~40분 — 회로도 품질과 footprint 검증

**목표** — "PCB를 그리기 전에 회로도가 끝나 있어야 한다"를 납득시킨다.

1. (5분) **12주차 피드백.** NG 항목 조치 상황을 확인한다.

   > 🗣️ "지난주에 찾은 NG가 오늘 PCB에 반영돼야 합니다. **회로도를 안 고치고 PCB부터 그리면** 나중에 다 다시 합니다."

2. (12분) **설계 흐름 전체.**

   > ✍️ 판서
   > ```text
   > schematic → symbol/footprint → ERC → netlist
   >           → placement → routing → DRC → gerber → BOM
   > ```

   > 🗣️ "이 순서를 거꾸로 가면 어떻게 됩니까? 배치를 다 해 놓고 회로도를 고치면 **배치가 무너집니다.**"

3. (10분) **회로도 품질 기준 4가지.**

   | 기준 | 왜 필요한가 |
   |---|---|
   | 모든 전원 net에 **전압과 최대 전류** 표시 | 트레이스 폭의 근거가 된다 |
   | 커넥터 핀·신호 방향·정상 전압·test point 명시 | 조립·시험에서 쓰인다 |
   | 부품 값 + **허용오차·정격전압/전력·패키지** | 값만 맞고 정격이 모자란 사고를 막는다 |
   | unused pin·no-connect·부트스트랩·디버그 커넥터의 **의도** 표시 | 나중에 "이건 왜 있지?"를 없앤다 |

4. (13분) **symbol vs footprint — 가장 자주 나는 사고.**

   > 🗣️ "심볼이 맞아도 **풋프린트가 틀리면 부품이 안 붙습니다.** 그리고 이건 보드가 도착한 뒤에 알게 됩니다."

   확인 절차를 못 박는다.

   | 확인 항목 | 방법 |
   |---|---|
   | 핀 번호 ↔ 패드 번호 | 데이터시트 치수와 직접 대조 |
   | top-view / bottom-view 방향 | 데이터시트가 어느 쪽 기준인지 확인 |
   | MOSFET exposed pad | 패드가 실제로 있는가 |
   | 전해 커패시터 극성, 커넥터 1번 핀, 다이오드 캐소드 | **1:1 출력해서 실물 대조** |

   > ⚠️ **3D 모양이 맞아 보이는 것은 검증이 아니다.** 실제로 틀리는 곳은 거의 항상 핀 번호와 방향이다.

> ✅ **이 블록이 끝났을 때** — 학생이 "footprint는 실물과 1:1로 대조한다"를 절차로 아는 상태.

#### 블록 2 · 40~85분 — 배치 순서와 net class (활동 1·2)

**목표** — 배치를 **전류 경로 논리**로 설명하게 한다.

1. (20분) **활동 1 — 배치 우선순위** (워크시트 AA 상단)

   부품 목록을 주고 **순서를 정하고 이유를 쓰게** 한다.

   ```text
   전원 커넥터 / DC link capacitor / MOSFET bridge / gate driver
   shunt resistor / MCU / sensor connectors / UART connector
   ```

   모범 순서와 이유를 판서한다.

   ```text
   전원 커넥터 → DC 링크 커패시터 → MOSFET 브리지 → 게이트드라이버
              → 션트 → MCU → 센서 커넥터

   ① 고전류 루프(DC링크–브리지)를 가장 먼저 최소화
   ② 게이트 루프를 그 다음으로 짧게
   ③ MCU는 스위칭 노드에서 15mm 이상 이격
   ```

   > 🗣️ "왜 MCU가 마지막입니까? MCU는 **가장 시끄러운 곳에서 멀어야** 하기 때문입니다. 6주차에 본 스위칭 노드 링잉 기억나시죠."

2. (25분) **활동 2 — net class와 트레이스 폭** (워크시트 AA 하단)

   | Net class | 예 | 폭/규칙 | 근거 |
   |---|---|---|---|
   | High current | BAT+, PHASE_U/V/W | 2.5mm, 2oz 외층 | 10A, ΔT 20K, IPC 계산 + 여유 |
   | Switching | SW node, GATE | 0.5mm, 루프 최소 | 면적 최소화, 민감 신호와 이격 |
   | Analog sense | SHUNT_P/N, NTC | 0.3mm 차동쌍 | Kelvin, 리턴 경로 분리 |
   | Digital | UART, HALL | 0.25mm | 기준면 연속성 |

   > ⚠️ **트레이스 폭은 고정 규칙이 아니다.** 구리 두께·외층/내층·허용 온도상승·주변 동박·길이로 정한다. 같은 2mm라도 조건이 다르면 허용 전류가 다르다.

   IPC 계산기로 자기 조건의 폭을 구하게 하고, **왜 그 값인지 근거를 적게** 한다.

#### 블록 3 · 85~160분 — CAD 실습과 릴리스 (활동 3·추가 실습)

**목표** — 실제로 그려 보고 **DRC를 돌려** 결과를 해석하게 한다.

1. (15분) **활동 3 — EasyEDA 프로젝트 확인**

   제공 프로젝트를 열어 블록을 찾게 한다 — 전원 입력 커넥터, MCU, PWM 출력 경로, 게이트드라이버, MOSFET, 션트, 홀센서 커넥터.

   > 🗣️ "부품 이름으로 찾지 말고 **연결을 따라가며** 찾으세요. 12주차에 그린 fault chain이 여기 어디에 있는지 짚어 보세요."

2. (45분) **PCB 초안 작성.** LED 회로 또는 벅컨버터 회로로 시작한다.

   진행 중 교수가 강조할 것.

   | 단계 | 강조점 |
   |---|---|
   | 배치 | 활동 1의 순서를 **실제로 지키는가** |
   | 배선 | 고전류 먼저, 신호 나중 |
   | 3W 룰 | 민감 신호 사이 간격 |
   | 직각 배선 | 지양(제조·임피던스) |
   | 루프 면적 | 전원-부하-리턴을 눈으로 확인 |

3. (15분) **DRC 실행과 결과 해석** (워크시트 AB 상단)

   > 🗣️ "DRC 오류 0이 목표가 아닙니다. **경고가 왜 났는지 설명할 수 있는 것**이 목표입니다."

   경고를 무시할지 고칠지 **판단하고 근거를 적게** 한다.

   예: `오류 0, 경고 3 (실크 겹침 2, 테스트 포인트 간격 1) → 조립에 영향 없음, rev C에서 정리`

**교수는 돌아다니며 두 가지만 확인한다**
- 배치가 **전류 경로 논리**로 설명되는가 (예쁘게 놓았는지가 아니라)
- 트레이스 폭에 **계산 근거**가 있는가

> ✅ **이 블록이 끝났을 때** — 각 팀이 DRC를 통과했거나, 남은 경고의 처리 방침을 적은 상태.

#### 블록 4 · 160~180분 — 릴리스 패키지와 과제

1. (10분) **추가 실습 — 설계 릴리스 패키지** (워크시트 AB 하단)

   한 버전 번호로 묶어야 할 것을 확인시킨다.

   ```text
   schematic PDF / PCB source / Gerber / drill / BOM
   pick-and-place / net-class 규칙 / ERC·DRC 결과 / known issue 목록
   ```

   레퍼런스 보드의 실제 BOM·CPL을 열어 **읽는 법**을 보여 준다.

   | 파일 | 확인 항목 |
   |---|---|
   | BOM | `Quantity` 내림차순 → 보드 성격(10Ω 36개, 100nF 30개) / `Designator` 수와 일치 / `Manufacturer Part` 빈 줄 |
   | CPL | `Layer`가 전부 `T` → 단면 실장 / `Rotation` 0·90·180·270 / 좌표 원점과 단위 |

   > ⚠️ **CPL의 회전각이 틀리면 IC가 90도 돌아간 채 납땜된다.** 그리고 이건 조립 후에 알게 된다.

   > 🗣️ "제조 전에 **다른 팀이** pin-1, 극성, footprint, 미연결 net을 독립 검토합니다. 자기 실수는 자기 눈에 안 보입니다."

2. (5분) **형성평가 3문항**

   1. 3D 모델이 맞아 보여도 footprint 검증이 끝난 것이 아닌 이유는?
   2. 같은 2mm 트레이스라도 허용 전류가 달라지는 조건을 세 가지 제시한다.
   3. test point를 배치 초기에 고려해야 하는 이유는?

3. (3분) **과제 안내**

   > 13주차 과제 — PCB 초안과 배치 의도
   > 제출물: EasyEDA 회로도·PCB 초안 / 배치 의도 1장 / net class 표 / DRC 결과
   > 형식: PDF 2~3장 + 프로젝트 파일 · 파일명 `W13_팀명_이름.pdf`
   > 마감: 다음 주 수업 시작 전 · 1일 지각당 20% 감점
   > 배점 5점 — 배치 순서가 전류 경로 논리로 설명 2 / 트레이스 폭 계산 근거 1 / net class 구분 적용 1 / DRC 결과와 미해결 항목 기록 1

4. (2분) **다음 주 예고**

   > 🗣️ "다음 주는 오늘 그린 배치를 **노이즈 관점에서 다시 봅니다.** 잘 그렸다고 생각한 배선이 왜 문제가 되는지 보게 됩니다."

### 3. 자주 나오는 질문과 답

| 학생 질문 | 답 |
|---|---|
| "자동 배선(auto-route)을 쓰면 안 되나요?" | 신호선은 쓸 수 있다. **고전류·게이트·아날로그 감지선은 직접 그린다.** 자동 배선은 전류 경로를 모른다 |
| "트레이스 폭은 표에서 찾으면 되지 않나요?" | 표의 조건(구리 두께·층·온도상승)을 확인해야 한다. **조건이 다르면 값도 다르다** |
| "DRC 경고를 다 고쳐야 하나요?" | 아니다. **왜 났는지 알고 처리 방침을 적으면** 된다. 실크 겹침은 보통 조립에 영향이 없다 |
| "비아는 많을수록 좋나요?" | 고전류에는 병렬 비아가 필요하지만, 기준면을 뚫으면 **리턴 경로가 끊긴다**(14주차) |
| "3D가 맞으면 footprint도 맞는 거 아닌가요?" | 3D는 외형만이다. **핀 번호와 방향은 별개**다 |
| "MCU를 가운데 두면 배선이 짧지 않나요?" | 짧아지지만 **스위칭 노드에 가까워진다.** 노이즈가 배선 길이보다 큰 문제다 |

### 4. 시간이 남거나 모자랄 때

| 상황 | 대응 |
|---|---|
| 15분 이상 남음 | 레퍼런스 보드 거버를 뷰어로 열어 층별로 확인, BOM `Quantity` 정렬 실습 |
| 10분 남음 | 실물 PCB에서 트레이스 폭·비아를 캘리퍼로 재고 계산값과 비교 |

### 5. 안전 점검

CAD 실습이라 물리적 위험은 없다. 대신 **설계 실수가 다음 학기 비용이 된다.**

- 실물 PCB를 다룰 때는 **모서리와 스루홀 핀**에 손을 베이지 않게 한다
- 정전기 — 부품이 실장된 보드는 핀 헤더를 맨손으로 오래 만지지 않는다
- 제조 발주 전 **다른 팀의 독립 검토**를 반드시 거치도록 공지한다. pin-1·극성·footprint·미연결 net 4항목이 최소 검토 범위다
- 12주차에 NG였던 Critical 항목이 **PCB에 반영됐는지** 오늘 확인시킨다
