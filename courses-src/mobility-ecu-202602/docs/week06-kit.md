# 6주차 운영 키트 — 인버터와 PWM 구동 이론

### 교안 정보

| 항목 | 내용 |
|---|---|
| 교과목 | 모빌리티 전자제어유닛 실습 (3학점 · 전공) |
| 대상 | 미래모빌리티학과 3~4학년 |
| 차시 | 6주차 / 15주차 · 180분 |
| 강의실 | Physical AI 실습실 |
| 관련 자료 | 상세 강의자료 06번 · 과제집 18번 · 배포용 워크시트 M·N |

### 학습목표

이 시간이 끝났을 때 학생은 다음을 수행할 수 있다.

1. 하프브리지, 풀브리지, 3상 인버터의 구조를 설명한다.
2. PWM duty가 평균 전압과 모터 전류에 미치는 영향을 이해한다.
3. center-aligned PWM과 deadtime의 의미를 설명한다.

### 핵심 질문

- PWM은 왜 저항 분압보다 효율적인가?
- 3상 인버터에서 한 상을 High, 다른 상을 Low, 나머지를 Open으로 두는 이유는?
- Deadtime이 너무 짧거나 너무 길면 각각 어떤 문제가 생기는가?

### 지도 중점

5주차가 "얼마나 힘이 필요한가"였다면, 6주차는 **"그 힘을 어떤 순서로 만들어 내는가"** 다. 이 주차의 목표는 회로도 암기가 아니라 **전류가 어느 경로로 흐르고 어디로 돌아오는지 손으로 그리는 능력**이다.

> ⚡ **이 주차부터 계측이 위험해진다.** 접지형 오실로스코프의 GND 클립을 스위치 노드에 물리면 **DC 링크가 단락된다.** 블록 3 시작 전에 반드시 안전 브리핑을 한다.

### 1. 180분 진행 대본

#### 블록 1 · 0~50분 — 스위칭 구동과 전류 경로

**목표** — "전류는 반드시 돌아온다"를 그림으로 각인시킨다.

1. (5분) **5주차 과제 피드백.**

   > 🗣️ "지난주에 홀센서 6상태를 직접 재서 적었죠. 오늘은 **그 6상태마다 어느 MOSFET을 켜는지**를 채웁니다."

2. (12분) **왜 PWM인가.** 선형 제어와 비교한다.

   > 🗣️ "24V에서 12V를 만들려면 저항으로 절반 떨어뜨리면 되죠. 그런데 10A가 흐르면 그 저항이 몇 W를 태웁니까? 120W입니다. 3주차에 MOSFET을 **linear 영역에서 쓰면 안 된다**고 한 이유가 이겁니다."

   > ✍️ 판서: `Vavg = Vdc × duty`

   스위칭은 **완전히 켜거나 완전히 끈다.** 둘 다 손실이 작다. 손실은 **바뀌는 순간**에만 생긴다(3주차 스위칭 손실).

3. (13분) **하프브리지** — 상단/하단 MOSFET, 암단락, 바디 다이오드.

   3주차에 그렸던 암단락 경로를 다시 꺼낸다.

   > 🗣️ "3주차에 이 그림 그렸죠. 그때는 '무섭다'까지만 했습니다. 오늘은 **막는 방법**을 계산합니다."

4. (20분) **3상 인버터와 6-step 전류 경로** — 이 블록의 핵심.

   레퍼런스 보드 회로도 시트 3을 띄운다. `L_UH/UL`, `L_VH/VL`, `L_WH/WL`이 실제로 6개 스위치임을 확인시킨다.

   > ✍️ 판서 — 한 sector의 전류 경로를 **끝까지** 그린다
   > ```text
   > DC+ → U상 하이사이드 → 모터 U권선 → V권선 → V상 로우사이드 → DC−
   >                                            (W상은 floating)
   > ```

   > 🗣️ "왜 한 상은 띄워 둡니까(floating)? 3상 중 **두 상만 통전**해야 자속 방향이 정해집니다. 나머지 하나는 쉬는 게 아니라, 다음 sector를 기다리는 겁니다."

   그다음 **환류(freewheeling)** 를 반드시 짚는다.

   > 🗣️ "PWM이 꺼지는 순간 전류가 0이 됩니까? 아닙니다. 권선은 **인덕터**입니다. 전류가 계속 흐르려고 하죠. 어디로 갑니까?"

   답: 바디 다이오드 또는 동기 정류 채널. 3주차의 바디 다이오드가 여기서 **일을 한다.**

> ✅ **이 블록이 끝났을 때** — 학생이 DC+에서 DC−까지 전류 경로를 손으로 그릴 수 있는 상태.

#### 블록 2 · 50~95분 — PWM 계산과 6-step 표 (활동 1·2)

**목표** — 5주차의 홀 실측표를 **구동 표로 확장**시킨다.

1. (10분) **활동 1 — PWM 평균 전압** (워크시트 M 상단)

   DC 링크 24V에서 duty 10/25/50/75/90%의 평균 전압을 계산시킨다. 단순하지만 **duty와 전압의 직관**을 잡는 단계다.

2. (12분) **PWM 주파수와 타이머 설정.**

   > ✍️ 판서
   > ```text
   > edge-aligned   : fpwm = ftimer / ((PSC+1) × (ARR+1))
   > center-aligned : fpwm ≈ ftimer / (2 × (PSC+1) × ARR)
   > Duty ≈ CCR / ARR
   > ```

   > 🗣️ "center-aligned는 카운터가 **올라갔다 내려옵니다.** 그래서 한 주기에 두 번 세는 거죠. 왜 굳이 그렇게 할까요?"

   답: 펄스가 중앙 정렬되어 **ADC 샘플링 시점을 잡기 좋다**(10주차 예고).

   주파수 선택의 맞바꿈도 짚는다.

   | 주파수를 올리면 | 결과 |
   |---|---|
   | 전류 리플 | 줄어든다 |
   | 가청 소음 | 줄어든다 (20kHz 이상) |
   | 스위칭 손실 | **늘어난다** (3주차) |
   | 게이트 구동 전력 | **늘어난다** |

3. (23분) **활동 2 — 6-step 상 패턴 표** (워크시트 M 하단)

   **여기가 이 주차의 중심이다.** 학생이 5주차에 직접 잰 홀 순서를 꺼내게 한다.

   표기법을 먼저 통일한다.

   ```text
   +  : 상단 PWM 구동
   −  : 하단 도통
   0  : 비활성(floating, high impedance)
   ```

   정방향(CW) 예시를 함께 채운다. `HallSum = A×4 + B×2 + C`.

   | HallSum | Phase A | Phase B | Phase C | 도통 경로 |
   |---:|:---:|:---:|:---:|---|
   | 5 | 0 | − | + | C상 상단 → 권선 → B상 하단 |
   | 3 | − | + | 0 | B상 상단 → 권선 → A상 하단 |
   | 1 | − | 0 | + | C상 상단 → 권선 → A상 하단 |
   | 6 | + | 0 | − | A상 상단 → 권선 → C상 하단 |
   | 4 | + | − | 0 | A상 상단 → 권선 → B상 하단 |
   | 2 | 0 | + | − | B상 상단 → 권선 → C상 하단 |

   > 🗣️ "각 행에 `+`가 하나, `−`가 하나, `0`이 하나입니다. **이 규칙이 깨지면 표가 틀린 겁니다.** 바로 확인할 수 있죠."

   확인 규칙을 칠판에 남긴다.

   - 모든 행에 `+` 1개, `−` 1개, `0` 1개
   - 역방향 표는 정방향의 `+`와 `−`를 맞바꾼 것
   - 인접한 두 행은 **한 상만** 바뀐다

   > ⚠️ 데이터시트 표를 그대로 옮겨 적는 팀이 있다. **5주차에 자기가 잰 홀 순서와 맞는지** 대조하게 한다. 배선이 다르면 표도 다르다.

#### 블록 3 · 95~155분 — 데드타임과 파형 계측 (활동 3·추가 실습)

> ⚠️ **이 블록을 시작하기 전에 안전 브리핑을 반드시 한다.** 아래 5번 항목을 읽고 시작한다.

**목표** — 데드타임을 **단일 값이 아니라 항목별 합산**으로 정하게 한다.

1. (20분) **데드타임 산정** (워크시트 N 상단)

   데이터시트에서 지연 항목을 직접 찾게 한다.

   | 항목 | 어디서 찾는가 | 예시 값 |
   |---|---|---|
   | 드라이버 전파지연 편차 | UCC27211 tON/tOFF 차 | 50ns |
   | MOSFET turn-off 지연 | td(off) @Vgs=12V | 80ns |
   | 하강 시간 | tf | 40ns |
   | 온도·공차 여유 | 판단 | 2배 이상 |
   | **선정 데드타임** | 합계의 약 3배 | **500ns** |

   > 🗣️ "합계가 170ns인데 왜 500ns를 씁니까? 데이터시트 값은 **특정 온도·특정 전압의 대표값**입니다. 실제는 더 느릴 수 있어요. 여유가 곧 안전입니다."

   양쪽 실패를 대칭으로 보여 준다.

   | 데드타임이 | 결과 |
   |---|---|
   | 너무 짧으면 | **암단락** — 부품이 파손된다 |
   | 너무 길면 | 바디 다이오드 도통 증가, 파형 왜곡, 손실 증가 |

   **bootstrap 제약**도 함께 짚는다.

   > ⚠️ 하이사이드 부트스트랩 커패시터는 **스위치 노드가 낮아질 때** 충전된다. duty 100%를 계속 유지하면 충전 기회가 없어 하이사이드가 꺼진다. 최대 duty에 상한을 둬야 한다.

2. (15분) **활동 3 — 측정 계획 문서화** (워크시트 N 중단)

   **측정 전에 계획을 적게 한다.** 이 순서가 이 주차의 안전 장치다.

   | 적어야 할 것 | 예 |
   |---|---|
   | 측정 노드 | 로우사이드 Vgs |
   | 기준 GND | 파워 GND |
   | 예상 파형 | 0~12V 구형파, duty 50% |
   | 위험 요소 | 고측은 접지 기준 측정 불가 |
   | 전류 제한값 | 0.5A |

   > 🗣️ "**예상 파형을 먼저 적으세요.** 그래야 화면에 나온 게 이상한지 아닌지 판단할 수 있습니다. 먼저 보고 나중에 해석하면 뭘 봐도 그럴듯해 보입니다."

3. (25분) **추가 실습 — 파형 판독**

   저전압·저duty·무부하에서 시작해 단계적으로 올린다.

   | 측정 채널 | 예상 파형 | 확인 항목 | 이상 징후 |
   |---|---|---|---|
   | PWM 입력 | 0~3.3V | 주파수, duty | jitter, 누락 |
   | 로우사이드 Vgs | 0~12V | 구동 전압 충분한가 | 부족한 게이트 전압 |
   | 스위치 노드 | 0~Vdc | 상승/하강, 링잉 | Vds 정격 접근 |
   | 션트 전압 | 작은 차동 신호 | 전류 리플 | offset, spike |

   **데드타임 실측**이 이 실습의 목표다. 상·하단 게이트 파형을 동시에 띄우고 겹침이 없는지 확인시킨다.

   > 🗣️ "펌웨어에 500ns라고 넣었는데 실제로 500ns가 나옵니까? 다르면 **왜 다른지** 찾는 게 오늘 숙제입니다."

   > ⚠️ **고측 Vgs는 차동 프로브로만 측정한다.** 차동 프로브가 없으면 이 항목은 **교수 시연** 또는 **생략**한다. 접지형 프로브 두 개로 빼서 계산하는 방법을 학생이 시도하지 않도록 명시적으로 금지한다.

**교수는 돌아다니며 두 가지만 확인한다**
- **측정 전에 계획을 적었는가** (적지 않은 팀은 프로브를 대지 못하게 한다)
- GND 클립이 **파워 GND에만** 물려 있는가

> ✅ **이 블록이 끝났을 때** — 학생이 자기 손으로 데드타임을 측정해 본 상태.

#### 블록 4 · 155~180분 — coast·brake·회생과 과제

1. (10분) **세 가지 정지 방법.**

   | 방식 | 스위치 상태 | 전류 경로 | 특징 |
   |---|---|---|---|
   | Coast | 전부 off | 바디 다이오드로 환류 후 소멸 | 관성으로 굴러간다 |
   | Dynamic brake | 하단(또는 상단) 전부 on | 모터 권선이 단락 | 급제동, 열이 모터에서 난다 |
   | 회생 | 정류 유지, duty 감소 | **모터 → DC 링크** | 에너지가 되돌아온다 |

   > 🗣️ "감속하면 모터가 **발전기**가 됩니다. 5주차에 손으로 돌려서 전압 재 봤죠. 그 전압이 DC 링크로 밀려 들어옵니다."

   > ⚠️ 배터리·BMS가 충전 전류를 못 받는 상태면 **DC 링크 전압이 올라간다.** 그래서 3주차에 100V MOSFET을 썼고, 과전압 보호와 감속 제한이 필요하다.

2. (7분) **형성평가 3문항**

   1. center-aligned PWM에서 카운터가 두 방향으로 움직이는 이유와 주파수 식의 차이는?
   2. bootstrap 드라이버가 100% duty에서 문제가 되는 이유는?
   3. 모터 감속 중 DC 링크 전압이 상승하는 에너지 흐름을 설명한다.

3. (5분) **과제 안내**

### 2. 판서 목록

1. `Vavg = Vdc × duty` — 선형 제어 대비 손실 비교(24→12V, 10A, 120W)
2. 한 sector의 전류 경로: `DC+ → U 하이 → U/V 권선 → V 로우 → DC−`, W는 floating
3. 환류 경로 (PWM off 구간, 바디 다이오드)
4. `fpwm = ftimer/((PSC+1)(ARR+1))` / center: `≈ ftimer/(2(PSC+1)ARR)` / `Duty ≈ CCR/ARR`
5. 6-step 표 6행 (각 행에 `+` `−` `0` 하나씩)
6. 데드타임 항목 합산 (50+80+40 = 170ns → 3배 → 500ns)
7. coast / brake / 회생 세 경로

### 3. 자주 나오는 질문과 답

| 학생 질문 | 답 |
|---|---|
| "왜 두 상만 켜나요? 세 상 다 쓰면 더 세지 않나요?" | 6-step에서는 두 상 통전으로 자속 방향이 정해진다. 세 상을 다 쓰는 방식이 **정현파 구동(FOC)** 인데, 위치를 더 정밀하게 알아야 한다 |
| "PWM 주파수는 높을수록 좋나요?" | 리플과 소음은 줄지만 **스위칭 손실과 게이트 전력이 늘어난다.** 보통 16~20kHz에서 타협한다 |
| "데드타임을 아주 크게 잡으면 안전하지 않나요?" | 암단락은 막지만 바디 다이오드 도통이 늘어 **손실과 파형 왜곡**이 커진다. 저duty에서는 출력이 왜곡된다 |
| "duty 100%로 계속 돌리면 안 되나요?" | 부트스트랩 하이사이드는 **스위치 노드가 낮아져야 충전**된다. 100%를 유지하면 충전 기회가 없어 꺼진다 |
| "고측 게이트를 그냥 프로브 두 개로 빼면 안 되나요?" | 안 된다. 접지형 프로브의 GND를 스위치 노드에 물리는 순간 **DC 링크가 단락**된다. 차동 프로브를 쓴다 |
| "환류 전류는 손실인가요?" | 바디 다이오드로 흐르면 순방향 전압만큼 손실이다. 그래서 **동기 정류**(하단을 켜서 채널로 흘림)를 쓴다 |

### 5. 안전 점검 — 이 블록은 반드시 읽고 시작한다

**이번 주는 계측 자체가 위험 요소다.**

- 🔴 **접지형 오실로스코프의 GND 클립을 스위치 노드나 고측 소스에 절대 연결하지 않는다.** 스코프 GND는 콘센트 접지와 연결돼 있어, 무는 순간 **DC 링크가 접지로 단락된다.** 부품과 장비가 함께 파손된다
- 🔴 **고측 게이트는 차동 프로브로만 측정한다.** 없으면 측정하지 않는다. 접지형 프로브 2개의 차를 구하는 방식도 금지한다
- 전원은 **저전압(12V 이하)·저duty·무부하**에서 시작해 단계적으로 올린다
- 전원공급기 **전류 제한을 먼저 설정**한다. 첫 시험은 0.5A 이하 권장
- 프로브를 대거나 뗄 때는 **출력을 끄고** 한다
- 모터를 연결한다면 **축을 고정하거나 바퀴를 공중에 띄운다**
- 측정 전 **계획서(측정 노드·기준 GND·예상 파형·위험 요소·전류 제한)를 작성**한다. 작성하지 않은 팀은 프로브를 대지 못하게 한다
- 이상 냄새·연기·과열 시 **즉시 전원 차단 후 교수 호출**
