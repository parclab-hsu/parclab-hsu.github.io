# 9주차 배포용 워크시트

진행 대본과 준비 체크리스트는 [9주차 운영 키트](week09-kit.md)에 있다.

| 워크시트 | 인쇄 부수 | 사용 시점 |
|---|---|---|
| S. 레지스터 해석과 클럭 검산 | 수강생 수 | 50~130분 |
| T. 3종 비교와 디버깅 기록 | 팀 수 + 2 | 130~155분 |

> ⚠️ 워크시트 S의 **클럭 검산표**는 10주차 Timer·UART 계산의 입력이 된다.

### 2. `BSRR`로 바꿔 쓰기

```c
GPIOx->BSRR = (1U << ___);          /* set   (LED ON)  */

GPIOx->BSRR = (1U << (___ + 16));   /* reset (LED OFF) */
```

### 3. 레지스터 비트 해석 — 말로 설명한다

다음 두 줄이 하는 일을 설명한다.

```c
GPIOC->MODER &= ~0x00003000;
GPIOC->MODER |=  0x00001000;
```

| 그러면 몇 번 핀인가 | PC___ |
| `0x00001000`이 넣는 2비트 값은 | |
| 그 값의 의미는 | |
| **결론: 이 두 줄이 하는 일** | |
