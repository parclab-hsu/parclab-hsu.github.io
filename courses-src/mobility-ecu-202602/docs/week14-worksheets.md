# 14주차 배포용 워크시트

진행 대본과 준비 체크리스트는 [14주차 운영 키트](week14-kit.md)에 있다.

| 워크시트 | 인쇄 부수 | 사용 시점 |
|---|---|---|
| AC. 노이즈 경로 분석과 개선안 | 수강생 수 | 45~90분, 155~180분 |
| AD. A/B 실험 기록 | 팀 수 + 2 | 90~155분 |

> ⚠️ 워크시트 AC의 **개선안 3건**은 15주차 최종 보고서에 그대로 들어간다.

### 1. 노이즈 경로 표시

13주차 PCB 초안(또는 레퍼런스 보드 레이어 이미지)에 다섯 경로를 **색을 달리해** 그린 뒤 답한다.

| 경로 | 사용한 색 | 확인 결과 |
|---|---|---|
| 고전류 스위칭 루프 | | 면적 약 ______ cm² |
| 게이트 구동 루프 | | driver–gate–source 길이 약 ______ mm |
| ADC 전류 센싱 경로 | | 전력 패드와 분리? 예 / 아니오 |
| MCU 디지털 GND | | 기준면 연속? 예 / 아니오 |
| 아날로그 센서 GND | | 파워 전류와 합류 지점: |

| 질문 | 우리 팀의 답 |
|---|---|
| 스위칭 루프는 어느 층에서 닫히는가 | |
| 그 면적을 줄이려면 무엇을 옮겨야 하는가 | |
| 루프 면적이 커지면 무엇이 커지는가 | |

### 2. 잘못된 배치 찾기 — 우리 보드에 해당하는가

| 전형적 문제 | 해당 | 우리 보드에서의 구체적 위치·수치 |
|---|---|---|
| DC link capacitor가 MOSFET에서 멀다 | ☐ | 거리 ______ mm |
| 션트 감지선이 파워선 옆을 길게 지난다 | ☐ | 평행 구간 ______ mm |
| 게이트 신호가 모터 phase와 평행하게 길다 | ☐ | 평행 구간 ______ mm |
| MCU 아래 ground plane이 끊겼다 | ☐ | 끊긴 위치: |

> 하나도 해당하지 않는다면 다시 본다. 처음 그린 보드에 하나도 없는 경우는 드물다.

### 4. 공통 임피던스 점검

```text
Vnoise = I × Zcommon
```

| 항목 | 값 |
|---|---|
| 파워 전류와 센서 전류가 공유하는 GND 구간이 있는가 | 예 / 아니오 |
| 있다면 그 구간의 길이 | mm |
| 그 구간에 흐르는 최대 전류 | A |
