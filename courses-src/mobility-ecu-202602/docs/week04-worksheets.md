| I. 전원 트리와 전력 예산 | 수강생 수 | 40~90분 |

### 3. 입력 전류 계산

> ⚠️ **출력 전류의 합 ≠ 입력 전류.** 반드시 효율을 나눈다.

```text
Pout = (V₁×I₁) + (V₂×I₂) + (V₃×I₃) + (V₄×I₄)

     = (    ×    ) + (    ×    ) + (    ×    ) + (    ×    )  =          W

효율 η =        (근거: 데이터시트 효율 곡선 p.        , 출력 전류         A 지점)

Pin  = Pout / η =          /          =          W

Iin  = Pin / Vbat =          /          =          A
```

### 5. 배터리 전압 강하 — 경사에서 꺼지지 않으려면

```text
Vbat(부하) ≈ Vocv − Ipeak × Rtotal
```

| 항목 | 값 |
|---|---|
| 만충 전압 `Vocv` | V |
| **방전 말기** 전압 `Vocv` | V |
| 피크 전류 `Ipeak` (등판 시) | A |
| 추정 내부저항 `Rtotal` (셀+배선+커넥터+퓨즈) | mΩ |
| **최악 조건 전압** = 방전말기 − Ipeak×Rtotal | V |

이 최악 전압에서 각 레귤레이터가 살아남는지 확인한다.

| 레일 | 필요 입력 최소전압 (Vout + 드롭아웃) | 최악 전압에서 동작하는가 |
|---|---|---|
| 12V | V | 예 / 아니오 |
| 5V | V | 예 / 아니오 |
| 3.3V | V | 예 / 아니오 |

| 질문 | 우리 팀의 답 |
|---|---|
| 저전압 차단(UVLO) 임계값을 얼마로 잡아야 하는가 | V |
| 그 값을 최악 전압보다 **높게** 잡으면 무슨 일이 생기는가 | |

## 워크시트 J · 벅컨버터 계산과 전원 계측

**모빌리티 전자제어유닛 실습 · 4주차** &nbsp;&nbsp; 팀명 ____________

### 1. 벅컨버터 소자 검토

우리 팀 조건

| 항목 | 값 |
|---|---|
| 입력 전압 `Vin` | V |
| 출력 전압 `Vout` | V |
| 출력 전류 `Iout` | A |
| 스위칭 주파수 `fsw` | kHz |
| 인덕터 `L` | µH |

```text
D     = Vout / Vin                    =            /          =

ΔIL   = (Vin − Vout) × D / (L × fsw)

      = (      −      ) ×      / (        ×        )          =            A

Ipeak = Iout + ΔIL/2  =          +          /2                =            A
```

| 항목 | 값 | 판정 |
|---|---|---|
| 선택한 인덕터의 **포화전류** | A | `Ipeak`보다 큰가? 예 / 아니오 |
| 선택한 인덕터의 DCR | mΩ | |
| DCR 발열 `Iout² × DCR` | mW | |

> ⚠️ 포화전류를 넘기면 인덕턴스가 급격히 떨어져 전류가 폭주한다. **반드시 여유를 둔다.**

### 2. 커패시터 위치 — 그림으로 답한다

아래 벅컨버터에서 **고주파 스위칭 전류가 도는 루프**를 그린다.

```text
   Vin ──┬──────[ SW ]──────┬───(L)───┬───── Vout
         │                  │         │
       [Cin]              [ SW ]    [Cout]
         │                  │         │
   GND ──┴──────────────────┴─────────┴─────
```

| 질문 | 우리 팀의 답 |
|---|---|
| 이 루프에 반드시 포함되는 부품은 | |
| `Cin`을 스위치에서 멀리 두면 무엇이 커지는가 | |
| 그 결과 무슨 문제가 생기는가 | |
| `Cout`은 무엇에 영향을 주는가 (2가지) | |

### 5. 부하 과도 시험

5V 레일 부하를 100mA → 500mA로 급변시킨다.

> ⚠️ 저항 부하를 쓰기 전에 **전력 정격을 먼저 계산**한다. 계산 없이 꽂으면 저항이 탄다.

```text
사용할 저항: ______ Ω,  예상 소비전력 = V²/R =                  W
저항의 정격 전력: ______ W       →  여유율:            배
```

| 항목 | 목표(허용 범위) | 측정값 |

| 회복 시간 | ms 이내 | ms |
