## 📦 공통 제출 규정

**제출 형식** — 아래 3종을 한 번에 올립니다.

1. 코드/설정 `zip`
2. 보고서 `PDF` — **표지에 학번·이름·과제명** 필수
3. 실행 결과 스크린샷 / 영상

**마감** — 별도 표기가 없으면 **다음 주차 강의 시작 전까지 LMS 업로드**

**공통 원칙**

- 코드는 **재현 가능**해야 합니다. 실행 명령과 환경(버전·경로)을 보고서에 적으세요.
- 외부 코드를 사용하면 **출처를 명시**합니다. 미표기 시 감점.
- 스크린샷은 캡처 시점의 터미널 명령이 함께 보이도록 찍으면 증빙이 쉽습니다.
- 실행이 끝까지 안 되더라도 **어디서 왜 막혔는지**를 기록해 제출하세요. 트러블슈팅 기록도 평가 대상입니다.
