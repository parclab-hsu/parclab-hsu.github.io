### 3. 쿼드콥터 공진 정량 분석 (8점) ⭐ 계산

> 충격시험 결과 주요 고유진동수가 **27 Hz, 38 Hz, 151 Hz**. **18×6.1 프로펠러**, 호버링 시 약 **6,000 RPM**.
> **(1)** 프로펠러 통과주파수(BPF)를 계산하고(블레이드 2매 가정), 측정된 고유진동수들과 비교하여 공진 위험을 정량적으로 분석하시오 (4점)
> **(2)** 공진 위험이 존재한다면, 전통적 순차설계(Sequential Design)와 구조–제어 병렬 통합설계(Co-Design) 관점에서 각각의 해결 방안을 비교하시오. 특히 두 접근법이 **강성(Stiffness) 확보 전략과 중량(Weight)**에 미치는 영향에서 어떻게 다른지, **강성과 강도의 차이**를 명확히 구분하여 논하시오 (4점)

**(1) 풀이**

- 회전 주파수 = 6,000 RPM ÷ 60 = **100 Hz**
- **BPF = 회전주파수 × 블레이드 수 = 100 × 2 = 200 Hz**
- 27 Hz, 38 Hz는 1× 가진(100 Hz)과도 충분히 이격 → **안전**
- **151 Hz가 핵심 쟁점** — BPF(200 Hz)와의 이격이 약 **24.5%**로 ±20% 경계를 약간 벗어나 정상 호버링(6,000 RPM)에서는 직접 공진은 아니다
- 그러나 RPM은 기동 시 변동한다. 151 Hz에 BPF가 일치하려면 회전주파수 75.5 Hz → **4,530 RPM**. 즉 호버링 RPM보다 낮은 운용 영역(상승/하강·저추력 구간)에서 BPF가 151 Hz를 **통과(sweep through)** → **천이 공진(transient resonance) 위험**
- 151 Hz는 1× 성분 기준 9,060 RPM으로 정격 범위 밖이나 BPF 경유 통과는 피할 수 없음 → **151 Hz 모드가 가장 위험한 모드로 판정**

**(2) 풀이**

- **강성(Stiffness)** — 변형 저항($k = F/\delta$). 고유진동수 $\omega_n = \sqrt{k/m}$를 결정 → **공진 문제의 핵심**
- **강도(Strength)** — 파괴·항복 저항(허용응력). **부재가 깨지는지의 문제**
- **공진은 강성–질량 문제이며, 순차설계는 강성을 구조로만 확보해 무겁고, 코디자인은 구조와 제어가 강성을 분담해 더 가볍게 같은 안전성을 달성한다.**

### 5. 멀티콥터 설계 분석 (24점) ⭐ 계산

> 미래모빌리티학과의 한 팀이 **Payload 1.5 kg**을 운반하는 멀티콥터를 설계하고자 한다. **T-Motor 기준 성능 데이터**를 활용하여 다음을 분석하시오.

**(1) 호버링 시간 역전 현상 (8점)**

> 동일 Payload·동일 임무에서 **Quadcopter(24분)**와 **Coaxial Octocopter(26분)**의 호버링 시간이 제시되어 있다. 동축 옥토콥터가 모터 수(8개)가 많고 총중량이 더 무거움에도 호버링 시간이 더 긴 이유를, **추력 대 중량비(T/W), 모터당 부하, 로터 효율(g/W) 곡선 특성**과 연결하여 정량적·물리적으로 설명하시오.

**핵심: 모터당 부하가 낮을수록 로터 효율(g/W)이 높아지기 때문**

① **부하 분산** — 호버링에 필요한 총추력 = 총중량(불변). 쿼드는 4개 로터가 분담(모터당 0.25W₄), 옥토는 총중량 1.2W₄라도 8개가 분담(모터당 0.15W₄) → **모터당 부하 약 40% 감소**
② **로터 효율 곡선의 비선형성** — 로터 효율(g/W)은 저추력 영역에서 높고 고추력 영역에서 급락. 운동량 이론상 $P \propto T^{3/2}$ → **추력을 절반으로 내리면 전력은 $2^{1.5}\approx2.83$배 절감**. 모터당 부하를 낮추면 효율 좋은 동작점으로 이동
③ **T/W 마진** — 옥토는 동일 모터로 더 큰 T/W 여유 확보 → 호버 추력이 최대추력 대비 낮은 비율(30~40%)에서 작동

**(2) 안전계수와 Weight Spiral (8점)**

> FoS 예시에서 드론 핵심부 FoS ≈ 2.0~2.5, 항공·우주 FoS ≈ 1.4~1.5이다. 동일 Arm의 굽힘 응력 해석값이 **80 MPa**일 때 각각의 요구 설계 허용응력을 계산하고, FoS를 무작정 높게 잡을 수 없는 이유를 **Weight Spiral 및 과설계(Over-design)** 개념과 연결하여 설명하시오.

- 허용응력 = 해석응력 × FoS
- 드론 핵심부 (FoS = 2.0): **80 MPa × 2.0 = 160 MPa**
- 항공·우주 (FoS = 1.4): **80 MPa × 1.4 = 112 MPa**
- **Weight Spiral** — FoS↑ → 요구 허용응력↑ → 단면적·두께 증대 → 구조 중량 증가(과설계) → 총중량↑ → 호버 추력 요구↑ → 더 큰 모터·프로펠러 → 더 큰 배터리 → 또 중량↑ → **발산 루프**. 결과: 페이로드 여유·체공시간 급감, 효율 악화

**(3) 동력원 선정 (8점)**

> 체공시간을 30분 이상으로 늘리기 위해 동력원을 LiPo에서 Fuel Cell 또는 Hybrid로 전환하는 것을 검토 중이다. 에너지 밀도 데이터(**LiPo ≤ 200 Wh/kg, Fuel Cell 500~1000 W/kg, Gasoline 1500 W/kg**)와 각 방식의 장단점을 근거로, 소형 드론(Payload 1.5 kg급)에 적용할 동력원을 선정하고 타당성을 논하시오.

- **선정: Hybrid (LiPo + Fuel Cell)** — 단, 규모 제약 시 고에너지 LiPo 우선 검토
- **근거** — 소형·고응답이 요구되는 멀티콥터 특성상 **순수 Fuel Cell은 부적합**(저온 시동 불가, 응답 지연, 기성품 제한). **에너지밀도는 Fuel Cell, 출력밀도는 LiPo가 분담**하는 Hybrid 구성이 30분 이상 체공과 비행 안정성을 동시에 만족하는 가장 타당한 해법

## 답안 작성 요령

!!! tip "계산 문제에서 점수를 잃지 않는 법"
    1. **단위를 반드시 쓴다.** RPM ÷ 60 = Hz 변환을 생략하지 말 것.
    2. **중간 과정을 남긴다.** 6,000 RPM → 100 Hz → ×2 = 200 Hz. 답만 쓰면 부분점수를 못 받는다.
    3. **판정 문장을 붙인다.** "따라서 151 Hz 모드가 가장 위험하다"처럼 결론을 명시.
    4. 비교 문항은 **표**로, 원리 문항은 **수식 + 한 줄 해석**으로.
    5. 개념 구분 문항(강성 vs 강도)은 **정의를 먼저 쓰고** 비교로 넘어간다.

- **인지·판단·제어**라는 3단 구조는 자동차든, 드론이든, 로봇이든 동일하다
