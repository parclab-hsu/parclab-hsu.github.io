# HD로보틱스 — 적외선 광학 추적 기반 로봇 캘리브레이션

:material-circle-outline:{ style="color:#e0a800" } **계획 중** · Infrared Optical Tracking for Robot Calibration

[:material-book-open-page-variant-outline: 핵심 논문 상세 분석 및 유사 기술 동향](hd-robotics-ots-literature.md)

!!! abstract "프로젝트 한눈에 보기"
    적외선 스테레오 카메라와 로봇 장착형 강체 마커를 활용하여 로봇 말단의 **3차원 위치·자세**를 측정하고, 기존 로봇 보정 알고리즘과 연계하는 **자동 캘리브레이션 시스템**을 개발합니다. 광학 추적 시스템(Optical Tracking System, OTS)의 하드웨어·소프트웨어와 로봇 인터페이스를 통합하여 생산라인 적용 가능성을 검증합니다.

!!! info "계획 및 목표의 적용 범위"
    본 문서는 연구개발 계획안입니다. 정량 수치는 **개발 목표**이며 시험 완료 또는 성능 달성 실적이 아닙니다. **12개월 일정은 제안**이며, 실제 연구기간·대상 로봇·작업 공간·평가 조건은 요구사항 정의 단계에서 확정합니다.

## 1. 연구개발 개요

**과제명:** 적외선 광학 추적 시스템 기반 산업용 로봇 자동 캘리브레이션 기술 개발

적외선 OTS로 취득한 로봇 말단의 위치·자세 정보와 로봇 관절 데이터를 이용하여 기구학적 오차를 식별·보정한다. 측정 데이터 취득부터 보정값 산출, 보정 결과 검증까지 연결하는 자동화 절차를 구현하여 로봇의 절대 위치 및 자세 정확도를 향상시키는 것을 목적으로 한다.

**기본 범위는 정적 캘리브레이션**이다. 로봇을 측정 자세로 이동시킨 뒤 정지·안정화 상태에서 계측한다. 인라인 적용은 생산라인 내 보정 공정의 자동화를 의미하며, 이동 중 실시간 경로 보상까지 포함하는 요구는 별도 범위로 협의한다. 하드웨어 자체 개발 범위와 기존 보정 알고리즘의 제공·수정·제어기 적용 책임은 착수 단계에서 확정한다.

### 개발 범위와 전제조건

| 구분 | 범위안 |
|---|---|
| 필수 개발 | OTS 모듈·강체 마커, 위치·자세 추적 SW, 기존 알고리즘 연동, 정지 측정 기반 자동 보정 |
| 필수 검증 | OTS 단독 성능, 보정 모델의 별도 자세 예측, 적용 후 실제 TCP 도달 오차, 자동 절차 완료율 |
| 적용 가능성 평가 | 생산라인 보정 셀 운용, 가려짐·재장착·환경 변화에 따른 성능과 소요시간 |
| 후속 고도화 | 이동 중 폐루프 보상, 학습 기반 자세 선정, 열·탄성·전달계 오차 모델 |

대상 로봇·제어기, 제공 알고리즘, 부품 자체 설계 범위, 기준 계측 장비 및 수행 인력은 착수 시 확정한다. 초기 설치·마커 장착·기준 교정과 이후 반복 보정의 자동 실행 범위를 분리한다.

## 2. 연구개발 배경 및 필요성

산업용 로봇은 동일 위치로 반복 이동하는 반복정밀도와 별개로, 제작·조립 공차, 링크 치수 편차 및 관절 영점 오차 등에 의해 지령 위치와 실제 도달 위치 사이에 절대 위치 오차가 발생할 수 있다. 오프라인 프로그래밍과 정밀 작업의 현장 교시 부담을 줄이기 위해서는 작업 공간 전반에서 절대정확도를 확보하는 계측·보정 기술이 필요하다.

본 과제는 기존 계측 기반 보정의 장비 도입 비용과 측정 시야 차단에 따른 작업 개입을 개선 대상으로 설정한다. 적외선 스테레오 카메라와 강체 마커로 로봇 위치·자세를 측정하고, 복수 마커 배치와 자동 재인식을 통해 가려짐(Occlusion)에 대응하는 기술을 개발한다.

로봇 이동, 데이터 취득, 보정값 산출 및 검증을 통합하여 인라인 자동 보정의 적용 가능성을 평가한다. 무인 보정 범위는 실제 작업 공간과 가려짐 조건에 대한 시험을 통해 확정한다.

### 선행연구에 기반한 개발 방향

OTS와 강체 마커를 이용해 UR10의 기구학·베이스·툴 파라미터를 보정한 연구는 **평균 위치 오차 0.348 mm, 표준편차 0.096 mm, 표본 최대 위치 오차 0.467 mm**, 평균 각도 오차 **0.070°**를 보고하였다. 해당 값은 별도 자세의 모델 예측과 같은 OTS 측정 사이의 차이이며, 보정 적용 후 독립 계측으로 평가한 TCP 도달 오차와 구분한다. 이는 접근법의 가능성을 보여주는 실험 사례이며, 다른 로봇·작업 공간·TCP에서의 목표 충족을 보장하지 않는다. 특히 표본 최대값은 전 작업 공간의 보증 상한이 아니며, 평균 각도 오차를 최대 자세 오차와 비교해서는 안 된다. [논문 1](https://www.mdpi.com/1424-8220/20/21/6341)

광학 모션캡처와 기준 레이저 트래커를 이용해 관절 영점 및 불확도를 추정한 연구도 보고되어 있다. 본 과제는 광학 계측 자체의 신규성보다 **대상 로봇에 맞춘 계측 구성, 기존 보정 알고리즘 연동, 가려짐 시 자동 재측정, 독립 검증을 포함하는 운용 절차**를 차별화 방향으로 설정한다. [논문 2](https://www.nist.gov/publications/efficiently-improving-and-quantifying-robot-accuracy-situ)

## 3. 연구개발 목표 및 성능 평가

| 평가 항목 | 개발 목표 | 평가 방법 |
|---|---|---|
| 로봇 절대 위치 오차 | 0.5 mm 이하 | 평가안: 독립 기준 계측으로 얻은 TCP 위치와 지령 TCP 위치 간 3차원 거리 오차 평가 |
| 로봇 자세 회전 오차 | 0.1° 이하 | 평가안: 독립 기준 자세와 지령 TCP 자세 간 상대 회전각 평가 |
| OTS 공간 분해능 | 0.05 mm 이하 | 기준 변위 장치로 미소 변위 구분 능력 평가 |
| OTS 절대 위치·자세 측정 오차 및 불확도 | 작업 공간과 오차 예산 분석 후 확정 | 기준 위치·자세와 비교하여 거리·방향·공간별 오차 및 불확도 평가 |
| 마커 인식 및 추적 | 고유 ID 식별 및 가려짐 해제 후 자동 재인식 | 거리·자세·가려짐 조건별 인식 성공률과 추적 복구 시간 평가 |
| 자동 보정 기능 | 측정부터 검증까지 자동 실행 | 정의된 작업 조건에서 작업자 개입 여부와 절차 완료율 평가 |

!!! note "측정 지표 정의"
    원 목표 사양은 **±0.5 mm, ±0.1°**이다. 위 표의 TCP 기준 3차원 거리·상대 회전각은 **평가 방법 제안**이며 확정된 검수 조건이 아니다. 축별·합성 오차와 최대값·통계값 기준을 합의한 뒤 요구사항을 동결한다. **공간 분해능은 절대 측정 정확도와 구분**한다. 논문의 평균·RMS·표본 최대값을 서로 같은 지표로 비교하지 않는다.

최종 위치·자세 목표는 **보정값 적용 후 로봇이 검증 지령으로 실제 이동한 결과**로 판정하는 것을 제안한다. 보정 모델과 측정 데이터 사이의 잔차는 별도 알고리즘 지표로 보고한다. 공간 분해능은 표시 자릿수가 아니라 기준 미소 변위를 구분하는 능력이며, 평균화 조건·정지 잡음·반복성·절대 오차를 함께 평가한다.

### 성능 판정 조건안

| 조건 | 요구사항 정의 단계에서 확정할 내용 |
|---|---|
| 측정 대상 | 실제 작업점인 TCP 위치·자세, 플랜지–마커–TCP 변환 및 툴 길이 |
| 적용 공간 | OTS 측정 거리·체적, 로봇 관절 범위, 가시성이 확보되는 유효 영역 |
| 환경·부하 | 온도 범위, 워밍업, 툴 질량·무게중심, 로봇 접근 방향 |
| 취득 절차 | 정지 안정화 판정, 샘플 수·평균화 방식, 시간 정합 허용값 |
| 표본 구성 | 보정 자세 수, 별도 검증 자세 수, 공간 분포, 반복 횟수 |
| 합격 판정 | 위치·자세 각각의 주 판정 지표와 임계값, 불확도를 고려한 판정 규칙 |
| 보조 보고 | 평균·RMS·최대값·백분위수, 축별 편향, 추적 실패·제외·재측정 건수 |

검증 자세·제외 규칙·판정 지표는 최종 시험 전에 동결한다. 검증 데이터로 보정값이나 가중치를 조정했다면 해당 데이터는 개발용으로 전환하고 새 검증 세트를 확보한다. 작업 공간은 공정 요구를 기준으로 정하며, 시험 후 실패 영역만 제외하여 목표를 충족한 것으로 판단하지 않는다.

| 자동화 지표 | 산정 방법안 |
|---|---|
| 최초 완료율 | 재시도 없이 유효한 보정·검증을 마친 실행 수 / 시작한 전체 실행 수 |
| 자동 완료율 | 정해진 재시도 한도 내 작업자 개입 없이 완료한 실행 수 / 시작한 전체 실행 수 |
| 유효 계측률 | 유효한 위치·자세를 얻은 시도 수 / 전체 측정 시도 수 |
| 총 소요시간 | 이동·안정화·취득·계산·적용·검증·재시도를 포함한 경과시간 |
| 작업자 개입 | 초기 설치와 반복 보정 중 개입의 횟수·사유를 구분 |

초기 목표값과 재시도·시간 제한을 요구사항에 명시하고, 기초시험 후 변경 시 근거와 이력을 기록한다. 실패·중단 실행도 분모와 시간 보고에 포함한다.

산업용 로봇 성능시험은 [ISO 9283](https://www.iso.org/standard/22244.html)을 참고하여 시험계획을 수립한다. 구체적인 절차를 확정하기 전에는 표준 적합 시험을 수행한 것으로 표현하지 않는다. 자세 오차는 회전행렬 또는 단위 쿼터니언의 상대 회전각으로 계산하는 방안을 검토하며, 위치와 자세를 함께 최적화할 때는 단위·측정 불확도를 고려하여 잔차의 가중치를 정한다.

세부 목표는 다음과 같다.

- 고해상도 스테레오 적외선 카메라 기반 OTS 하드웨어 개발
- 로봇 장착형 강체 마커와 카메라·조명 동기화 인프라 구축
- 마커 검출, 고유 ID 매칭 및 3차원 위치·자세 복원 소프트웨어 개발
- 기존 로봇 보정 알고리즘 및 제어기와의 연동 인터페이스 확보
- OTS 자체 계측 성능과 로봇 보정 성능 검증
- 생산라인 적용을 위한 자동 측정·보정·검증 절차 구현

## 4. 주요 연구개발 내용

[개발 컨셉·카메라/마커 세부 사양·시뮬레이션 결과](hd-robotics-ots-concept.md)에서 1차 설계 후보와 14개 조건의 수치 분석을 확인할 수 있다. 5 MP급 스테레오 구성, 2~3 m 측정 거리, 600 mm 기준선, 비대칭 6점 마커를 출발점으로 검토한다. 수치는 설계 가정이며 실측·로봇 보정 성능과 구분한다.

### 4.1. OTS 하드웨어 개발

고해상도 적외선 카메라, 렌즈, 광학 필터 및 조명으로 구성된 스테레오 계측 모듈을 개발한다. 대상 로봇의 작업 공간과 측정 거리를 고려하여 카메라 간격과 설치 위치를 설계하고, 측정 시야와 위치·자세 측정 성능을 확보한다.

복수 적외선 마커로 구성된 로봇 말단 장착형 강체 마커 툴을 설계한다. 마커의 기하학적 배치로 고유 ID와 자세를 식별하고, 체결 강성과 반복 장착 시 위치 재현성을 검토한다. 로봇 자세 변화와 주변 구조물에 따른 가려짐을 고려하여 마커 배치를 최적화한다.

능동 LED 마커와 수동 반사 마커의 전원·배선·조명·ID 식별 특성을 비교하여 방식을 선정한다. 카메라 해상도만으로 성능을 판단하지 않고 측정 거리, 카메라 간격, 렌즈 왜곡, 노출 및 열적 안정성을 함께 설계한다.

마커 배치와 가시성에 따른 목표점 오차를 평가하는 연구를 참고하여 마커 원점뿐 아니라 **실제 TCP에서의 불확도**를 관리한다. [논문 5](https://link.springer.com/chapter/10.1007/978-3-540-75759-7_79) 설계 예시로, 회전축에 수직인 마커–TCP 거리가 300 mm이고 회전 오차가 0.1°이면 작은 각도 근사에 따른 위치 오차 성분은 약 0.524 mm이다. 이 계산은 논문의 실험 결과가 아닌 기하학적 예시이며, TCP 이격 거리와 자세 측정 성능을 함께 제한해야 함을 보여준다.

카메라 촬영과 적외선 조명의 동기화 기능을 구현하고, 로봇 상태 데이터와 영상 데이터의 취득 시점을 정합하기 위한 타임스탬프 및 트리거 체계를 구축한다.

**주요 산출물:** 스테레오 적외선 카메라 모듈, 강체 마커 툴, 동기화 회로·구동 모듈, 하드웨어 설계서.

### 4.2. 광학 추적 소프트웨어 개발

적외선 영상에서 마커를 검출하고 중심 좌표를 정밀하게 추정하는 영상처리 알고리즘을 개발한다. 외란광, 반사체 및 영상 노이즈의 영향을 줄이기 위한 전처리와 이상 검출 기능을 구현한다.

스테레오 카메라의 내부·외부 파라미터를 교정하고, 좌우 영상의 마커 대응 관계와 삼각측량으로 3차원 좌표를 복원한다. 복원 좌표와 강체 마커 기준 형상을 이용하여 로봇 말단의 위치·자세를 산출한다.

복수 강체 마커의 고유 ID 매칭과 연속 추적 기능을 개발한다. 일부 마커가 가려지면 관측 가능한 마커 수와 배치로 측정 유효성을 판단하고, 저신뢰 데이터는 보정 입력에서 제외한다. 추적 중단 후 시야가 회복되면 자동으로 재인식한다.

| 관측 상태 | 제안 동작 및 기록 |
|---|---|
| 충분한 마커 관측 | 기하학적 배치·잔차·신뢰도를 확인하여 유효 측정값 출력 |
| 일부 마커 가려짐 | 남은 관측으로 위치·자세 계산이 유효한지 판정하고 품질 저하 기록 |
| 관측 부족 또는 완전 가려짐 | 계측값을 무효 처리하고 대기·재측정; 예측값을 검수용 실측값으로 사용하지 않음 |
| 시야 회복 | ID와 강체 형상 재확인 후 계측 재개, 복구 시간 기록 |

재인식 성공률, 잘못된 ID 인식률, 유효 계측률 및 복구 시간을 가려짐 조건별로 평가한다. 초기 임계값을 요구사항에 정의하고 시제품 기초시험으로 적정성을 검토한다. 마커 수 증가만으로 완전 가려짐이 해결되는 것으로 가정하지 않는다.

**주요 산출물:** 카메라 교정·마커 검출·3차원 복원·ID 매칭 소프트웨어, 추적 유효성 판단 및 재인식 모듈.

### 4.3. 로봇 보정 연동 및 자동화 인터페이스 개발

OTS 측정 좌표계와 로봇 베이스 좌표계, 강체 마커 좌표계와 로봇 툴 좌표계 사이의 변환 관계를 추정하는 정합 절차를 개발한다.

Robot-world/hand-eye 동시 정합 연구를 참고하여 좌표변환 방향과 표기 규칙을 고정하고, 초기 정합과 보정 후 정합의 잔차를 각각 평가한다. 이 정합 문제와 로봇 기구학 파라미터 식별은 구분한다. 잘못된 명목 기구학에서 유래한 오차를 좌표계 변환이 흡수하지 않는지 독립 자세로 확인한다. [논문 3](https://www.nist.gov/publications/solving-robot-worldhand-eye-calibration-problem-using-kronecker-product)

기존 알고리즘의 제공 형태·입출력·식별 가능 파라미터를 먼저 확인한다. 관절 영점만 식별할지 링크·축 정렬까지 확장할지는 모델의 식별 가능성과 제어기 지원 범위를 바탕으로 결정한다. 제조사 협조 항목은 로봇·제어기 접근, 기존 알고리즘 사용 범위, 보정값 적용 및 복원 절차이며 실제 역할 분담은 협의한다.

로봇 관절값과 OTS 측정값을 기존 보정 알고리즘에 전달하기 위한 데이터 형식과 통신 인터페이스를 정의한다. 측정 데이터에는 위치·자세, 마커 ID, 취득 시각 및 유효성 정보를 포함한다.

제공 모델에 접근할 수 있으면 단위·규모를 정규화한 식별 Jacobian의 SVD로 파라미터 종속성을 점검한다. 알고리즘이 블랙박스이면 제공 진단값과 외부 예측 시험으로 검증하고, 관측가능성 기반 선정은 접근 가능한 범위에서 수행한다.

인터페이스에는 단위, 좌표변환 방향, 회전 표현·순서, 시간 기준 및 교정 버전을 명시한다. 카메라 간 동기, 조명·마커 구동 동기, 로봇 상태와 영상의 시간 정합을 각각 확인한다. 복수 강체 마커 전환 시에는 마커별 TCP 변환과 전환 전후 위치·자세의 연속성을 검증한다.

보정에 필요한 측정 자세를 선정하고, 다음 절차를 자동 실행하는 소프트웨어를 개발한다.

1. 로봇 측정 자세 이동 및 정지 안정화
2. 관절값과 OTS 위치·자세 데이터 취득
3. 데이터 유효성 확인 및 이상값 제거
4. 기존 알고리즘을 통한 보정값 산출
5. 보정값 유효성 확인 및 기존 보정값 백업
6. 제어기 지원 기능 또는 지원되는 외부 보정 명령 방식으로 적용
7. 별도 지령으로 실제 이동한 뒤 독립 기준 측정 및 결과 판정

제조사 내장 보정과 외부 보정이 중복 적용되지 않도록 활성 보정 상태를 확인한다. 외부 역기구학을 사용하는 경우 지원 명령 방식, 해 분기, 관절 한계와 경로 연속성을 검토한다.

추적 실패나 통신 오류가 발생하면 재측정 또는 절차 중단이 가능하도록 예외 처리를 구현한다.

모델에 접근 가능한 경우, 측정 자세 선정에 파라미터 변화가 측정값에 충분히 드러나는지 평가하는 **관측가능성**을 반영한다. Hyundai YS100에서 자세 선택과 표본 수의 영향을 시험한 연구를 참고하여, 동일한 측정 수에서 균등·무작위 선정과 관측가능성 기반 선정을 비교한다. 가시성, 관절 한계, 충돌 회피 및 이동 시간은 본 과제의 추가 제약으로 적용한다. [논문 4](https://doi.org/10.1155/2014/291389)

베이지안 실험 설계에 의한 적응형 자세 선택은 후속 고도화 후보로 둔다. 기본 일정은 기존 보정 알고리즘과 관측가능성 기반 기준 방법을 우선 확보하는 범위로 관리하며, 학습 기반 알고리즘을 필수 개발 항목으로 확대하지 않는다. [논문 6](https://arxiv.org/abs/2409.10802)

**주요 산출물:** 좌표계 정합 모듈, 통신·데이터 인터페이스 명세서, 자동 보정 실행 소프트웨어.

### 4.4. 시스템 통합 및 성능 검증

OTS 단독 시험으로 공간 분해능, 측정 반복성, 절대 측정 오차 및 작업 공간 내 위치별 성능 편차를 평가한다. 측정 거리, 마커 자세, 외란광 및 온도 조건의 영향을 분석하여 하드웨어와 알고리즘을 개선한다.

대상 로봇에서 보정 전후의 위치·자세 오차를 비교한다. **보정용 데이터와 검증용 데이터를 분리**하고, 작업 공간에 분포한 독립 검증 지점에서 목표 달성 여부를 확인한다.

**검증 자세의 분리와 기준 계측의 독립성은 별도로 확보**한다. 자체 OTS만으로 보정과 평가를 모두 수행하면 공통 편향을 놓칠 수 있으므로, 최종 검증에는 별도 기준 계측 장치 또는 교정된 기준물을 사용한다. 자세 검증은 6자유도 기준 계측 또는 알려진 기준 형상을 이용한 방식으로 구성하며, 단일 점 위치 측정만으로 자세 정확도를 검증한 것으로 간주하지 않는다.

기준 장치·기준물의 교정 상태와 불확도를 기록한다. 길이 기준물만으로 TCP의 공간 위치·자세를 모두 검증한 것으로 간주하지 않는다. 기준 좌표계 정합에 사용하는 지점과 최종 평가 지점을 구분하고, 평가 결과에 맞춰 좌표계를 다시 최적화하지 않는다.

| 검증 단계 | 비교 대상 | 결과 해석 |
|---|---|---|
| OTS 단독 시험 | 기준 위치·자세와 OTS 측정 | 계측기 성능 |
| 모델 예측 시험 | 별도 관절값에서 모델과 실측 | 모델 일반화 성능 |
| 실제 도달 시험 | 보정 적용 후 지령 TCP와 독립 실측 TCP | 최종 로봇 정확도 판정 |
| 운용 시험 | 반복 실행·가려짐·재장착·오류 처리 | 자동화 성능·적용 조건 |

오차 예산에는 OTS 위치·자세, 베이스 정합, 마커–TCP 변환, 시간 정합 및 반복 장착을 포함한다. 독립성이 입증되지 않은 오차를 단순 제곱합으로 합성하지 않고 공분산·상관관계를 검토한다. 측정 실패·제외 표본과 재시도 횟수도 함께 보고하여 유효 표본만 선택한 결과로 자동화 성능을 과대평가하지 않는다.

| 비교 시험 | 목적 |
|---|---|
| 보정 전 / 기존 절차 / OTS 연동 보정 후 | 동일 조건에서 정확도 개선과 기존 방식 대비 효과 확인 |
| 균등·무작위 자세 / 관측가능성 기반 자세 | 동일 측정 수에서 자세 선정 효과 확인 |
| 정상 시야 / 부분 가려짐 / 시야 복구 | 유효 계측률, ID 오류, 복구 시간 및 자동 완료율 확인 |
| 작업 공간 중심 / 경계 / 서로 다른 TCP 자세 | 공간·자세에 따른 편차 및 적용 범위 확인 |

제어기 적용 전 오프라인 결과와 보정값 유효성을 점검하고, 적용 후 성능 저하 시 이전 보정값으로 복원할 수 있도록 이력을 관리한다.

생산라인 모사 환경에서는 가려짐 발생·해제, 반복 보정 및 통신 이상 상황을 시험하여 자동 보정 절차의 안정성과 현장 적용 조건을 도출한다.

**주요 산출물:** OTS 성능평가 보고서, 로봇 보정 전후 비교 결과, 통합 시험성적서, 현장 적용·운용 가이드.

## 5. 추진 방법 및 일정안

요구사항 정의, 계측 시스템 구현, 로봇 연동 및 통합 검증 순으로 추진한다. 초기 단계에서 목표 작업 공간과 정확도 평가 기준을 확정하고, 카메라 계측 오차·좌표계 정합 오차·마커 장착 오차를 구분하여 관리한다.

아래 일정은 **연구기간 12개월을 가정한 제안**이다.

| 단계 | 기간 | 주요 수행 내용 | 주요 산출물 |
|---|---|---|---|
| 요구사항 정의 및 기본 설계 | 1~2개월 | 대상 로봇·작업 공간 분석, 평가 기준 수립, 시스템 구조 및 인터페이스 설계 | 요구사항 정의서, 기본 설계서, 시험계획서 |
| OTS 하드웨어 및 핵심 SW 개발 | 3~5개월 | 카메라 모듈·마커 툴 제작, 동기화 구현, 카메라 교정 및 마커 검출 | OTS 시제품, 핵심 계측 SW |
| 위치·자세 추적 및 로봇 연동 | 6~8개월 | 3차원 복원, ID 매칭, 좌표계 정합, 기존 보정 알고리즘 연동 | 통합 SW, 인터페이스 명세서 |
| 자동 보정 및 성능 개선 | 9~10개월 | 자동 측정 절차 구현, 가려짐 대응, 오차 분석 및 개선 | 자동 보정 시제품, 중간 시험 결과 |
| 통합 검증 및 적용 기준 수립 | 11~12개월 | 독립 검증, 반복 운용 시험, 현장 적용 조건 정리 | 최종 시제품, 성능평가 보고서, 운용 매뉴얼 |

각 단계의 완료는 문서 제출뿐 아니라 **평가 조건·역할 확정 → OTS 기초 계측 성능 확인 → 좌표계 정합 및 데이터 연동 확인 → 자동 절차·예외 처리 확인 → 독립 기준 검증** 순으로 판정한다. 12개월 일정은 기존 광학 부품·보정 알고리즘의 활용 가능성과 인력·장비 접근성 확보를 전제로 한 안이며, 자체 설계 범위가 확대되면 재산정한다.

|---|---|---|
| 로봇·알고리즘 제공 | 산업체의 로봇·제어기 접근, 모델 또는 API 제공 | 기종·인터페이스·적용 절차 |
| OTS 개발·통합 | 수행팀의 광학 모듈·마커·추적 SW·연동 구현 | 시제품, 도면·부품 목록, SW·설치 문서 |
| 계측·성능 평가 | 공동 시험계획과 기준 계측 담당·장비 확보 | 시험절차, 원시 데이터, 분석·불확도 |
| 적용·인수 | 적용·복원, 운용 조건, 유지보수 범위 협의 | 매뉴얼, 제한조건, 최종 결과 보고 |

실제 기관별 분담과 SW·소스·도면의 제공 범위·사용권은 착수 시 협의한다. 시험 기록은 로봇·툴·마커·교정 파일·알고리즘 버전·적용 보정값을 연결해 재현 가능하게 관리한다.

## 7. 기대효과 및 활용 방안

적외선 광학 추적 기반의 로봇 위치·자세 계측 기술과 기존 보정 알고리즘의 연동 기술을 확보하고, 로봇 절대정확도 향상을 위한 자동 캘리브레이션 체계를 구축한다.

로봇 출하 전 정확도 검사, 설치 후 초기 보정 및 유지보수 후 재보정에 활용할 수 있다. 자동 측정과 결과 기록으로 수동 계측 부담을 줄이고, 보정 절차와 품질 이력 관리의 표준화를 추진한다.

OTS 하드웨어, 강체 마커 툴, 추적·보정 연동 소프트웨어 및 검증 절차를 패키지화하여 대상 로봇과 생산라인으로 적용 범위를 확대한다. 장비 비용, 보정 소요 시간 및 작업자 개입 감소 효과는 실증 결과를 바탕으로 정량 평가한다.
