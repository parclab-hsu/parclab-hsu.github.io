# 연차별 목표와 성과지표

**담당 분야 — 실환경–가상환경 연계형 데이터 증강**

산업통상부 공고 제2026-549호 · 연구개발과제 1
「로봇 데이터팩토리 구축 및 로봇파운데이션모델(RFM) 개발」

!!! warning "이 수치는 확정된 목표가 아닙니다"
    아래 정량 목표는 **기준선 확정 전 잠정치**입니다. 제조 Use Case·소재군·Robot·
    실증환경이 확정되고 기준 데이터를 실측한 뒤 **컨소시엄 공통 KPI 로 동결**합니다.
    **확정 전에는 협약 목표로 인용하지 않습니다.**

    성과지표(논문·특허·SW 등록) 역시 연구개발비 규모와 참여 인력을 전제로 한 값이며,
    **범위가 조정되면 함께 조정**됩니다.

!!! info "함께 읽을 것"
    과제 개요·아키텍처·세부 R&R 은 **[대표 페이지](index.md)**,
    기술 근거와 수행 역량은 **[기술 상세](technical.md)** 에 있습니다.

## 확정된 주요 역할

2026-08-29 주관사 통보로 한성대학교의 담당 분야는 **실환경–가상환경 연계형 데이터 증강**,
주요 역할은 다음 네 가지로 확정되었습니다.

| # | 주요 역할 |
|:--:|---|
| ① | **Real-to-Sim-to-Real 고도화(디지털 트윈)** |
| ② | **Zero-shot Transfer 기반 도메인 적응** |
| ③ | **엣지 케이스 시뮬레이션** |
| ④ | **학술 연구 및 기술 자문** |

기간은 **43개월 · 4개 차년도** 로, **1차 9개월 · 2차 10개월 · 3차 12개월 · 4차 12개월** 입니다.

한성대학교는 **대규모 World Foundation Model(WFM)을 자체 개발하지 않습니다.**
검증된 선도모델을 제조 도메인에 적용하고 그 결과를 **Physics Twin 으로 물리적으로 검증**하는
**Foundation Model 활용형 시스템 설계·오케스트레이션·검증**에 집중합니다.

> **World Model 은 가능성을 생성하고, Physics Twin 은 물리를 검증하며,
> Real Robot 은 현장 유효성을 실증한다.**

## 연차별 목표와 예상 결과물

각 차년도는 **목표 → 핵심 결과물 → 정량 목표 → 성과지표** 순으로 정리했습니다.
정량 목표는 **기준선 확정 전 잠정치**이며, Use Case·소재군·Robot·실증환경이 확정되고
기준 데이터를 실측한 뒤 컨소시엄 공통 KPI로 동결합니다. **확정 전에는 협약 목표로
인용하지 않습니다.**

### 1차년도 (9개월) — 기준 시스템과 인터페이스 확보

> **목표** — WFM 과 Physics Twin 을 잇는 기준 아키텍처를 세우고, **같은 입력이 같은
> 결과를 내는 상태**를 만든다. 재현되지 않는 환경 위에서는 뒤의 모든 검증이 무의미하다.

**핵심 결과물**

| # | 결과물 | 내용 |
|:--:|---|---|
| 1 | **WFM–Physics Twin Reference Architecture** | 계층 정의, 데이터 흐름, 책임 경계 |
| 2 | **Scene–Action–State–Event 표준 v1** | 5개 Descriptor 스키마와 교환 규약 |
| 3 | **Model Adapter v1 · Capability Registry v0** | Cosmos 계열 로컬 추론 연동, 모델 능력·라이선스·요구사양 등록 |
| 4 | **Domain Gap 측정 프로토콜 v1** | 시각·물리·센서·제어 4개 축의 격차 정의와 측정 절차 |
| 5 | **Edge Case Taxonomy v1 · Scenario DSL 명세 초안** | 8개 구분의 제조 Edge Case 분류체계 |
| 6 | 기준 공정 Digital Twin v0 | 단일 제조작업 대상 |

**정량 목표 (잠정)**

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| **생성 재현성** | 동일 Seed·모델버전·조건에서 재실행 시 **동일 결과 100 %** | 해시 대조 |
| **스키마 왕복 정합** | Scene–Action–State–Event 로 표현한 시나리오가 Physics Twin 으로 손실 없이 전달되는 비율 **≥ 95 %** | 필드 단위 대조 |
| Adapter 연동 | Cosmos 계열 **T2W·I2W·V2W 3개 모드 전부** 로컬 추론 성공 | 모드별 실행 로그 |
| Taxonomy 커버리지 | 제조 Edge Case **8개 구분 전부** 정의, 구분당 시나리오 후보 **≥ 5건** | 후보 목록 |
| 실행환경 검증 | GPU·CUDA·Docker 호환성 검증 완료 — **CUDA 12.8 / 13.0 두 계통** | 검증 보고서 |

**성과지표**

| 구분 | 목표 |
|---|---|
| 학술발표 | 국내 학술발표 **1건** |
| 기술문서 | 기술동향·라이선스 검토 보고서 **1건**, 공통 Interface 자문 의견서 **1건** |

**완료 판정** — 동일 입력조건의 생성·검증 이력이 재현되고, WFM 결과가 제조 Scene 구조로
변환되어 Physics Twin 에 전달되며, 기본 HIL 데이터 연동이 확인됩니다.

### 2차년도 (10개월) — Physics Grounding 과 증강 엔진

> **목표** — 생성결과가 물리적으로 말이 되는지 **자동으로 판정**하고, 제조환경 변동성을
> 체계적으로 만들어내는 증강 엔진을 세운다.

**핵심 결과물**

| # | 결과물 | 내용 |
|:--:|---|---|
| 1 | **Prompt·Condition Compiler v1** | 구조화된 제조조건 → Text·Image·Video·Action Condition 변환 |
| 2 | **Physics Consistency Evaluator v1** | 생성결과의 물리 정합성 자동 판정 |
| 3 | **제조 Domain Variation Library v1** | 시각·물리·동역학 변동조건 집합 |
| 4 | **Transferability Score v1 · OOD 판단모듈** | 미학습 환경 차이의 정량화 |
| 5 | **Edge Case Compiler v1 · Scenario Orchestrator** | Scenario DSL → 실행 가능한 생성·검증 작업 |
| 6 | WFM 오류사례 · Physics Gap 사례 DB | 검증 실패결과의 구분 축적 |

**정량 목표 (잠정)**

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| **비물리 결과 자동 검출률** | 물리적으로 불가능한 생성결과의 자동 식별 **≥ 85 %** | 전문가 라벨 대비 |
| **오검출률(False Positive)** | 물리적으로 타당한 결과를 잘못 배제하는 비율 **≤ 15 %** | 전문가 라벨 대비 |
| **접촉력 재현오차** | 기준 시편 접촉력–변위 시험 대비 **NRMSE ≤ 20 %** | 실측 대조 |
| Domain Variation 축 | 변동조건 **≥ 8개 축**, 축당 수준 **≥ 3단계** | Library 명세 |
| 조건 준수율 | 지시한 재질·조명·Pose·배치가 생성물에 반영된 비율 **≥ 70 %** | 분기 표본 100건 육안 검수 |
| Edge Case 자동 생성 | Taxonomy 구분당 시나리오 자동 생성 **≥ 20건** | 생성 로그 |

**성과지표**

| 구분 | 목표 |
|---|---|
| 논문 | **SCI(E)급 1편 이상** 투고, 국내외 학술발표 **2건** |
| 특허 | 국내 출원 **1건** (Physics Consistency 판정 방법) |
| SW | 프로그램 등록 **1건** (Prompt·Condition Compiler) |

**완료 판정** — 비물리적 생성결과가 자동으로 걸러지고, 환경변화에 따른 정책 성능저하가
정량화되며, 실측 데이터 기반 Physics Parameter 보정이 이루어집니다.

### 3차년도 (12개월) — 전이 판정과 HIL 검증

> **목표** — 「추가 학습 없이 실물에서 쓸 수 있는가」를 **수치로 답한다.** 그리고 그 답을
> 시뮬레이션이 아니라 제어기·통신이 물린 HIL 에서 확인한다.

**핵심 결과물**

| # | 결과물 | 내용 |
|:--:|---|---|
| 1 | **Transfer Decision Manager** | 5단계 적용전략 자동 분류 (직접 적용 / 경량 적응 / Few-shot·LoRA / 추가 검증 / 적용 보류) |
| 2 | **Zero-shot Transfer 평가 리포트** | 증강 기법별 기여도 Ablation 포함 |
| 3 | **Simulation–HIL–Real Robot 인터페이스** | 제어주기·통신·센서 연계 규약 |
| 4 | **Multi-stage Validation Gate (6단계)** | Gate 1~6 판정 기준과 자동화 |
| 5 | **Edge/Recovery 증강 Dataset · Failure Boundary 분석** | 실패 경계 조건 식별 |
| 6 | Physics Calibration 결과 · Sim–Real Gap Model | 실측 기반 보정 |

**정량 목표 (잠정)**

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| **Zero-shot 성능 유지율** | 미학습 환경에서 기준환경 대비 작업성공률 **≥ 70 %** | 동일 정책, 환경만 변경 |
| **경량 적응 후 성능** | LoRA·Few-shot 적용 시 기준환경 대비 **≥ 90 %** | 동일 정책 |
| **Transfer Decision 정확도** | 실제 전이 성공·실패와 사전 판정의 일치율 **≥ 80 %** | 사후 대조 |
| **OOD 탐지율** | 학습분포 밖 조건의 사전 탐지 **≥ 85 %**, 오탐 **≤ 20 %** | 라벨 대조 |
| **Sim–Real 일치도** | 접촉력·궤적의 시뮬레이션–실물 상대오차 **≤ 25 %** | HIL·실물 대조 |
| Validation Gate 운영 | Gate 1~6 **전 단계 자동 판정**, 통과 이력 100 % 추적 | 검증 DB |
| HIL 실시간성 | 제어주기 이탈률 **≤ 5 %** | HIL 로그 |

**성과지표**

| 구분 | 목표 |
|---|---|
| 논문 | **SCI(E)급 1편 이상**, 국내외 학술발표 **2건** |
| 특허 | 국내 출원 **1건** (Transfer 적용 판정 방법), 이전 출원 건 **등록 추진** |
| SW | 프로그램 등록 **1건** (Edge Case Compiler 또는 Validation Gate) |
| 자문 | RFM 평가기준 자문 의견서 **1건** |

**완료 판정** — Edge Case Taxonomy 별 시나리오가 자동 생성되고, 주요 실패유형이 Physics
Twin 에서 재현되며, HIL 에서 정책 취약조건이 확인되고 실패 원인이 추적 가능해집니다.

### 4차년도 (12개월) — 고도화·표준화와 Closed-loop 완성

> **목표** — 우리가 아니어도 같은 순환이 돌게 만든다. **절차서와 벤치마크로 남기는 것**이
> 4차년도의 성과다.

**핵심 결과물**

| # | 결과물 | 내용 |
|:--:|---|---|
| 1 | **Real-to-Sim-to-Real 운용 가이드라인** | 타 기관이 재현 가능한 절차서 |
| 2 | **Cross-domain Physical AI Benchmark** | 공정·대상물 교차 평가 체계 |
| 3 | **Robust Operating Envelope 평가모듈** | 안정 동작 범위의 정량 도출 |
| 4 | **Closed-loop Validation RoboOps Toolchain** | 데이터–시나리오–모델–검증 순환 자동화 |
| 5 | **Capability Registry 최종본** | 모델 교체·버전변경 대응절차 포함 |
| 6 | **기술 백서 · 표준 제안서** | Scene–Action–State–Event 스키마, Validation Gate 절차 |

**정량 목표 (잠정)**

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| **재학습–재검증 Loop** | 전주기 **1회 완주**(기본안), 확장 시 2회 이상 | 실행 이력 |
| **Edge Case Coverage** | Taxonomy 대비 검증 완료 비율 **≥ 80 %** | Coverage Dashboard |
| **절차 재현성** | 제3자가 가이드라인만으로 기준 시나리오 재현 성공 **≥ 90 %** | 재현 시험 |
| **모델 교체 대응** | 기준 모델 교체 시 **Adapter·Capability Profile 수정만으로** 동작 | 교체 시험 |
| Operating Envelope | 대상 Task 별 안정 동작 범위 정량 제시 **전 Task** | 평가 리포트 |
| 전주기 추적성 | 실로봇 시험 건별 입력조건–모델버전–판정근거 추적 **100 %** | 검증 DB |

**성과지표**

| 구분 | 목표 |
|---|---|
| 논문 | 국내외 학술발표 **2건**, 최종 성과 논문 **1편** |
| 특허 | 등록 **1건 이상** |
| SW | 프로그램 등록 **1건** (RoboOps Toolchain) |
| 표준 | 표준 제안 **1건**, 기술 백서 **1건** |

**완료 판정** — 실로봇 적용 전 Validation Gate 가 작동하고, 실증결과가 자동 수집·분석·환류되며,
Simulation–HIL–Real Robot 전주기 추적성이 확보됩니다.
