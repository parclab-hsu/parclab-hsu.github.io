# 현대자동차 L-Project — 지형 변형 엔진 고도화 (차년도 과제 제안)

:material-circle:{ style="color:#f0ad4e" } **제안** · 월면토 침하·바퀴자국 모델 · 기준일 **2026-09-07**

!!! abstract "요약"
    달 탐사 로버 HILS 의 플랜트는 지금 **완전 강체 지형** 위에서 돕니다. 월면토는 밟으면
    꺼지는데, 그 층이 비어 있습니다.

    지형 변형 기능 자체는 시뮬레이터(OmniLRS)에 있습니다. 그런데 **실측해 보니 켤 수 없는
    상태**였습니다 — 현행 설정으로는 12 m 를 달려도 지형이 **한 칸도 바뀌지 않고**, 발자국
    폭을 실측값으로 고치면 이번에는 **로버가 파묻혀 움직이지 못합니다.**

    막는 원인 **네 가지를 모두 특정**했고 계측 도구도 만들어 두었습니다. 차년도 과제로
    이것을 정식화해 **근거 있는 침하 모델**로 만들 것을 제안합니다.

## 1. 왜 필요한가

달 탐사 로버의 주행 성능은 **토양이 어떻게 꺼지는가**에 크게 좌우됩니다. 아폴로·VIPER
기록이 공통으로 말하는 것은 바퀴가 레골리스를 밀어내며 만드는 자국과 그에 따른 견인력
변화입니다. 지금 저희 플랜트는 그 층이 없는 **단단한 달** 위에서 돌고 있습니다.

그 위에서 얻은 슬립·견인·자세 수치는 **강체 지형의 값**입니다. 차년도에 자율 주행이나
크레이터 탈출 거동을 다루려면 이 층을 먼저 세워야 합니다.

!!! info "지금이 착수 시점인 이유"
    2026-08-25 에 오래 미해결이던 계측 문제(D-31)가 풀리면서, **이 플랜트의 슬립이 사실상
    0 임을 확인**했습니다. 변형을 켰을 때 생기는 변화를 **깨끗하게 귀속시킬 수 있는
    기준선**이 이번에 처음 확보되었습니다.

## 2. 현재 상태 — 켤 수 없다

기능을 실제로 켜고 로버를 몰면서 측정했습니다(2026-08-26). 같은 지령·같은 시간으로
두 조건을 돌린 결과입니다.

| | 현행 설정 | 발자국 폭만 실측 휠 폭으로 |
|---|---|---|
| **로버 이동 거리** | **12.156 m** | **0.054 m** |
| 지형에서 변한 격자 칸 | **0** | 40 → 49 |
| 최대 침하 | **0.000000 m** | 0.208 m |
| 연산 비용 | 30 → **26.5 Hz** (−12 %) | — |

**두 상태 다 사용할 수 없습니다.**

- 현행 설정은 **비용만 지불하고 지형이 전혀 바뀌지 않습니다.** 근사적으로 0 이 아니라
  정확히 0 이며, **오류도 나지 않습니다** — 그래서 "변형을 켰다"고 믿는 상태가 됩니다.
- 발자국 폭을 실측 휠 폭으로 고치면 변형은 발생하지만, 로버가 **자기 구덩이를 파고
  갇힙니다.** 한 번의 계산이 만드는 침하가 휠 반경과 같은 자릿수입니다.

## 3. 막는 원인 네 가지 — 전부 특정되어 있다

추정이 아니라 계측 결과입니다. 지형이 안 변하는 이유는 세 갈래(접지력 없음 · 침하량 0 ·
좌표 범위 밖)인데 **겉으로는 모두 똑같이 보이기 때문에**, 세 값을 한 기록에 함께 남기는
도구를 만들어 갈랐습니다.

| # | 원인 | 근거 |
|---|---|---|
| ① | **발자국 폭이 격자 두 칸보다 좁아** 경계 분포가 전부 0 | 접지력이 **최대 734 N** 으로 충분히 들어오는데 침하가 0 — 힘도 좌표도 아님 |
| ② | **힘–침하 관계식의 출처가 없다** | 어떤 토양·휠·중력에서 맞춘 계수인지 자료가 없고, 접촉력이 0 일 때도 침하가 나오는 형태 |
| ③ | 정지 상태에서 접지력이 **0 으로 읽혀**, 침하가 하중이 아니라 **충격**에 비례 | 실제 바퀴자국과 반대 방향. 무거울수록이 아니라 흔들릴수록 깊어짐 |
| ④ | **스폰 낙하 충격이 지형에 새겨짐** | 주행 시작 전에 이미 **21 cm 깊이**가 생기고 로버가 그 안에서 출발 |

③ 에 대해서는 **대체 계측 경로를 이미 확인**했습니다. 접지력이 0 으로 읽히는 바로 그
상태에서 서스펜션 조인트의 하중 신호는 살아 있었고(표준편차 0.000), 네 바퀴 합이
**기대 자중의 1.08 배**로 나왔습니다. 정적 하중 정보가 그쪽에는 있습니다.

!!! warning "다만 정확히 해 둡니다"
    위 1.08 배는 **정보가 존재한다는 근거**이지 환산식이 완성되었다는 뜻이 아닙니다.
    좌우 부호가 갈리므로 서스펜션 4절 링크 기구학을 거쳐야 실제 바퀴 하중이 됩니다.
    그 작업이 아래 WP1 입니다.

## 4. 제안하는 작업 범위

| WP | 내용 | 선행 |
|---|---|---|
| **WP1** | **하중 계측 경로 교체** — 접지력 대신 서스펜션 하중에서 역산. 4절 링크 기구학 반영 | — |
| **WP2** | **힘–침하 관계 재수립** — 지반공학 문헌(Bekker·Wong 계열) 기반 재정식화. 달 중력·그라우저 휠 조건 명시 | WP1 |
| **WP3** | **발자국 기하 산정** — 접지 폭·길이를 접지 역학에서 결정. 길이는 침하량의 함수라 상수로 둘 수 없음 | WP2 |
| **WP4** | **시작 조건 정비** — 낙하·안착 종료 후 변형 개시 | — |
| **WP5** | **격자 해상도 재검토** — 현재 해상도에서 휠 폭이 4 칸뿐이라 자국 형상이 매우 거칢 | WP3 |
| **WP6** | **연산 성능** — 현재 40 칸을 바꾸기 위해 정점 배열 전체를 매 스텝 다시 씀 | — |
| **WP7** | **검증** — 실측 바퀴자국(깊이·폭·형상)과 대조 | **토질 시험 자료** |

!!! danger "WP7 이 이 과제의 성패를 가릅니다"
    앞의 여섯이 모두 끝나도 **비교할 실측 자료가 없으면**, 「수치는 나오는데 근거가 없는」
    상태가 하나 더 생길 뿐입니다. 이번 분석에서 확인된 원인 ② 가 정확히 그 모양이었습니다.

    **월면토 시뮬런트 바퀴자국 시험 자료 확보를 과제 범위에 포함**해 주시기를 요청드립니다.
    시뮬런트 종류·하중 조건·그라우저 형상이 저희 로버와 맞아야 대조가 성립합니다.

## 5. 기대 효과

- **주행 성능 예측의 근거 확보** — 슬립·견인력·등판 한계를 강체 지형이 아닌 조건에서 산출
- **크레이터 탈출 거동 연구의 전제** — 탈출은 토양이 무너지는 거동에 크게 좌우되므로,
  강체 지형에서 얻은 결과는 실기로 옮기기 어렵습니다
- **누적 주행 영향 평가** — 반복 통과로 생긴 자국이 이후 주행에 미치는 영향
- **HILS 플랜트 충실도 향상** — 제어기가 마주하는 부하 조건이 실제에 가까워집니다

## 6. 확인되지 않은 것

!!! note "이 절을 함께 읽어 주십시오"
    아래는 이 과제로도 **확인할 수 없는 범위**입니다. 과제 종료 시 무엇이 남는지를
    미리 밝혀 둡니다.

- **실제 월면 레골리스가 아닙니다.** 지상 시뮬런트 기준이며, 진공·정전기·입도 이력 등
  실제 레골리스의 조건은 재현하지 않습니다.
- **실물 로버가 없습니다.** 검증은 시뮬레이터 내부에서, 문헌 및 토질 시험 자료와의
  대조로만 수행합니다. 실기 주행으로 확인한 결과가 아닙니다.
- **토질 시험 자료가 확보되지 않으면 WP7 이 성립하지 않습니다.** 그 경우 모델은
  「문헌 기반 정식화」까지이며, 검증된 모델이라고 부를 수 없습니다.
- 시뮬레이터 상류(OmniLRS) 구조 변경이 포함될 수 있어, 포크 유지 부담이 늘어납니다.
- 현재 플랜트는 **실시간의 약 절반 속도**로 동작합니다. 이 조건은 별개 사안이며 이
  과제의 범위가 아닙니다 — 다만 측정은 모두 시뮬레이션 시간 기준으로 수행합니다.

## 7. 준비된 것

과제 착수 시 바로 사용할 수 있는 상태로 정리되어 있습니다.

| 항목 | 상태 |
|---|---|
| 원인 분석 문서 | 8 개 절, 상류 소스 결함 2 건 포함 |
| 계측 도구 | 접지력·침하·좌표·지형 변화·로버 이동을 한 기록에 남김 |
| 실동작 검증 원자료 | 2 조건, 호출 단위 기록 |
| 성능 측정 자료 | 4 조건(변형 ON/OFF × 정지/주행), 구간 분포 포함 |
| 로버 자산 실측 | 그라우저 **24 개**, 높이 19.1 mm, 휠 반경 0.2134 m |
| 기준선 | 강체 지형 슬립 ≈ 0 (2026-08-25 확인) |

!!! tip "부수적으로 확인된 것"
    설정의 그라우저 관련 계수가 **13 개에 해당하는 값**으로 들어가 있었습니다. 자산에서
    실측한 그라우저는 **24 개**이며, 접지 길이를 반영한 올바른 값은 다릅니다. 다만
    **접지 길이 자체에 근거가 없어**, 값만 바꾸는 것으로는 해결되지 않습니다(WP3).
