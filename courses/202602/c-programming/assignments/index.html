    주차별 과제와 제출 예시¶

    C 프로그래밍 · 미래모빌리티학과 1학년 2학기 | 평가 비중 C 프로그램 과제 10% 매주 한 건씩, 총 13건을 제출한다. 8주차(중간고사)와 15주차(기말 프로젝트)는 별도 규정을 따른다.

    이 페이지는 다른 문제들과 무엇이 다른가¶

    이 강의에는 성격이 다른 문제가 네 종류 있다. 헷갈리지 않도록 정리한다.

    종류 어디서 언제 제출
    연습문제 각 주차 강의 페이지 끝 수업 직후 자가 점검 없음 (정답 공개)
    🔥 도전 문제 주차별 운영안 수업 2시간(실습) 중 없음 (힌트·정답 공개)
    주차 과제 이 페이지 다음 주 수업 전까지 제출 (채점)
    설계 문제 프로그램 설계 문제 학기 중 자율·기말 대비 선택 (가산점)

    주차 과제는 그 주에 배운 것만으로 풀 수 있게 설계했다. 아직 배우지 않은 문법을 쓸 필요는 없다.

    1. 제출 규정¶

    제출물 세 가지¶

    과제 하나에 아래 세 가지를 한 폴더에 담아 압축해 제출한다.

    1. 소스 파일 .c — 파일 하나로 완결되어야 한다.
    2. 실행 결과 — 콘솔 캡처 이미지 또는 붙여넣은 텍스트. 요구된 입력 예를 전부 실행한 결과여야 한다.
    3. 회고 3줄 — 아래 세 문장을 그대로 채운다.
    4. 막힌 곳: …
    5. 해결 방법: …
    6. AI를 쓴 부분과 내가 검증한 방법: …

    파일명 규칙¶

    w05_2026123_홍길동.c
w05_2026123_홍길동.zip

    w + 두 자리 주차 + 학번 + 이름. 폴더째 압축한 .zip으로 올린다. 규칙을 지키지 않으면 채점이 누락될 수 있다.

    소스 첫머리에 넣을 주석¶

    /* ============================================================
   5주차 과제 · 충전소 요금 계산기
   미래모빌리티학과 2026123 홍길동
   환경: Visual Studio 2022 (C17) / Windows 11
   빌드: 경고 0개
   ============================================================ */

    마감¶

    다음 주차 수업 전날 23:59. 지각 제출은 3일까지 받고 하루당 20%를 감점한다. 4일 이상 지각은 0점이다.

    빌드 기준¶

    • Visual Studio 2022에서 경고 없이 빌드되어야 한다. 경고가 남아 있으면 감점한다.
    • 입력 함수는 강의 기준대로 scanf_s()를 쓴다. scanf_s()는 Visual Studio 전용이므로, 다른 컴파일러에서 확인할 때는 scanf()로 바꿔야 한다(환경 설정 가이드 참고).
    • 컴파일이 안 되는 코드는 0점이다. 완성하지 못했더라도 반드시 컴파일되는 상태로 제출하고, 못 한 부분을 회고에 적는다. 부분 점수를 받을 수 있다.

    AI 활용¶

    AI 사용은 허용한다. 다만 세 가지를 지킨다.

    • 제출한 코드의 모든 줄을 설명할 수 있어야 한다. 설명하지 못하면 점수를 인정하지 않는다.
    • 회고에 어디를 AI로 썼고 무엇을 어떻게 검증했는지 적는다. 안 썼으면 "안 씀"이라고 적는다.
    • AI가 준 코드를 그대로 붙여넣고 검증하지 않아 생긴 오류는 감점 사유다. 자세한 원칙은 AI 활용 가이드를 따른다.

    표절

    다른 사람의 코드를 그대로 낸 경우, 준 쪽과 받은 쪽 모두 해당 과제 0점이다. 같이 공부하는 것은 권장하지만, 코드는 각자 손으로 쓴다.

    2. 채점 루브릭¶

    주차 과제는 모두 10점 만점이며 같은 기준으로 채점한다.

    항목 배점 무엇을 보는가
    동작 4점 요구된 입력 예에서 기대한 출력이 나오는가
    요구사항 충족 2점 빠뜨린 조건이 없는가
    경계·예외 처리 2점 0, 음수, 범위 밖, 나누기 0을 다루는가
    가독성 1점 이름, 들여쓰기, 상수화, 주석
    회고 1점 세 줄이 구체적인가

    경계 처리 2점은 매주 나온다

    가장 많이 놓치는 항목이다. 과제를 다 짠 뒤 0을 넣어 보고, 음수를 넣어 보고, 범위 밖 값을 넣어 보는 습관을 들이자. 이 2점이 학기 내내 누적된다.

    3. 제출 예시 (전문)¶

    아래는 7주차 수업에서 함께 만든 예제를 제출 형식에 맞춰 정리한 것이다. 과제의 정답이 아니라 제출물의 모양을 보여 주기 위한 예시다. 여러분의 제출물도 이 정도 구성이면 충분하다.

    3.1 예시 과제¶

    세 과목 점수를 입력받아 총점·평균·등급을 출력하라. 점수는 0~100이어야 하고, 범위를 벗어나면 다시 입력받는다.

    3.2 제출 소스 — w07_2026123_홍길동.c¶

    /* ============================================================
   과제 예시 · 점수 입력과 등급 계산
   미래모빌리티학과 2026123 홍길동
   환경: Visual Studio 2022 (C17) / Windows 11
   빌드: 경고 0개 (수준 4)
   ============================================================ */

#include <stdio.h>

#define SUBJECT_COUNT 3
#define SCORE_MIN     0
#define SCORE_MAX     100

/* 점수 하나를 입력받는다. 범위를 벗어나면 다시 묻는다. */
int input_score(const char *subject)
{
    int score = 0;

    while (1) {
        printf("%s 점수(0~100): ", subject);

        if (scanf_s("%d", &score) != 1) {
            printf("  숫자가 아닙니다. 다시 입력하세요.\n");
            while (getchar() != '\n') { /* 입력 버퍼 비우기 */ }
            continue;
        }
        if (score < SCORE_MIN || score > SCORE_MAX) {
            printf("  0~100 사이여야 합니다. 다시 입력하세요.\n");
            continue;
        }
        return score;
    }
}

int total_of(const int scores[], int count)
{
    int sum = 0;

    for (int i = 0; i < count; i++) {
        sum += scores[i];
    }
    return sum;
}

/* 정수 나눗셈으로 소수점이 잘리지 않도록 double 로 계산한다. */
double average_of(int total, int count)
{
    return (double)total / count;
}

char grade_of(double average)
{
    if (average >= 90.0) return 'A';
    if (average >= 80.0) return 'B';
    if (average >= 70.0) return 'C';
    if (average >= 60.0) return 'D';
    return 'F';
}

int main(void)
{
    const char *subjects[SUBJECT_COUNT] = { "국어", "영어", "수학" };
    int scores[SUBJECT_COUNT] = { 0 };

    for (int i = 0; i < SUBJECT_COUNT; i++) {
        scores[i] = input_score(subjects[i]);
    }

    int total = total_of(scores, SUBJECT_COUNT);
    double average = average_of(total, SUBJECT_COUNT);
    char grade = grade_of(average);

    printf("\n");
    printf("과목   점수\n");
    printf("------------\n");
    for (int i = 0; i < SUBJECT_COUNT; i++) {
        printf("%-6s %4d\n", subjects[i], scores[i]);
    }
    printf("------------\n");
    printf("총점   %4d\n", total);
    printf("평균   %6.2f\n", average);
    printf("등급   %4c\n", grade);

    return 0;
}

    3.3 실행 결과¶

    정상 입력 — 90, 85, 95

    국어 점수(0~100): 90
영어 점수(0~100): 85
수학 점수(0~100): 95

과목   점수
------------
국어     90
영어     85
수학     95
------------
총점    270
평균    90.00
등급      A

    범위 밖 입력 — 150, -3을 먼저 넣어 재입력이 도는지 확인

    국어 점수(0~100): 150
  0~100 사이여야 합니다. 다시 입력하세요.
국어 점수(0~100): -3
  0~100 사이여야 합니다. 다시 입력하세요.
국어 점수(0~100): 60
영어 점수(0~100): 70
수학 점수(0~100): 50

과목   점수
------------
국어     60
영어     70
수학     50
------------
총점    180
평균    60.00
등급      D

    한글 열이 어긋나 보이면 인코딩 문제다

    printf("%-6s", "국어")의 폭은 글자 수가 아니라 바이트 수로 센다. 위 결과는 한글 한 글자가 2바이트인 CP949 기준이다. 소스를 BOM 없는 UTF-8로 저장하면 한글이 3바이트가 되어 열이 밀린다.

    파일을 UTF-8 with BOM으로 저장하면 Visual Studio 2022와 VS Code 양쪽에서 위와 같이 나온다(환경 설정 가이드 6.6절). 열을 확실히 맞추고 싶으면 항목명을 Kor, Eng, Math처럼 영문으로 두는 방법도 있다.

    3.4 경계값 확인표¶

    이 표까지 넣으면 "경계·예외 처리 2점"은 확보한 셈이다.

    입력 기대 실제 확인
    90, 85, 95 평균 90.00 · A 90.00 · A ✅
    60, 70, 50 평균 60.00 · D 60.00 · D ✅
    0, 0, 0 평균 0.00 · F 0.00 · F ✅
    100, 100, 100 평균 100.00 · A 100.00 · A ✅
    150 입력 재입력 요구 재입력 요구 ✅
    −3 입력 재입력 요구 재입력 요구 ✅
    문자 abc 입력 재입력 요구 재입력 요구 ✅

    3.5 회고 3줄¶

    • 막힌 곳: 85, 90, 96을 넣으면 평균이 90.33이어야 하는데 90.00으로 나왔다. 총점 271을 int / int로 나눠서 소수점이 버려진 것이었다.
    • 해결 방법: (double)total / count로 한쪽을 실수로 바꿔서 실수 나눗셈이 되게 했다. 4주차에 배운 형 변환이었다.
    • AI를 쓴 부분과 내가 검증한 방법: 입력이 숫자가 아닐 때 무한 루프가 도는 이유를 AI에게 물어 getchar()로 버퍼를 비우라는 답을 받았다. 그대로 믿지 않고 abc를 직접 넣어 재입력이 정상으로 도는 것을 확인했고, 버퍼 비우는 줄을 지웠을 때 실제로 무한 루프가 나는 것도 확인했다.

    이 예시에서 눈여겨볼 것

    • while (1) 안에서 조건을 만족할 때만 return — 재입력 구조의 기본형
    • 90, 85 같은 숫자를 코드에 흩뿌리지 않고 #define으로 이름 붙임
    • 함수 하나가 하나의 일만 함 (입력 / 합계 / 평균 / 등급)
    • 회고에 무엇을 어떻게 확인했는지가 구체적으로 적힘

    과제 11 · 포인터로 값 바꾸기 (12주차) ⭐⭐¶

    목표 — 주소와 값의 차이를 코드로 확인하고, 함수가 호출자의 변수를 바꾸는 방법을 익힌다.

    요구사항

    1. void swap(int *a, int *b);를 만들어 두 변수의 값을 교환한다. 교환 전후를 출력한다.
    2. 포인터를 쓰지 않는 swap_wrong(int a, int b)도 만들어, 왜 안 바뀌는지 출력으로 보인다.
    3. int *max_pos(int *arr, int n); — 배열에서 최댓값이 있는 자리의 주소를 반환한다. 호출한 쪽에서 그 주소를 이용해 값과 인덱스를 모두 출력한다.
    4. int 배열의 각 원소 주소를 출력해, 주소가 4씩 증가하는 것을 보인다. char 배열로도 같은 것을 해 1씩 증가함을 비교한다.
    5. 널 포인터를 넘겼을 때 함수가 죽지 않도록 if (arr == NULL) return NULL;을 넣는다.

    입출력 예

    교환 전: a=10, b=20
swap_wrong 후: a=10, b=20   ← 안 바뀐다
swap 후      : a=20, b=10

배열: 30 70 20 90 50
최댓값 90 (인덱스 3, 주소 0x7ffd...)

int  배열 주소: 0x7ffd1000 0x7ffd1004 0x7ffd1008  (4씩)
char 배열 주소: 0x7ffd2000 0x7ffd2001 0x7ffd2002  (1씩)

    제출물 — 소스 .c, 실행 결과, 회고 3줄

    흔한 감점 — swap 안에서 a = b;처럼 포인터 자체를 바꿈(*a = *b;여야 한다) · 주소 출력에 %d를 씀(%p를 쓴다)

    과제 12 · 한 번에 여러 값 돌려받기 + 재귀 (13주차) ⭐⭐⭐¶

    목표 — 반환값이 하나뿐인 C에서 여러 결과를 받는 방법과, 재귀의 탈출 조건을 익힌다.

    요구사항

    1. void analyze(const int a[], int n, int *min, int *max, double *avg); — 한 번 호출로 세 값을 모두 돌려받는다.
    2. 재귀 함수 두 개를 만든다.
    3. long long factorial_r(int n);
    4. int sum_to_r(int n); — 1부터 n까지의 합
    5. 같은 기능을 반복문 버전으로도 만들어, 두 결과가 같은지 출력으로 비교한다.
    6. 재귀의 탈출 조건을 주석으로 명시한다. 탈출 조건을 지웠을 때 무슨 일이 일어나는지 회고에 쓴다. (실제로 지워서 실행해 볼 것 — 스택 오버플로로 죽는다)
    7. factorial_r(21)처럼 큰 값을 넣으면 결과가 이상해진다. 왜 그런지 회고에 한 줄로 쓴다.

    입출력 예

    배열: 45 12 78 33 60
  최소 12 / 최대 78 / 평균 45.60

factorial(10) 재귀 = 3628800
factorial(10) 반복 = 3628800   일치 ✅

sum_to(100) 재귀 = 5050
sum_to(100) 반복 = 5050        일치 ✅

factorial(21) = -4249290049419214848   ← long long 범위 초과

    제출물 — 소스 .c, 실행 결과, 회고 3줄(탈출 조건 제거 실험 + 오버플로 설명 포함)

    흔한 감점 — 포인터 매개변수에 NULL 검사가 없음 · 재귀와 반복 결과를 비교하지 않고 각각만 출력

    과제 13 · 센서 패킷 구조체 (14주차) ⭐⭐⭐¶

    목표 — 관련된 값을 하나로 묶고, 문자열로 바꿨다가 되돌린다.

    요구사항

    1. 구조체를 정의한다.
    typedef struct {
    int   id;
    char  state[16];
    float distance_cm;
    float speed_cmps;
} SensorPacket;
    1. 패킷 5개를 배열에 담고, 거리에 따라 state를 채운다. 15cm 미만 STOP, 30cm 미만 SLOW, 그 외 RUN.
    2. void print_packet(const SensorPacket *p); — 포인터와 ->로 접근한다. 값 복사로 넘기지 않는다.
    3. void to_line(const SensorPacket *p, char *out, int out_size); — "3,RUN,42.0,25.0" 형태의 한 줄 문자열로 만든다.
    4. int from_line(const char *line, SensorPacket *p); — 그 문자열을 다시 구조체로 되돌린다. 성공하면 1, 실패하면 0을 반환한다.
    5. 5개 패킷을 문자열로 바꿨다가 되돌려, 원본과 같은지 출력으로 확인한다.

    문자열 복사는 반드시 크기를 정해서

    state는 char[16]이다. strcpy()는 크기를 검사하지 않으므로 긴 문자열이 들어오면 그대로 넘쳐 쓴다. 이 과제에서는 snprintf(p->state, sizeof(p->state), "%s", ...) 를 쓴다. 문자열을 읽을 때도 sscanf의 폭 지정자 %15[^,]처럼 최대 길이를 반드시 적는다. 14주차 강의의 버퍼 오버플로 경고를 다시 읽어 볼 것.

    입출력 예

    [원본]
 #1 id=1 state=STOP  dist= 12.0 speed=  0.0
 #2 id=2 state=SLOW  dist= 22.5 speed= 10.0
 #3 id=3 state=RUN   dist= 42.0 speed= 25.0
 ...

[직렬화]
 1,STOP,12.0,0.0
 2,SLOW,22.5,10.0
 3,RUN,42.0,25.0

[역직렬화 검증]
 #1 일치 ✅  #2 일치 ✅  #3 일치 ✅  #4 일치 ✅  #5 일치 ✅

    제출물 — 소스 .c, 실행 결과, 회고 3줄

    흔한 감점 — strcpy를 크기 검사 없이 사용(감점) · 구조체를 값으로 복사해 함수에 넘김 · 파싱 실패를 검사하지 않아 쓰레기 값이 들어감

    15주차 · 기말 프로젝트 (팀)¶

    주차 과제가 아니라 프로젝트 평가 20%에 해당한다. 규정이 다르다.

    항목 내용
    인원 3~4인 팀
    주제 프로그램 설계 문제 6선 중 택1, 또는 팀 자체 주제(사전 승인)
    필수 배열·포인터·구조체·함수 분해가 모두 들어갈 것
    연동 Arduino 또는 C↔ROS2 연동 중 최소 하나 (C↔ROS2 & Stella N2 로봇)
    제출 설계 노트 · 소스 전체 · 시연 영상(3분 내) · 발표 자료
    발표 팀당 7분 + 질의 3분

    채점은 설계 문제 공통 루브릭을 따른다. 팀 기여도를 발표 자료에 역할별로 명시한다.

    5. 제출 전 자가 점검¶

    제출 버튼을 누르기 전에 이 목록을 지나가자. 여기서 걸리는 것이 감점의 대부분이다.

    • Visual Studio 2022에서 경고 없이 빌드된다
    • 요구사항에 적힌 입출력 예를 전부 실행해 봤다

    • 나누기가 있다면 분모가 0인 경우를 막았다
    • 배열이 있다면 인덱스가 범위를 벗어나지 않는지 확인했다
    • 마법의 숫자를 #define이나 const로 바꿨다
    • 변수 이름만 보고 무슨 값인지 알 수 있다
    • 파일명이 wNN_학번_이름.c 규칙에 맞다
    • 소스 첫머리 주석에 학번·이름·환경이 있다
    • 회고 3줄이 구체적이다 ("어려웠다" ❌ / "정수 나눗셈이라 소수점이 잘렸다" ✅)
    • 내가 쓴 코드의 모든 줄을 설명할 수 있다
