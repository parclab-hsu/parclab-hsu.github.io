    시험 유형과 핵심 정리¶

    이 과목의 시험은 중간 40% + 기말 30% = 70%다. 여기서는 두 시험의 유형·출제 경향·반복 함정을 한 곳에 모았다. 주차별 상세는 각 주차 페이지로 연결된다.

    기출 기준

    아래 분석은 2024·2025·2026-1학기 기출을 정리한 것이다. 2026-2학기 시험 일자는 학사일정에 따라 공지된다.

    1. 두 시험의 성격이 다르다¶

    구분 중간고사 (40%) 기말고사 (30%)
    시기(직전 운영분) 8주차 (2026-1학기 4/23) 15주차 (2026-1학기 6/22)
    범위 1~7주차 · 자율주행 9~14주차 · 드론·도시·로봇
    구성 객관식 20 + 서술형 5 객관식 10 + 서술형
    성격 개념 판단형·비교형 개념 + 계산형
    핵심 역량 정의·구조·제도의 정확한 구분 정량 분석(BPF·FoS·호버링)

    기말은 계산이 나온다

    개론 과목이지만 기말에는 11주차 드론 구조설계에서 세 종류의 계산이 출제된다. 손으로 한 번은 풀어 보고 들어가야 한다. ① BPF(프로펠러 통과주파수) ② 허용응력 = 해석응력 × FoS ③ 호버링 시간 역전의 물리적 설명($P \propto T^{3/2}$)

    2. 연도별 형식 변화¶

    연도 중간고사
    2024 객관식 + 서술형
    2025 객관식 30문항(60점) + 서술형 3문항(10 / 10 / 20점)
    2026 객관식 20문항 + 서술형 5문항(각 상12 / 중8 / 하6점)

    → 문항 수는 줄고, 한 문항의 사고 깊이가 깊어지는 방향이다. 단순 암기보다 개념 간 관계를 묻는다.

    3. 중간고사 서술형 5문항 (2026-1학기 기출) — 대비 지도¶

    # 문항 요지 답안 골격 주차
    1 SAE Level 0~5 단계별 특징·운전자 역할 레벨별 표 + 레벨 3이 책임 경계선임을 명시 5주차
    2 인지–판단–제어 구조와 단계별 기술 SENSE → PERCEIVE/LOCALIZE/MAP → PLAN → CONTROL + 각 단계 예시 기술 3주차
    3 6종 센서 비교 + 안개 야간 시나리오 센서 퓨전 센서별 (원리/출력/장점/단점) 표 → 시나리오별 기여·한계 → 결론(주력 조합) 6주차
    4 V2X 4유형 정의 + 협조주행과 자율주행의 관계 V2V/V2I/V2P/V2G 정의 → 협조주행은 자율주행을 대체가 아닌 보완·확장 7주차
    5 도심 자율주행의 기술·윤리·법제도 도전과제와 해결방안 세 소제목을 그대로 달고 각 1개 이상 + 해결안 7주차

    4. 기말고사 서술형 (2026-1학기 기출) — 대비 지도¶

    # 문항 요지 답안 골격 주차
    1 스마트시티 정의 + '인간 중심'의 사회·기술·정책 의미 정의(ICT·IoT·빅데이터·AI, 효율성·지속가능성·삶의 질) → 3측면 12주차
    2 토크 제어 액추에이터 4종 원리·장단점 유압 / 토크센서 통합 전기 / SEA / QDD 4행 표 14주차
    3 쿼드콥터 공진 정량 분석 + 순차설계 vs 코디자인 BPF 계산 → 151 Hz 판정 → 강성/강도 구분 11주차
    4 휴머노이드 모션 플래닝·제어 설계 고려사항 플래닝(고DoF·충돌회피·ZMP) / 제어(동역학·센서융합·HRI) 14주차
    5 멀티콥터 설계 분석 (호버링 역전 / FoS / 동력원) 3소문항 각각 계산 + 물리적 근거 11주차

    5. 반복 출제 함정 총정리¶

    자율주행 (중간)¶

    함정 정답
    제어 단계에서 수행하지 않는 일 위치(Localization은 판단 단계)
    고성능 자율주행 프로세서를 제조하지 않는 기업 루미나(라이다 업체)
    온도 감지로 야간 인식 가능한 센서 열화상 카메라
    라이다 설명 중 옳지 않은 것 "안개·비·눈에도 정확한 성능 유지"
    CNN 설명 중 옳지 않은 것 "항상 Softmax를 사용해야만 인식 가능"
    객체 탐지 설명 중 틀린 것 "CCTV 영상에서 음성인식 구현 가능"
    경계 상자 추출 설명 중 옳지 않은 것 "Canny가 경계 상자 내부 클래스를 분류"
    임베디드 AI 프로세서 설명 중 옳지 않은 것 "전력 소모가 많아도 괜찮다"
    자율주행자동차 주요 시스템에 해당하지 않는 것 4구성 명칭(위성항법·센서·연산제어·자율주행작동) 정확히 암기
    SAE 조건부 자율주행 레벨 3
    군집주행 통신·이점 조합 V2V — 연료 효율 향상 및 운전자 부담 완화
    군집주행 이점이 아닌 것 운전자의 운전 부담 증가
    커넥티드 카 이점으로 옳지 않은 것 교통 체증 및 사고 발생 빈도 증가
    V2I가 주로 사용되는 목적 교통 사고 예방
    MaaS의 약자 Mobility as a Service
    스마트시티 자율주행 통합의 기술적 장벽 센서 및 통신 기술의 미성숙
    도시 계획에 미치는 장기 영향 보행자 중심의 도시 개발
    윤리적 고려사항과 거리가 먼 것 접근성
    CASE 관련 가장 적절한 설명 "공유 확산 시 총 주행거리는 감소할 수 있으나 공차 주행 증가로 효과 제한적"
    미래 모빌리티의 정의 "기존 운송수단에 첨단 기술이 융합·확장된 개념"
    정책 동향 중 옳지 않은 것 "한국은 2025년부터 내연기관 신규 등록 제한" (그런 정책 없음)
    데이터 파이프라인에서 성격이 다른 하나 NMS(추론 후처리)

    드론·로봇 (기말)¶

    함정 정답
    산림 보호·재해 감시 센서 조합 EO/IR 복합 + 열화상 카메라
    UTM 기능이 아닌 것 지자체별 연료 보급소 위치 전송
    AI 적용이 필수가 아닌 단계 날다 / 찍다 (자동화로 가능)
    플랫폼 기반 드론 연구 핵심요소가 아닌 것 고정익 기체의 날개 형상 해석
    로봇의 인류 문제 해결 사례로 보기 어려운 것 개인 맞춤형 엔터테인먼트 로봇
    자율주행차법·드론법의 공통 목적 신산업 창출·활용 촉진의 제도적 기반 마련
    무인이동체 기술 영역으로 보기 어려운 것 정밀 타격 미사일 운용 체계
    상업적 활용의 최우선 법적 쟁점 수집 영상의 개인정보·사생활 침해
    차세대 성장동력 설명 중 사실과 먼 것 "제조업 비중 계속 증가·고도 성장 지속"
    지능형 로봇 유연생산 핵심 전략 인간-로봇 협업 중심 유연 작업 흐름

    6. 함정의 패턴 — 왜 이런 문제가 나오는가¶

    출제 논리를 알면 처음 보는 문항도 풀린다

    패턴 ① 단계를 섞는다 — 판단 단계의 일(위치)을 제어 단계에 넣는다. → 각 단계가 하는 일을 정확히 구분해 둘 것. 패턴 ② 회사의 정체를 바꾼다 — 라이다 회사(루미나)를 프로세서 회사로 넣는다. → 기업–제품 짝을 외울 것. 패턴 ③ 센서의 약점을 강점으로 쓴다 — 라이다가 악천후에 강하다고 한다. → 각 센서가 못하는 것을 함께 외울 것. 패턴 ④ "항상/반드시"를 붙인다 — "항상 Softmax를 써야 한다". → 절대 표현이 있으면 의심할 것. 패턴 ⑤ 없는 정책을 만든다 — 한국의 2025년 내연기관 등록 제한. → 국가별 정책의 연도와 수치를 정확히 외울 것. 패턴 ⑥ 좋은 말을 오답으로 쓴다 — "전 공정 무인화", "모든 인간 개입 최소화". → 이 과목의 지향은 완전 무인화가 아니라 인간-로봇 협업이다.
