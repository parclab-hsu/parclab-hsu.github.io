    2주차 배포용 워크시트 — 인쇄해서 나눠 주는 용도¶

    진행 대본과 준비 체크리스트는 25번 「2주차 운영 키트」에 있다.

    워크시트 인쇄 부수 사용 시점
    E. LED 저항·분압기 계산 수강생 수 50~90분
    F. 계측 기록표 팀 수 + 2 90~155분

    워크시트 E · LED 저항과 배터리 분압기 계산¶

    모빌리티 전자제어유닛 실습 · 2주차    팀명 __ 이름 ____

    1. LED 전류 제한 저항¶

    교수가 지정한 조건을 적는다.

    항목 값
    공급 전압 Vs V
    LED 순방향 전압 Vf V
    목표 전류 If mA

    계산

    R = (Vs − Vf) / If  =  (        −        ) /         =            Ω

P = If² × R         =                             =            mW

    표준값 선택 — 계산값에 가장 가까운 E24 표준값을 고른다.

    항목 값
    선택한 표준 저항 Ω
    그때 실제 전류 If' = (Vs − Vf) / R mA
    목표 대비 차이 %
    선택한 저항의 정격 전력 W
    정격 대비 여유율 배

    ⚠️ 계산값 그대로는 살 수 없다. 표준값으로 바꾼 뒤 실제 전류를 다시 계산해야 설계가 끝난다.

    2. 배터리 전압 분배기¶

    조건 — 배터리 최대 42V, MCU ADC 입력 최대 3.3V, 목표 최대 입력 2.8V 이하

    Vadc = Vbat × Rbottom / (Rtop + Rbottom)
    항목 값
    Rtop Ω
    Rbottom Ω
    Vadc,max (42V일 때) V
    상시 소비 전류 Idivider µA
    Rtop 소비 전력 mW

    3. 세 가지 되묻기 — 반드시 채운다¶

    질문 우리 팀의 답
    저항값을 너무 작게 하면 무엇이 문제인가
    저항값을 너무 크게 하면 무엇이 문제인가
    ADC 샘플링과 RC 필터는 왜 연결되는가

    4. 필터 계산¶

    R = 10kΩ, C = 100nF일 때

    fc = 1 / (2πRC) =                Hz
τ  = R × C      =                ms
5τ 후 도달률    =                %

    워크시트 F · 계측 기록표¶

    모빌리티 전자제어유닛 실습 · 2주차    팀명 ______

    모든 측정값에는 단위와 측정 조건을 함께 적는다. 조건 없는 숫자는 증거가 아니다.

    측정 조건¶

    항목 내용
    사용 장비 (모델)
    멀티미터 레인지
    오실로스코프 설정 (V/div, s/div, 커플링)
    실온 °C

    실험 1 · 저항 공차 측정¶

    같은 표기값 저항 5개를 측정한다. 표기값 __ Ω, 표기 허용오차 ± ____ %

    번호 측정값 (Ω) 표기값 대비 오차 (%)
    1
    2
    3
    4
    5
    항목 값
    최대 오차 %
    표기 허용오차 안에 들어왔는가 예 / 아니오
    5개가 같은 값이 아닌 이유 (추측)

    실험 2 · RC 상승시간¶

    회로: R = ______ Ω, C = ______ F, 입력 사각파 __ Hz / ____ Vpp

    항목 계산값 측정값 차이
    시정수 τ ms ms
    63% 도달 시간 ms ms
    5τ (99% 도달) ms ms

    차이가 난 원인 추측: __________

    실험 3 · ADC gain·offset 오차¶

    분압기 출력을 ADC로 읽고 DMM 값과 비교한다.

    입력 전압 (DMM, V) ADC raw 환산 전압 (V) 오차 (V) 오차 (%) 
    환산식: Vpin = raw / 4095 × Vref     (Vref = ______ V)
    항목 값
    offset 오차 (0V 근처) V
    gain 오차 (최대 입력 근처) %
    보정이 필요한가 예 / 아니오

    종합 — 계산값과 측정값이 달랐던 이유¶

    실험 차이 가장 유력한 원인
    1 저항 공차
    2 RC 상승시간
    3 ADC 오차

    원인을 확정할 수 없으면 "확인 필요" 라고 적고 무엇을 더 재야 하는지 쓴다. 모르는 것을 아는 척하는 것이 가장 나쁜 보고다.
