    7주차 배포용 워크시트¶

    진행 대본과 준비 체크리스트는 7주차 운영 키트에 있다.

    워크시트 인쇄 부수 사용 시점
    O. 이산 PI 설계와 코드 검토 수강생 수 45~90분
    P. 튜닝 실험 기록표 팀 수 + 2 90~155분

    ⚠️ 워크시트 P의 튜닝 표와 선택 근거는 8주차 중간 설계 리뷰 자료가 된다. 버리지 말 것.

    2. 이산 PI 유도¶

    제어 주기 Ts = __ ms = ____ s

    error[k] = ref[k] − fdb[k]

I[k]     = I[k−1] + Ki × Ts × error[k]

u_raw[k] = Kp × error[k] + I[k]

u[k]     = clamp(u_raw[k],        ,        )
