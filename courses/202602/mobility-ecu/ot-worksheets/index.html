    1주차 배포용 워크시트 — 인쇄해서 나눠 주는 용도¶

    이 파일은 학생에게 그대로 나눠 주는 양식만 모았다. 진행 대본과 준비 체크리스트는 23번 「1주차 OT 운영 키트」에 있다.

    워크시트 인쇄 부수 사용 시점 회수
    A. 팀 편성·역할 카드 팀 수 + 2 80~90분 ○ (팀 명단 정리용)
    B. 로버 ECU 입출력 분해 팀 수 + 2 90~130분 △ (사진 촬영 후 반환)
    C. 요구사항 3개 + 미니 FMEA 팀 수 + 2 130~165분 △ (과제 초안으로 가져가게 함)
    D. 안전 수칙 확인서 수강생 수 + 5 25~30분 ○ (반드시 전원 회수)

    각 워크시트는 다음 쪽부터 한 장에 하나씩 나온다. 필요한 쪽만 골라 인쇄한다.

    워크시트 C · 요구사항 3개와 미니 FMEA¶

    팀명    ________

    1. 요구사항¶

    한 문장에 동작 하나만 쓰고 주어·조건·행동·수치·단위를 모두 넣는다. 검증 방법을 못 쓰면 그것은 요구사항이 아니다.

    ID 구분 요구사항 문장 검증 방법 검증 주차
    R-01 기능
    R-02 성능
    R-03 안전

    참고 — 좋은 예

    • 기능: 스로틀 입력에 비례해 좌우 바퀴 속도를 제어한다
    • 성능: 명령 대비 정상상태 속도 오차를 ±5% 이내로 유지한다
    • 안전: 홀 신호가 100ms 이상 갱신되지 않으면 120ms 안에 PWM을 차단한다

    나쁜 예 — "모터를 잘 제어한다" / "안정적으로 동작한다" / "빠르게 반응한다" → 시험자가 PASS인지 FAIL인지 정할 수 없다.

    2. 미니 FMEA¶

    고장 형태 원인 시스템에 미치는 영향 어떻게 탐지하는가 어떤 안전 상태로 가는가

    참고 예시

    고장 형태 원인 영향 탐지 안전 상태
    스로틀 단선 커넥터 이탈 입력 부동·최대값 ADC 정상범위 검사 PWM 차단

    이 표는 버리지 말 것. 8주차 중간 설계 리뷰의 요구사항 추적표와 15주차 인수시험 표의 첫 행이 된다.

    워크시트 D · 실습 안전 수칙 확인서¶

    모빌리티 전자제어유닛 실습 · 2026-2학기 · 한성대학교 미래모빌리티학과

    본 교과목은 배터리·모터·인버터를 다루는 실습 과목입니다. 아래 안전 수칙을 안내받고 이해하였음을 확인합니다.

    1. 위험 회전체 금지 프로펠러 등 위험 회전체를 장착한 상태로 모터를 구동하지 않는다.

    2. 구동 전 확인 모터 구동 전 전원 전압, 전류 제한, 극성, 배선 상태를 반드시 확인한다.

    3. 계측 안전 오실로스코프 GND 클립을 연결하기 전에 기준점을 확인하고, 고측(high-side) 게이트는 차동 프로브로 측정한다.

    4. 발열 부품 접촉 금지 MOSFET, 레귤레이터, 션트 저항 등 발열 부품을 손으로 직접 만지지 않는다.

    5. 고전류 실습 절차 고전류 실습은 전류 제한과 비상 차단 절차를 세운 뒤에만 진행한다.

    추가 확인 사항

    • 실습 중 이상 냄새·연기·과열을 발견하면 즉시 전원을 차단하고 교수자에게 알린다.
    • 모터 구동 시험 시 팀에서 비상 차단 담당자 1명을 지정한다.
    • 혼자 남아 고전류 실습을 하지 않는다.
