    11주차 배포용 워크시트¶

    진행 대본과 준비 체크리스트는 11주차 운영 키트에 있다.

    워크시트 인쇄 부수 사용 시점
    W. 정류 테이블 검증과 코드 흐름 수강생 수 35~90분
    X. 계측과 고장 주입 기록 팀 수 + 2 90~160분

    ⚠️ 오늘 수업에는 세 장의 지난 워크시트가 필요하다. 워크시트 L(5주차 홀 순서) · 워크시트 M(6주차 6-step 표) · 워크시트 V(10주차 타임라인)

    워크시트 W · 정류 테이블 검증과 코드 흐름¶

    3. RPM 계산¶

    mechanical_rpm = 60 × hall_edge_frequency / (6 × pole_pairs)
    항목 값
    측정한 edge 주파수 Hz
    극쌍 수
    계산한 기계 RPM rpm
    Teleplot에 표시된 RPM rpm
    차이가 있다면 원인

    4. 함수 호출·인터럽트 흐름도¶

    ⚠️ 인터럽트 문맥과 주기 태스크 문맥을 색 또는 선 종류로 구분한다. 섞어 그리면 과제 배점 2점을 못 받는다.

    [TIM1 UP ISR ____kHz]


[EXTI ____]


[1ms Task]


[10ms Task]

    공유 데이터 표시 — ISR과 main이 함께 만지는 변수

    변수명 쓰는 곳 읽는 곳 volatile? 일관성 보장 방법

    volatile은 최적화만 막는다. 여러 변수를 한 세트로 읽어야 하면 별도 처리가 필요하다.

    워크시트 X · 계측과 고장 주입 기록¶

    모빌리티 전자제어유닛 실습 · 11주차    팀명 ______

    0. 시험 전 안전 확인 — 전원을 켜기 전에 채운다¶

    확인 항목 확인
    모터 축 고정 또는 바퀴 공중 부양 ☐
    전원 전압 (12V 이하로 시작) ______ V ☐
    전류 제한 설정 ______ A ☐
    초기 duty 상한 (10% 이하) ______ % ☐
    비상 차단 담당자 ______ ☐
    로직 애널라이저 GND 먼저 연결 ☐

    🔴 전부 체크하기 전에는 전원을 켜지 않는다. 정류 표가 틀리면 관통 전류가 흐른다.

    1. Hall / PWM 동시 캡처¶

    채널 연결한 신호
    CH1~3 Hall A / B / C
    CH4~6 PWM enable (U / V / W)

    각 sector에서 실제로 켜진 상

    HallSum 워크시트 M의 표 실측 (파형에서 읽은 것) 일치?
    측정 항목 목표 실측 판정
    Hall 전이 → PWM 갱신 지연 20µs 이하 µs
    한 번에 바뀌는 Hall 비트 수 1비트 비트
    dead time (6주차 설정값과 비교) ns ns

    불일치가 있다면 — 증상으로 원인을 좁힌다

    관측한 증상 해당 유력한 원인
    진동만 하고 회전하지 않음 ☐ 정류 순서가 뒤섞임
    한 방향만 회전 ☐ 역방향 테이블 오류
    특정 구간에서만 덜컥거림 ☐ 홀 1채널 노이즈·접촉 불량
    반대로 회전 ☐ 시퀀스 방향 반전

    우리 팀이 실제로 고친 것

    2. 고장 주입 — 차단 지연을 숫자로 잰다¶

    ⚠️ 신호 주입으로만 한다. 하드 단락으로 과전류를 만들지 않는다.

    주입한 고장 방법 기대 동작 실제 동작 차단 지연 판정
    홀 신호 소실 커넥터 1개 분리 timeout → RPM 0 → PWM 차단 ms
    불법 Hall 값 000 또는 111 강제 즉시 fault, PWM 차단 ms
    명령 timeout UART 명령 중단 감속 후 정지 ms

    8주차 HSI에 적은 최대 허용 지연과 비교

    신호 HSI의 최대 허용 지연 실측 차단 지연 만족?

    "차단됐다"로 끝내지 않는다. 몇 ms 만에 차단됐는지가 증거다.

    3. 재시작 조건 확인¶

    확인 항목 결과 판정
    고장 원인을 제거하면 자동으로 다시 도는가 예 / 아니오 자동이면 결함
    명시적 재시작 명령이 필요한가 예 / 아니오
    재시작 시 PWM이 꺼진 상태에서 시작하는가 예 / 아니오
    fault 원인이 latch에 남아 있는가 예 / 아니오

    자동 재시작이었다면 무엇을 고쳐야 하는가

    4. 필수 진단 항목 점검¶

    진단 항목 우리 코드에 있는가 없다면 언제 넣을 것인가
    Hall 000/111, 불법 순서
    PWM 중 Hall timeout (stall)
    명령 방향 ≠ 측정 방향
    과전류·과열·저전압·과전압
    ISR 값과 main 값의 불일치
    제어 주기 초과(overrun)
    상위 명령 timeout

    overrun 판정 기준선 (10주차 워크시트 V에서 가져온다)

    항목 값
    1ms 태스크 실행 시간 ms
    주기 대비 비율 %
    여유가 충분한가 예 / 아니오

    항목 공유 / 분리 이유

    RPM, duty
    PI 적분항

    안전 차단

    확정할 수 없으면 "확인 필요" 라고 적고 무엇을 더 재야 하는지 쓴다.
