    10주차 배포용 워크시트¶

    진행 대본과 준비 체크리스트는 10주차 운영 키트에 있다.

    워크시트 인쇄 부수 사용 시점
    U. 주변장치 설정과 예산 계산 수강생 수 45~90분
    V. 통합 타임라인 측정 기록 팀 수 + 2 90~160분

    ⚠️ 워크시트 V의 타임라인 실측값은 11주차 overrun 진단의 기준선이 된다.

    워크시트 U · 주변장치 설정과 예산 계산¶

    모빌리티 전자제어유닛 실습 · 10주차    팀명 __ 이름 ____

    9주차에 검산한 클럭 값을 먼저 옮겨 적는다. 이 값이 오늘 모든 계산의 입력이다.

    0. 클럭 값 (9주차 워크시트 S에서 가져온다)¶

    항목 값

    과전류 차단
    홀센서 정류

    상태 출력

    4. UART 처리량 예산¶

    8-N-1 → 1 byte ≈ 10 bit

설정 baud =            bps

처리 가능량 = baud / 10 =                        =            byte/s

    4. 일부러 망가뜨려 보기 — 원인과 증상을 연결한다¶

    안전하게 되돌릴 수 있는 변경만 한다. 각 실험 뒤 원상 복구한다.

    실험 무엇을 바꿨는가 관측된 증상 왜 그런가
    ADC 트리거를 PWM edge로 옮김
    UART 출력 주기를 1kHz로 올림
    ISR 안에서 blocking UART 호출

    마지막 실험은 주기가 얼마나 밀리는지 반드시 숫자로 적는다. __ ms → ____ ms

    5. ISR 점검¶

    확인 항목 우리 코드는 판정
    ISR에서 pending flag를 지우는가
    ISR 안에 blocking 호출이 있는가
    ISR 안에 부동소수점 계산이 있는가
    ISR과 main이 공유하는 변수에 volatile이 붙었는가
    공유 변수의 원자성을 검토했는가 (volatile만으로는 부족)

    6. 다음 주로 넘길 것¶

    항목 값 11주차에서 어떻게 쓰이는가
    1ms 태스크 실행 시간 ms overrun 판정 기준선
    Hall EXTI 처리 시간 µs 정류 지연 예산
    확정한 출력 형식 정류 상태 로깅

    원인을 확정할 수 없으면 "확인 필요" 라고 적고 무엇을 더 재야 하는지 쓴다.
