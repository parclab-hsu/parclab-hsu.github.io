    전자부품/전원회로 기술 노트 (2~4주차)¶

    근거 자료: UAV개발/실무회로.pdf, 실무회로 기술면접 정리.pdf, 모터제어&인버터 기술면접 정리.pdf 출처표기: (슬)=강의 슬라이드, (면)=기술면접 정리

    0. 소자 대분류¶

    • 수동소자: 저항(전류 제한·열 변환), 인덕터(전류변화에 반대 기전력·자기장 저장), 커패시터(전하 축적/방출). 동작전압 개념 없음.
    • 능동소자: 반도체, 특정 동작전압 필요, 신호 증폭/변환. 디스크리트 vs IC.
    • 커패시터: DC→전하저장 / AC→주파수별 임피던스로 필터 역할.

    2주차 — 저항·커패시터·인덕터¶

    저항¶

    • 종류: 탄소피막(저렴·정밀↓), 금속피막(고정밀·온도계수 양호), 시멘트(대전력), SMD칩(AMR 주력), 서미스터(PTC/NTC), 바리스터(과전압 보호). AMR는 SMD 기준.
    • 등가회로: 실제 저항 = R + 기생C + 기생L. 기생L은 리드선에서 발생, 수백MHz↑서 영향.
    • 기본식: I=V/R, P=V²/R=I²R.
    • 선정 5요소: 용량, 허용오차, 정격전력, 최대허용전압, 온도.
    • LED 전류제한: R=(Vs−Vf)/If. 예 (5V−3.1V)/2mA. 색상별 Vf(빨2.0/노랑주황2.1~2.2/초2.1/파백3.0~3.6).
    • 풀업/풀다운: 4.7k~10kΩ, 입력임피던스 1/10 이하. 플로팅 방지(EMI·CMOS 관통전류).
    • 전압분배(AMR 핵심): Vadc=R2/(R1+R2)·Vin. 실회로: 배터리 32~45V를 82kΩ/4.99kΩ 분배→ADC. 32V→1.83V, 45V→2.58V. (인버터HW자료에서는 R55/R52로 4.99k/86.99k, 42V→2.16V 표기)
    • 션트저항(전류측정): AMR 실물 2mΩ ±1% 3W (인버터HW자료 소형보드는 10mΩ). P=I²·Rsh, 4-wire 켈빈, 차동증폭.
    • 고주파 기생L: Z=R+jωL. 저감=SMD·소형패키지·No-cut·최단배선.

    커패시터¶

    • 종류: 전해(극성·저주파·평활·ESR↑), MLCC(적층세라믹, AMR 주력, 무극성·고주파·바이패스), 필름(고전압·인버터 DC링크·고장시 Open). 탄탈 등.
    • 실제 = C + ESR + ESL. ESL로 고주파 공진점 발생, 그 이후 유도성.
    • Q=CV, Ic=C·dVc/dt, E=½CV².
    • AMR 입력 DC캡: 470uF 전해 ×2 병렬 = 940uF.
    • 디커플링(IC 안정 전원공급, 외부노이즈) vs 바이패스(IC 내부 스위칭 고주파를 GND로 우회): 둘 다 MLCC, IC 전원핀 근처 배치.
    • 다른 용량 병렬(10:1)로 주파수 분담, 안티레조넌스 주의. ESR 발열 P=I²rms·ESR, 전해는 10°C↑당 수명 절반.

    인덕터¶

    • VL=−L·dIL/dt, E=½LI², L=Φ/I.
    • 종류: 파워인덕터(전원회로·수십A), 페라이트비드(고주파서 R로 노이즈를 열로 소비), 변압기(절연 Vs/Vp=N2/N1).
    • 포화전류: 최대부하 20~30% 여유. 초과 시 인덕턴스 급감·리플·발열.
    • DCR(도선저항): 구리손실 P=I²·DCR. AMR 벅컨버터 인덕터에 적용.
    • 페라이트비드 3구간: 인덕티브→저항성(노이즈 흡수 핵심)→용량성.

    3주차 — 다이오드·BJT·MOSFET·CMOS·출력단¶

    다이오드¶

    • 순방향 Vf≈0.7V, 역회복시간 trr.
    • 종류: 범용정류(3상 전파정류+평활), 스위칭(1N4148, trr빠름), 쇼트키(Vf 0.2~0.6V, AMR 게이트Off, SS14), 제너(정전압 클램핑), TVS(ESD/서지 보호, 제너보다 빠름).

    BJT¶

    • 동작영역: 차단(Off)→선형(증폭)→포화(스위칭 On, VCE(sat)≈0.2V).
    • IB=(Vin−VBE)/RB, IC=IB·hFE, IE≈IC.
    • 2N3904 예제: Vcc=12V, IC=50mA → RL=(12−0.3)/0.05≈240Ω, RB=(5−0.95)/0.005≈820Ω.

    MOSFET (3상 인버터 핵심)¶

    • VGS>VGS(th)면 채널형성. 바디다이오드 존재. On 시 도통저항 RDS(on).
    • 동작영역: 차단(Vgs<Vth) / 선형·옴익(완전도통 On/Off 스위치용, Ron낮음) / 포화(스위칭 중 손실↑, 빠르게 통과).
    • VGS 12~15V 구동 → MCU 단독 불가 → 게이트드라이버 IC 필수.
    • 예시 SQJQ466E: Vds 60V, Id 200A, Vth 3.5V, Ron 1.9mΩ.
    • 기생C: Ciss=Cgs+Cgd, Coss=Cds+Cgd, Crss=Cgd. I=C·dv/dt로 손실.
    • Turn-on 4단계: ①Cgs충전(Vgs 0→Vth) ②채널전류상승 ③Miller Plateau(Cgd충전, Vds급락=턴온) ④포화충전.
    • 손실 P=Psw+Pcond, Pcond=ID²·Ron. 드라이브손실 P=QG·VGS·fsw.
    • 바디다이오드: trr 길어 필요시 외부 쇼트키 병렬 + 데드타임(shoot-through 방지).

    CMOS/TTL, Push-Pull/Open-Drain¶

    • 74HC04(Vcc6V): VIH4.2/VIL1.8, VOH5.34/VOL0.33 → 노이즈 마진.
    • 푸쉬풀(토템폴, High/Low 강구동) vs 오픈드레인(NMOS만, 외부풀업 필수, I2C·레벨변환).

    4주차 — 전원회로¶

    • 리니어 vs 스위칭: 리니어=부품적음·저노이즈·정밀, 발열·강압만·효율↓(η=Vout/Vin). 스위칭=고효율75~95%·승강압·소형, 노이즈·부품많음.
    • 리니어: 오차증폭기+기준전압+출력TR. Vout=(R1+R2)/R2·Vref.
    • 벅(강압, AMR 사용): Voltage-sec 평형 (Vin−Vout)DT=Vout(1−D)T → Vout=D·Vin. 리플 L=(Vin−Vout)D/(fsw·ΔiL). 동기식(다이오드→MOSFET 교체)로 효율↑(10A서 7W→1W).
    • 부스트(승압): Vout=Vin/(1−D). D=0.5→2배, 0.8→5배.

    주차 배분¶

    • 2주차: 소자 대분류 + 저항/커패시터/인덕터 (분량 많으면 2차시 분할)
    • 3주차: 다이오드/BJT/MOSFET(비중 최대)/CMOS/출력단
    • 4주차: 리니어/벅/부스트 (벅·부스트 유도는 인덕터와 연결)
