    6주차 배포용 워크시트¶

    진행 대본과 준비 체크리스트는 6주차 운영 키트에 있다.

    워크시트 인쇄 부수 사용 시점
    M. PWM 계산과 6-step 상 패턴 수강생 수 50~95분
    N. 파형 판독표와 데드타임 산정 팀 수 + 2 95~155분

    ⚠️ 워크시트 M의 6-step 표는 11주차 정류 코드의 원본이 된다. 반드시 회수하거나 사진을 남긴다.

    3. 6-step 상 패턴 표¶

    📌 5주차 워크시트 L에서 직접 측정한 홀 순서를 옆에 놓고 작성한다. 데이터시트를 그대로 옮기지 않는다.

    표기법

    +  : 상단 PWM 구동
−  : 하단 도통
0  : 비활성 (floating, high impedance)

    HallSum = A×4 + B×2 + C

    정방향 (CW)

    HallSum Phase A Phase B Phase C 도통 경로 (어느 상 상단 → 어느 상 하단)

    역방향 (CCW) — 정방향 표에서 무엇을 바꾸면 되는가?

    HallSum Phase A Phase B Phase C

    표 자체 검증 — 세 가지를 모두 확인한다

    검증 항목 통과?
    모든 행에 + 1개, − 1개, 0 1개가 있는가 예 / 아니오
    인접한 두 행은 한 상만 바뀌는가 예 / 아니오
    5주차에 측정한 홀 순서와 일치하는가 예 / 아니오

    하나라도 "아니오"이면 표가 틀렸다. 다시 작성한다.

    질문 답

    6. Coast · Brake · 회생¶

    방식 스위치 상태 전류 경로 언제 쓰는가
    Coast
    Dynamic brake
    회생
    질문 우리 팀의 답
    감속할 때 DC 링크 전압이 오르는 이유는
    배터리가 그 전류를 못 받으면 무슨 일이 생기는가
    어떻게 대비해야 하는가 (2가지)

    원인을 확정할 수 없으면 "확인 필요" 라고 적고 무엇을 더 재야 하는지 쓴다.
