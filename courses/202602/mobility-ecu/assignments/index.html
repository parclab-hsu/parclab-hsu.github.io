    과제집 · 주차별 과제와 제출 예시¶

    🔗 사용법 — 각 주차 강의 페이지의 🧪 실습·과제가 "무엇을 하는가"라면, 이 페이지는 "무엇을 어떤 형식으로 내고 어떻게 채점되는가"를 정한다. 제출 예시는 계산이 끝난 견본이며, 팀 조건으로 다시 계산해야 한다.

    공통 제출 규칙

    • 파일명은 W주차_팀명_이름.pdf 형식. 예: W03_로버1팀_홍길동.pdf
    • 모든 수치에 단위와 계산 근거를 적는다. 근거 없는 값은 0점 처리한다.
    • 측정값에는 조건(장비, 설정, 부하, 온도)을 같이 적는다.
    • 데이터시트 인용은 부품 번호·페이지·시험 조건을 표기한다.
    • 예시 수치를 그대로 옮겨 적으면 감점한다.
    • 마감은 다음 주 수업 시작 전, 1일 지각당 배점의 20% 감점.
    • 각 주차 5점, 15주 합계가 주차별 실습 과제 점수(25%)로 환산된다.

    1주차 · 로버 ECU 신호 흐름도¶

    제출물 형식 필수 포함
    신호 흐름도 A4 1장, 요구사항 3개, 미니 FMEA 3행 PDF 1~2장 전원·MCU·센서·인버터·모터·통신·보호

    지시 — 전원 경로와 신호 경로를 선 종류로 구분한다. 요구사항은 주어·조건·행동·수치·단위를 모두 포함한다.

    제출 예시

    전원 ═══        신호 ───

Battery 24V ═ 퓨즈 ═ 역극성 ═ DC링크 ═ 3상 인버터 ═ BLDC
                              ╚═ 벅 5V ═ LDO 3.3V ═ MCU

MCU ── PWM U/V/W ──> 게이트드라이버      MCU <── 홀 A/B/C ─── 모터
MCU <── 스로틀 ADC ── 그립              MCU <── 전류 ─── 션트+증폭
MCU ── UART 상태 ──> PC                 MCU ── Fault ──> LED
    • REQ-DRV-001: 로버는 평지에서 0.5m/s 이상으로 5m를 이탈 없이 주행해야 한다.
    • REQ-SAFE-001: 상전류가 5.0A를 초과하면 2ms 이내에 PWM 출력을 차단해야 한다.
    • REQ-PWR-001: 배터리 18~30V 범위에서 MCU 3.3V를 ±5% 이내로 공급해야 한다.
    고장 형태 원인 영향 탐지 안전 상태
    스로틀 단선 커넥터 이탈 입력 부동, 오동작 가속 ADC <0.3V 또는 >3.0V PWM 차단
    홀 신호 오류 접촉 불량 정류 오류, 역회전 HallSum 000/111 PWM 차단, 재시작 요구

    채점 — 경로 구분·블록 포함 2점 / 요구사항 검증 가능성 2점 / FMEA 구체성 1점

    2주차 · 수동소자 데이터시트와 계산¶

    제출물 형식 필수 포함
    R·C·L 정리표, LED 저항 계산, 분압기 설계, 계측 결과 PDF 2~3장 계산식, 표준값 근거, 측정 오차

    제출 예시

    LED (Vs=5V, Vf=2.0V, If=10mA)
R = (5.0-2.0)/0.010 = 300Ω → 표준 330Ω, 실제 9.1mA(-9%)
P = 0.0091² × 330 = 27mW → 1/16W 정격, 여유 2.3배
    분압기 항목 값 근거
    Rtop/Rbottom 100kΩ/10kΩ 분압비 1/11
    Vadc @30V 2.727V 30 × 10/110
    소스 임피던스 9.1kΩ Rtop∥Rbottom
    필터 100nF fc 175Hz, τ 0.91ms ADC 샘플링 시간과 함께 검토

    채점 — 계산·표준값 근거 2점 / 여유율 1점 / 소스 임피던스·시정수 1점 / 측정 오차 1점

    3주차 · MOSFET 선정표¶

    제출물 형식 필수 포함
    후보 3종 비교, 손실·접합온도 계산, 선정 근거 PDF 2장 고온 Rds(on), 스위칭·게이트 손실, 열

    제출 예시 (24V, 20A 피크, 20kHz, 주위 40°C, 도통률 50%)

    Rds(on) @125°C = 5.0mΩ × 1.7 = 8.5mΩ
Pcond = 20² × 0.0085 × 0.5 = 1.70W
Psw  ≈ 0.5 × 24 × 20 × (30+40)ns × 20kHz = 0.34W
Pgate = 30nC × 12V × 20kHz = 7.2mW
Tj ≈ 40 + 2.05 × 40 = 122°C  → 여유 부족

    판단: 구리 면적을 2배로 늘려 RθJA 25°C/W → Tj ≈ 91°C로 낮추면 채택 가능. 40V 정격 후보는 24V 링잉·회생 과전압에 여유가 없다.

    채점 — 세 손실 계산 2점 / 접합온도·방열 연결 1점 / 전압 여유 판단 1점 / 데이터시트 근거 1점

    4주차 · 전원 트리와 전력 예산¶

    제출물 형식 필수 포함
    전원 트리, 레일별 전류·보호 표, 입력 전류 계산 PDF 2장 설계 여유, 효율 반영, 보호 소자

    제출 예시

    레일 부하 최대 여유 설계 보호
    12V 게이트드라이버 0.30A 30% 0.39A UVLO
    5V 홀센서·통신 0.45A 30% 0.59A 과전류 제한
    3.3V MCU 0.25A 30% 0.33A BOR, power-good 
    Pout = 12×0.39 + 5×0.59 + 3.3×0.33 = 8.72W
Pin  = 8.72 / 0.85 = 10.26W → Iin(24V) = 0.43A
LDO 대안: (12-5) × 0.3 = 2.1W 발열 → 벅컨버터 채택

    채점 — 레일별 부하·여유 2점 / 효율 반영 1점 / LDO·벅 근거 1점 / 입력 보호 순서 1점

    5주차 · 로버 구동 모터 요구사항¶

    제출물 형식 필수 포함
    주행 요구 계산, 차동 구동 계산, 모터 대조표 PDF 2~3장 가정값, 연속/피크 구분, 미검증 표기

    제출 예시 (20kg, 15°, r=0.1m, Crr 0.03, a=0.2m/s², 2륜, 감속 10:1, η 0.8, track 0.30m)

    Fslope 50.8N + Froll 5.7N + Faccel 4.0N → Twheel 6.05N·m
Tmotor(각) = 6.05 / (10 × 0.8 × 2) = 0.378N·m   ← 연속 요구
직진 0.5m/s → 좌우 47.7rpm   제자리 회전 1rad/s → ∓14.3rpm
    항목 요구 후보 M1 판정
    연속 토크 0.38N·m 이상 0.55N·m 충족
    피크 토크 0.80N·m 이상 1.10N·m (5초) 충족
    제자리 회전 토크 미산정 - 미검증 위험으로 기록

    채점 — 저항 3종 반영 2점 / 감속비·효율 1점 / 직진·회전 각각 1점 / 미검증 기록 1점

    6주차 · 6-step 구동표와 데드타임¶

    제출물 형식 필수 포함
    6 sector 상 패턴, 전류 경로 설명, 데드타임 산정 PDF 2장 floating phase, 항목별 지연 합산

    제출 예시 — + 상단 PWM, - 하단 도통, 0 비활성

    HallSum A B C 도통 경로
    5 0 - + C 상단 → 권선 → B 하단
    3 - + 0 B 상단 → 권선 → A 하단
    1 - 0 + C 상단 → 권선 → A 하단
    6 + 0 - A 상단 → 권선 → C 하단
    4 + - 0 A 상단 → 권선 → B 하단
    2 0 + - B 상단 → 권선 → C 하단
    데드타임 항목 값
    드라이버 전파지연 편차 50ns
    MOSFET turn-off 지연 80ns
    하강 시간 40ns
    온도·공차 여유 200ns
    선정 500ns

    채점 — 표 일관성 2점 / 전류·환류 경로 1점 / 지연 합산 근거 1점 / 측정 절차 1점

    7주차 · PI 속도제어 튜닝 보고¶

    제출물 형식 필수 포함
    Kp·Ki 3조합 비교, 선택 근거, anti-windup 검토 PDF 2~3장 + 그래프 동일 조건, 전류 기록, 포화 실험

    제출 예시 (무부하, 0 → 300rpm step, 1ms 주기, duty 상한 60%)

    실험 Kp Ki 상승 overshoot 정착 정상오차 최대전류
    A 1.0 5 0.42s 0% 0.55s 6.0% 1.8A
    B 2.0 10 0.18s 8% 0.31s 0.5% 2.6A
    C 4.0 20 0.09s 24% 0.72s 0.4% 4.8A

    선택 B. C는 최대 전류가 과전류 임계 5.0A에 근접하고, A는 정상오차 6%로 ±5% 요구를 못 맞춘다.

    포화 실험: duty 상한 30%에서 500rpm 지령 후 200rpm으로 낮추면 210rpm까지 overshoot가 1.4초 지속된다 → 적분항이 포화 중에도 누적된 결과.

    채점 — 정량 비교 2점 / 요구사항 연결 1점 / 포화 재현 1점 / 적분 처리 지적 1점

    8주차 · 레지스터 직접 제어 코드¶

    제출물 형식 필수 포함
    GPIO 제어 코드와 주석, CubeMX 생성 코드 대조 코드 + PDF 1~2장 "왜 필요한가" 중심 주석, register view

    제출 예시

    /* BSRR을 쓰는 이유: ODR read-modify-write는 ISR이 같은 포트를 건드리면
 * 갱신이 유실될 수 있다. BSRR은 해당 비트만 원자적으로 set/reset한다. */
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN;   /* 클럭 없으면 레지스터 쓰기가 무시된다 */
GPIOC->MODER &= ~(3U << (6 * 2));      /* 두 비트를 먼저 지운다 */
GPIOC->MODER |=  (1U << (6 * 2));      /* 01 = output */
GPIOC->BSRR   =  (1U << 6);            /* ON  */
GPIOC->BSRR   =  (1U << (6 + 16));     /* OFF */

    CubeMX로 같은 핀을 설정해 생성된 MX_GPIO_Init()이 건드리는 레지스터를 register view로 확인하고 위 코드와 대조한다.

    채점 — 비트 마스킹·BSRR 이유 2점 / clock enable 연결 1점 / CubeMX 대조 1점 / 주석 품질 1점

    9주차 · 클럭 검산과 인터럽트 지연 측정¶

    제출물 형식 필수 포함
    클럭 트리 검산표, EXTI 지연·바운스 측정 PDF 2장 CubeMX 화면값과 레지스터 대조

    제출 예시 (HSE 16MHz)

    단계 설정 결과 확인 레지스터
    PLL M=8, N=216, P=2 216MHz RCC->PLLCFGR
    APB1 /4 54MHz RCC->CFGR PPRE1
    타이머 TIMPRE=1 216MHz RCC->DCKCFGR1
    측정 목표 실측 판정
    EXTI ISR 진입 지연 20µs 이하 3.2µs PASS
    스위치 바운스 폭 - 1.8ms debounce 5ms 적용

    채점 — 클럭 단계별 검산 2점 / CubeMX 대조 1점 / 지연 실측 1점 / 바운스 대책 1점

    10주차 · ADC·Timer·UART 통합 모니터¶

    제출물 형식 필수 포함
    통합 코드 또는 의사코드, 변환식, 타임라인 측정, UART 예산 코드 + PDF 2장 실측 주기, 검증 가능한 출력 형식

    제출 예시

    Vpin = raw/4095 × 3.3V ;  raw 2048 → 1.650V
Vdc  = 1.650 / 0.0909 = 18.2V (100k/10k) ; DMM 18.0V → +1.1%, 보정 0.989

1kHz 태스크: 216MHz / ((215+1) × (999+1)) = 1.000kHz
UART: 115200 8-N-1 → 11,520 B/s
      50B × 10Hz = 500 B/s (4.3%)  OK
      50B × 1kHz = 50,000 B/s      불가 → 주기 축소 또는 DMA

    출력 형식은 Teleplot으로 통일한다: >Throttle:1.24 >Vdc:18.2 >RpmFdb:120.0 >Flt:0

    채점 — 물리량 변환·실측 대조 2점 / 타이머 계산·확인 1점 / UART 예산 1점 / 출력 형식 1점

    11주차 · 요구사항·HSI 수정본¶

    제출물 형식 필수 포함
    요구사항 10개 이상, HSI 15신호 이상, 블록도, 검증 계획 PDF 4~6장 + CubeMX pinout 추적 트리, 리뷰 지적 반영

    제출 예시

    MIS-001 경사 15° 주행
 ├─ SYS-DRV-001 바퀴 토크 6.1N·m 이상          → T-DRV-06
 │   ├─ HW-PWR-003 상전류 10A 피크 허용        → T-PWR-04
 │   └─ SW-CTL-002 속도 오차 ±5% 이내          → T-DRV-03
 └─ SYS-SAFE-001 과전류 시 2ms 이내 차단       → T-SAFE-02
    신호 핀 정상 범위 고장 판정 리셋 중 최대 지연 검증
    THROTTLE PA7 0.8~2.8V <0.3V 또는 >3.0V 풀다운 10ms 전압 sweep
    HALL_A PD0 0/3.3V 000·111 조합 풀업 edge 즉시 EXTI 카운트
    OC_FLT PB12 Low=정상 High 유지 풀업 2ms 신호 주입
    번호 등급 지적 조치
    R-01 Critical 부팅 중 게이트 입력 부동 10kΩ 풀다운 추가 (rev B)
    R-02 Major 스로틀 단선 검출 없음 REQ-SAFE-003 추가

    채점 — 추적성 2점 / HSI 계약 항목 2점 / 지적 관리 1점

    12주차 · 회로 리뷰 체크리스트와 fault chain¶

    제출물 형식 필수 포함
    체크 항목 10개 이상과 판정, fault chain, bring-up 절차 PDF 2~3장 검증 방법, 미충족 조치 계획

    제출 예시 (발췌)

    # 항목 판정 근거
    3 MCU 미전원 시 게이트 풀다운 OK 10kΩ, 무전원 측정 0.0V
    4 드라이버 UVLO가 PWM 허용 조건에 포함 NG 미연결 → FAULT를 PB12로 배선 (rev C)
    5 하드웨어 과전류 비교기 NG 소프트만 존재 → 비교기 + TIM1 BKIN 
    션트 → 차동증폭(×15) → ① 비교기 → TIM1 BKIN → BDTR MOE=0 (수 µs, 펌웨어 무관)
                        └→ ② ADC → I_Max 판정 → Disable_PWM() (수백 µs)

    채점 — 항목 구체성·검증 2점 / 조치 계획 1점 / HW·SW 경로 구분 1점 / 고장 시 안전성 1점

    13주차 · PCB 초안과 배치 의도¶

    제출물 형식 필수 포함
    회로도·PCB 초안, 배치 의도 1장, net class, DRC 결과 PDF 2~3장 + 프로젝트 폭 근거, 미해결 DRC

    제출 예시 — 배치 순서: 전원 커넥터 → DC 링크 → MOSFET 브리지 → 게이트드라이버 → 션트 → MCU → 센서 커넥터. 고전류 루프를 먼저 최소화하고 MCU는 스위칭 노드에서 15mm 이상 이격.

    Net class 폭/규칙 근거
    High current (BAT+, PHASE) 2.5mm, 2oz 외층 10A, ΔT 20K 기준 + 여유
    Switching (SW node, GATE) 0.5mm, 루프 최소 면적 최소·민감 신호 이격
    Analog sense (SHUNT, NTC) 0.3mm 차동쌍 Kelvin, 리턴 분리

    DRC: 오류 0, 경고 3(실크 겹침 2, 테스트 포인트 간격 1) → rev C 정리 예정

    채점 — 배치 논리 2점 / 폭 근거 1점 / net class 1점 / DRC 기록 1점

    14주차 · 노이즈·그라운드 개선 보고서¶

    제출물 형식 필수 포함
    개선안 3건(문제·원인·영향·개선·검증), A/B 실험 PDF 2~3장 + 파형 동일 조건 비교, 부작용 기록

    제출 예시 — 게이트 저항만 변경, 나머지 조건 동일

    항목 A: 10Ω B: 22Ω 판단
    Switch node overshoot 41V 31V 정격 여유 개선
    ADC 전류 표준편차 12 LSB 5 LSB 개선
    MOSFET 온도(10분) 62°C 69°C 악화
    효율 89.1% 88.6% 소폭 악화

    B 채택 — 온도 7°C 상승은 Tj 여유 내이고 overshoot·계측 안정성 이득이 크다. 방열 면적을 늘리고 장시간 부하로 재확인한다.

    채점 — source·path·victim 분리 2점 / 동일 조건 1점 / 부작용 기록 1점 / 실현 가능성 1점

    15주차 · 구동 펌웨어 구조도와 최종 보고서¶

    15주차는 두 과제를 함께 낸다. 배점은 각 5점이며 최종 발표 평가와 별도로 산정한다.

    15-A. 통합 펌웨어 구조도와 안전 차단 경로¶

    제출 예시

    [TIM1 ISR 20kHz] ADC → 전류·온도 판정 → Fault 처리 → Set_Phases()
                                    ↓ (FltFlg)
                               Disable_PWM() → MOE=0
[EXTI0/1/2] Hall edge → Update_Hall_Sequence() → SpeedCal()
[1ms Task]  RpmRef → PI → VoltageRef

    제공 baseline 코드에서 요구사항 위반 2건 이상을 근거와 함께 보고한다.

    번호 관측 위반 개선안
    F-01 홀 커넥터를 뽑아도 RPM 300 유지 REQ-SAFE-002 edge timeout 후 RPM 0, PWM 차단
    F-02 적분항 무제한 누적, 음수 지령이 부호 없는 변수로 뒤집힘 REQ-CTL-001 적분 clamp, 하한 클램프

    15-B. 최종 보고서와 요구사항 추적표¶

    제출 예시 — 펌웨어 rc-1.3 (a9f21c4), MOTOR_KIT_B, OC 5.0A, duty 상한 60%

    요구사항 Test ID 결과 증거 비고
    REQ-PWR-001 T-PWR-01 PASS T-PWR-01.csv 3.29~3.31V
    REQ-SAFE-001 T-SAFE-02 PASS T-SAFE-02.png 실측 0.4ms
    REQ-SAFE-002 T-SAFE-03 FAIL T-SAFE-03.png 홀 소실 시 미차단
    REQ-DRV-001 T-DRV-04 PARTIAL T-DRV-04.mp4 0.42m/s, 편차 0.35m
    REQ-DRV-002 T-DRV-05 BLOCKED - 타이어 미끄러짐, 재시험
