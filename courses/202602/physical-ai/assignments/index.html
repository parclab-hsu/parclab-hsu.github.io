    📋 과제 · 평가 통합 안내¶

    이 페이지는 무엇인가

    한 학기 과제 15개와 평가 기준을 한 페이지에 모았습니다. 각 과제의 상세 설명·예시 코드·슬라이드는 해당 주차 페이지에 있습니다. 이 페이지는 "무엇을 언제까지 어떻게 내는가"만 봅니다.

    🎯 학기 전체 평가 비중¶

    항목 비중 설명
    출석 10%
    실습·과제 30% 아래 과제 1~14 (주차별 100점 만점을 환산)
    중간고사 25% 8주차 — 1~7주차 이론+실기
    기말 프로젝트 35% 과제 15 (System-1/2 통합 데모) + 발표

    📦 공통 제출 규정¶

    제출 형식 — 아래 3종을 한 번에 올립니다.

    1. 코드/설정 zip
    2. 보고서 PDF — 표지에 학번·이름·과제명 필수
    3. 실행 결과 스크린샷 / 영상

    마감 — 별도 표기가 없으면 다음 주차 강의 시작 전까지 LMS 업로드

    공통 원칙

    • 코드는 재현 가능해야 합니다. 실행 명령과 환경(버전·경로)을 보고서에 적으세요.
    • 외부 코드를 사용하면 출처를 명시합니다. 미표기 시 감점.
    • 스크린샷은 캡처 시점의 터미널 명령이 함께 보이도록 찍으면 증빙이 쉽습니다.
    • 실행이 끝까지 안 되더라도 어디서 왜 막혔는지를 기록해 제출하세요. 트러블슈팅 기록도 평가 대상입니다.

    ✅ 제출 전 체크리스트¶

    • 보고서 표지에 학번·이름·과제명이 있는가
    • zip 안의 코드가 다른 PC에서도 실행 가능한 형태인가 (절대경로·개인 환경 의존 제거)
    • 스크린샷/영상이 본인이 직접 실행한 것임을 알 수 있는가
    • 외부 코드·자료의 출처를 표기했는가
    • 실패한 부분이 있다면 증상 → 원인 추정 → 시도한 해결을 적었는가
